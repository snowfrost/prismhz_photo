# 生成失败诊断与修复

## 修复原则

先指出一个最主要的问题，再改写造成问题的完整镜头。不要把用户已经认可的镜头全部推翻。若问题来自全局光线、资产或负面约束，同步修正对应段落。

## 常见问题

| 表现 | 常见原因 | 修复方式 |
|---|---|---|
| 人脸出现硬光块 | 只写了阳光穿叶，没有限定漫射和补光 | 改为纱帘或树冠漫射侧前光，脸部柔亮，叶影只在衣料或脸侧短暂掠过 |
| 纱帘一直挡脸 | 把遮挡当成静态构图，没有写移开时机 | 写清纱帘何时贴近、何时离开，眼睛和五官必须重新露出 |
| 人物像站桩摆拍 | 只有姿态和服装，没有动作链 | 加入一件可完成的小事，并写起势、变化和落点 |
| 眼神呆或一直盯镜头 | 没有视线对象和变化 | 指定先看道具或远处，动作末端才短暂看向镜头附近 |
| 情绪过于忧伤 | 使用“落寞、悲伤、低垂”等强情绪词 | 改为平静、若有所思、松弛，下颌和嘴角放松 |
| 风很假或过强 | 只写“风吹动一切” | 写风的来源和方向，每镜只影响一至两个元素，发丝不遮脸 |
| 倒影脏、泥土抢镜 | 岸边与地面描述过多，水面缺少视觉优先级 | 裁掉泥岸，以干净深绿水面为主体，保留荷叶、细纹和完整倒影 |
| 镜头动作混乱 | 单镜头同时发生多项动作和多种运镜 | 留一个主动作、一个变化、一个运镜，其余拆镜头 |
| 背景人物抢戏 | 背景人物缺少清晰度和位置限制 | 限定为一个成年人失焦轮廓，不进入前景，不与主角对视 |
| 人物或服装漂移 | 没有资产锁定或换装节点 | 在资产绑定中锁定人物、发型、花饰、耳坠、服装和换装镜头 |
| 平台触发限制 | 年龄或关系表述模糊，负面词堆叠 | 明确人物均为成年人，用含蓄互动表达关系，删除无关敏感词 |
| 出现字幕、水印或标志 | 没有明确排除画面文字 | 在负面约束中写明禁止字幕、水印、标志和无关文字 |

## 局部修复流程

1. 复述用户指出的可见问题，不猜测无关原因。
2. 找到问题属于动作、构图、光线、风、连续性、资产或模型安全中的哪一类。
3. 改写受影响镜头的完整时间段，保留已确认的顺序、人物和总时长。
4. 检查前后镜头的道具、手势、视线和人物朝向是否仍然连贯。
5. 用户只要成品时，直接输出修正版，不附长篇诊断。
