# 人物风格与三视图规则

本文件用于根据已经确认的剧情、整体画风和人物参考，先让用户选择人物面容与穿搭，再通过一次图像生成直接建立一张16:9人物三视图。不得拆成定脸、全身立绘和三视图三次生成。

## 1. 人物风格选项

先从剧情中确定每名核心角色的身份、年龄、社会环境、性格、行动方式和叙事作用，再结合用户选择的整体画面风格设计三项人物风格。

每项选项使用一句信息完整但紧凑的中文，直接确定：

```text
年龄感 + 脸型轮廓与下颌 + 眉形与眼型 + 鼻型与唇形 + 肤色与妆容 + 发型 + 身材比例 + 完整服装方向 + 人物气质 + 1—2个身份记忆点
```

要求：

- 第一项必须是最适合当前剧情与整体画风的方案，并在选项末尾标注“（推荐）”；
- 三项保持同一角色身份和剧情功能，只改变具体人物风格；
- 三项在脸型轮廓、眉眼气质、发型和服装中至少有三处明显差异；
- 不使用抽象的“高级感”“氛围感”“好看”代替具体外观；
- 商业剧情中的主角可以精致、上镜、有审美完成度，但不得套用千篇一律的网红脸；现实人物、年长角色、反派或特殊身份角色优先服从其生活经历与剧情身份；
- 人物辨识度必须由骨相、五官气质与身份记忆点共同建立，服装只能辅助身份，不能代替容貌设计；
- 现代年轻女性、旅行、日常、校园与青春题材的三项选择优先分别采用日系小清新、韩系清透、日韩简约文艺方向；每项必须写出具体单品、版型、材质、配色、鞋履和克制配饰，不只写风格名称；
- 日系小清新优先使用棉麻衬衫、轻薄针织开衫、低饱和连衣长裙、A字长裙、乐福鞋或玛丽珍鞋；韩系清透优先使用短款针织开衫、利落短风衣、垂感直筒裤、简洁长裙和白色低帮鞋；日韩简约文艺优先使用宽松白衬衫、针织背心、浅卡其长裙、灰蓝阔腿裤和棕色皮鞋；
- 服装必须服从天气、动作与人物身份。寒冷湖边加入具体外套与防风层，夏日城市使用轻薄面料；没有运动剧情时不使用成套运动服，没有古装身份时不使用汉服；
- 不提供互相冲突的混合选项，不在一个选项中保留多个发型或服装；
- 有人物参考时保持同一人物身份、脸型骨相和核心五官，选项只调整妆发、服装与角色状态；
- 用户通过自由填写指定的痣、眉形、发际线、碎发、发饰或其他身份记忆点必须完整保留。

交互问题格式：

```text
问题：你希望【角色名】使用哪种面容与穿搭？
类型：单选
选项：三项根据当前剧情即时生成的具体面容、妆发与完整穿搭；现代年轻女性优先为日系小清新、韩系清透、日韩简约文艺
自由填写提示：补充具体五官、发型、服装或身份记忆点
```

## 2. 三视图提示词结构

用户选定人物风格后，按照以下五段结构编写完整中文提示词：

```text
【角色身份与外观】
【固定人物资产构图】
【肤质、布光与成像】
【一致性要求】
【负面约束】
```

### 【角色身份与外观】

有人物参考时，第一句写“严格以图片1为同一人物身份参考”，保持参考人物的脸型骨相、下颌线、眼型、鼻唇结构、肤色和身份记忆点；随后按照用户选择补充确定的妆容、发型、身材比例、完整服装、鞋袜与饰品。

没有人物参考时，根据剧情和用户选择直接写明角色的具体年龄、族裔、脸型、眉形、眼型、鼻型、唇形、肤色、妆容、发型、身材比例、完整服装、鞋袜、饰品、人物气质与一至两个身份记忆点。

服装必须从领口、上装、下装、腰部结构、鞋袜和饰品完整描述，配色与材质只有一套确定方案，画面无品牌标识。

### 【固定人物资产构图】

固定写明：

```text
横向16:9人物设定板，纯白无缝#ffffff背景，画面严格分为左右两个区域。

左侧约占60%：并排呈现同一人物三张等大的全身视图，依次为正面、完整侧面、背面。三个人物均从头顶完整呈现到鞋底，采用标准自然站姿，双手自然垂落，身高一致，头部高度、肩线、腰线、膝盖和脚底对齐，人物之间留出均匀间距。

右侧约占40%：呈现同一人物的正面面部近景，头部居中，完整显示脸部、双耳、发际线和全部发型，双眼自然直视镜头，表情符合角色气质。
```

右侧面部近景是不可省略的第四视图，不得以第三张全身图、半身图、侧脸或装饰元素替代。必须继续写明：

```text
右侧为独立的正面头颈面部细节图，人物面部高度占右侧区域的55%—60%，头顶靠近画面上缘，下方裁切至锁骨位置；完整保留脸部、双耳、发际线与全部头发，双眼平视镜头。双眼、睫毛、眉毛、虹膜、鼻部、嘴唇、双耳、发际线和全部发型处于同一清晰焦平面，不使用浅景深。构图优先级：右侧面部细节清晰度 > 四视图身份一致性 > 左侧全身服装细节。
```

### 【肤质、布光与成像】

默认使用真人写实质感，提示词中必须写入以下皮肤质感原句：

```text
smooth clean realistic skin with a refined natural finish, subtle fine texture and minimal barely-visible pores, looking real but polished like high-end editorial retouching, never plastic, never rough bumpy blemished
```

同时写明：肤色真实通透，保留细微且克制的自然肌理；使用柔和、有体积感的人像布光，额头、鼻梁和颧骨出现柔和高光，脸侧形成轻微柔影，暖色皮肤具有自然半透明感。整个人物与全部服装清晰，发丝、耳朵、手指、鞋袜和饰品细节完整，右侧面部细节达到高端人物选角照与编辑级轻修质感，边缘干净，不使用浅景深。

避免玻璃皮肤、蜡像或塑料肤质、完全对称的假脸、过大眼睛、通用网红脸、粗糙凸起毛孔、灰暗肤色与过度锐化。人物可以精致，但必须保留可信的骨相起伏、面部软组织转折和自然表情张力。

用户明确选择3D、CG、三渲二或插画风格时，质感按该风格统一转换，但固定构图、纯白背景、人物身份和三视图一致性保持不变。不得把真人皮肤词与3D或插画渲染词混写。

### 【一致性要求】

固定写明：

```text
左侧正面、侧面、背面与右侧面部近景属于同一个人，脸型骨相、五官结构、肤色、发型、发饰、身材比例、服装结构、材质、颜色、鞋袜和饰品完全一致。侧面为完整90度侧视，背面真实呈现同一发型和服装背部结构。四个视图保持统一比例、统一光线和统一清晰度。
```

### 【负面约束】

使用一段紧凑文字限制：灰色或米白背景、复杂场景、文字、水印、Logo、多人身份、不同脸、不同发型、不同服装、人物重复、视图缺失、半侧面冒充完整侧面、背面回头、裁切头顶或鞋底、比例不一致、肢体畸形、多余手指、模糊面部、浅景深、蜡像皮肤和过度锐化。

## 3. 图像生成调用

人物资产画幅与项目视频画幅是两个独立变量：`character_asset_aspect` 永久固定为16:9，`project_video_aspect` 只供场景资产和最终视频节点使用。即使项目视频选择21:9或9:16，人物三视图仍然使用16:9。

每名角色只调用一次图像生成。调用前先建立唯一的 `character_asset_prompt`，该变量必须是按照本文件完整展开的五段提示词，而不是人物设定摘要：

```text
character_asset_prompt = "【角色身份与外观】……【固定人物资产构图】……【肤质、布光与成像】……【一致性要求】……【负面约束】……"

图像生成能力(
  prompt=character_asset_prompt,
  title="【角色名】人物三视图",
  tag="character",
  aspect_ratio=character_asset_aspect,
  参考资产=[用户上传的人物参考图；没有参考时省略]
)
```

调用前检查提示词必须同时包含：

- 横向16:9人物设定板；
- 左侧约60%的正面、完整侧面、背面全身视图；
- 右侧约40%的正面面部近景；
- 纯白无缝#ffffff背景；
- 同一人物、同一面部、同一发型、同一服装与同一身材比例；
- 清晰完整的头顶、双手和鞋底；
- 当前角色选定的具体人物风格与身份记忆点。
- 对年龄、脸型轮廓、下颌、眉形、眼型、鼻型、唇形、肤色、妆容、发型、身材和完整服装的明确描述；
- 右侧独立正面头颈面部细节图，面部高度占右侧区域55%—60%，下方裁切至锁骨；
- 右侧双眼、睫毛、眉毛、虹膜、鼻部、嘴唇、双耳、发际线和全部头发处于同一清晰焦平面；
- 写实人物包含指定的真实精修肤质原句与柔和体积人像布光。

缺少任意一项时先补全提示词，不得调用图像生成。将检查通过的整份中文提示词原样传递给图像生成节点，不压缩、不翻译、不重新组织。

### 3.1 节点输入框硬检查

图像节点的提示词输入框是最终生成依据，不是摘要展示区。写入后必须读取或检查输入框内容，并同时满足：

- 五个标题完整存在且顺序正确；
- 角色容貌不是“圆脸、皮肤白净、眼神明亮”一类概述，而是完整包含骨相、下颌、眉眼、虹膜、鼻唇、妆容、发型、身材、服装与身份记忆点；
- 完整包含左侧60%三张全身图与右侧40%独立面部细节图的构图；
- 完整包含面部高度55%—60%、裁切至锁骨、面部全部细节处于同一焦平面的要求；
- 写实角色完整包含指定的英文肤质原句、体积人像布光与防止网红脸、塑料皮肤的约束；
- 输入框中的文字与 `character_asset_prompt` 完全一致。
- 图像节点的真实画幅参数等于16:9，不是项目视频的21:9或9:16。

如果输入框只出现“人物三视图，16:9横版，纯白背景，正面、侧面、背面”一类短句，判定为写入失败。人物节点真实画幅显示21:9或9:16时同样判定为配置失败。必须先覆盖成完整五段提示词，并把真实画幅改为16:9，再调用生成；不得用短句或错误画幅继续生成，也不得在生成之后才补写。

## 4. 生成后的处理

生成成功后把该图片标记为对应角色的人物身份与服装资产，继续进入剧情梳理与标准分镜。用户对生成结果提出修改时，只调整指定的面部、发型、服装、比例或构图问题，保留未被否决的角色设定并重新生成该角色三视图。
