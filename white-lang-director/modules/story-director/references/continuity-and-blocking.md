# 连续性与空间调度

涉及参考图、双人镜头、门内门外、道路、车辆、马匹、队伍、换装、跨年龄、遮挡人物或核心道具时，完整执行本文件。

## 1. 连续性账本

在内部为每个时间段记录：

| 项目 | 必须明确的状态 |
|---|---|
| 时间 | 当日、前夜、清晨、回忆、季节、天气 |
| 人物版本 | 年龄、发型、胡须、身份与当前服装 |
| 人物状态 | 位置、站坐蹲、朝向、视线与遮挡 |
| 道具 | 持有人、左右手、佩戴部位、外观与动作后状态 |
| 空间 | 摄影机所在区域、人物所在区域、入口与边界 |
| 已完成事件 | 已进入、已离开、已交付、已佩戴、已揭示的信息 |

下一镜继承上一镜结束状态。换装、跨年龄、跨时段和道具转移必须由镜头、对白或场次切换明确说明。

## 2. 参考资产是空间依据

用户上传环境图、标记站位或绘制路径时，严格绑定：

- 固定建筑结构；
- 门窗和家具位置；
- 红框对应的人物站位；
- 箭头对应的移动路径；
- 已明确的门内、门外与道路方向。

不要因“画面更电影”擅自改变结构、扩大入口、增加侧门或创造未出现的反向空间。

一张环境图只可靠地定义其当前观察方向。计划反拍、侧拍或门外反看时，先检查资产是否覆盖该方向。资产没有定义时，限制镜头角度，或明确告诉用户需要补充反向环境资产；不要凭空编造复杂空间。

## 3. 摄影机位置验证

每镜内部先写一句：

```text
摄影机位于哪里，朝向哪里，主体背后因此能看到什么。
```

使用反证检查：

- 人物背后是庭院，摄影机通常位于门外朝向府内；
- 人物背后是横向街道，摄影机通常位于府内朝向府外；
- 摄影机在人物背后时，只能看见后脑、肩背、步速和手臂动作；
- 摄影机在人物正前方时，不能同时看清远离画面的背后细节动作。

背景与摄影机位置不匹配时，改机位或改背景，不能同时保留矛盾描述。

## 4. 世界位置与画面位置

区分：

- 世界位置：人物在真实场景中的左右与前后关系；
- 画面位置：当前摄影机观看时人物位于屏幕左侧或右侧。

摄影机反向后，画面左右可能翻转。每次切镜都重新确认画面左、画面右，不机械继承上一镜。

双人镜头至少明确：

```text
谁在画面左侧
谁在画面右侧
两人面对、同向或并排
谁靠近镜头
谁允许转身、越过或离开
```

## 5. 门槛与运动边界

把房门、府门、车门、站台、街道边缘和水岸视为明确边界。写清：

- 谁可以跨越；
- 谁必须停留；
- 跨越发生在哪一镜；
- 门外的人马、车辆和队伍允许向哪个方向运动。

横向街道只允许人物和队伍沿画面左或画面右移动，不使用“向远处前进”“走向院内”等纵深表达。

复杂边界动作必须拆分：

```text
走到门口 → 跨过门槛 → 上马或上车 → 队伍启动
```

不要在同一镜头里完成全部步骤。

## 6. 前景、背景与浅景深

每个背景人物必须在当前时间和空间中真实存在。

- 已经离开画面的角色不得以影子、倒影、虚影或焦外人物重新出现；
- 用户要求真实人物通报时，显示真实身体，可裁掉面部，不用墙面影子代替；
- 浅景深焦外背景只承担环境和低重要度动作；
- 回头、回礼、告别、递交道具和关键反应必须放在主体清晰的镜头中；
- 背景角色承担重要事件时，改用中远景、全景、同焦平面双人镜头或独立切镜。

输出提示词时，普通单人镜头无需机械列举前景、中景与后景。正反打、过肩、门内门外和多人调度镜头必须在自然段中明确：摄影机实际位置与朝向、前景人物或遮挡物、清晰主体、主体画面左右、视线方向与主体背后的固定空间锚点。

正反打先在内部锁定两人之间的动作轴线，两台摄影机始终位于轴线同一侧。人物A在画面左侧朝右看时，反打后的人物B保持在画面右侧朝左看。两侧镜头分别使用各自拍摄方向真实存在的背景结构，背景门窗、家具和通道的位置与摄影机方向一致。

环境资产只展示一个方向时，采用靠近动作轴线的小角度过肩反打，使两个角度继续使用资产中已经定义的结构。完整反向空间承担关键剧情时，先将反向环境列入所需资产，再编写对应镜头。

## 7. 景别与可见性

根据必须看见的内容选择：

| 必须看见 | 推荐景别 |
|---|---|
| 眼睛与细微面部反应 | 面部特写 |
| 面部、肩颈与手部 | 半身近景 |
| 面部、双手与腰间道具 | 膝上中景 |
| 双人关系与近距离动作 | 双人中景 |
| 人物与门、道路、车辆关系 | 中远景或全景 |
| 队伍完整运动方向 | 固定全景 |

一个景别无法同时看清全部关键信息时拆镜。不要要求面部特写同时展示完整脚步、腰间道具和远处队伍。

## 8. 过肩镜头

过肩镜头必须明确：

```text
从谁的哪一侧肩后拍摄
该人物位于哪侧前景
镜头主要看向谁或什么
前景人物是否露脸
背景动作是否在当前景深内清楚可见
```

不要只写“父亲过肩镜头”。使用“摄影机位于父亲右肩后方，父亲后脑与右肩位于画面右侧前景，镜头看向门外的女儿与花轿”。

## 9. 遮挡人物

纯背影、红盖头、面具、头盔和前景遮挡状态下，只写当前能看见的表演：

- 手部收紧或松开；
- 头部转向；
- 肩背和身体重心；
- 步速与停顿；
- 与另一人物的距离变化。

不写被遮住的眼神、眉间、嘴角和泪水。需要面部情绪时，切到可见面部的人物，或调整机位。

## 10. 道具与服装

道具必须绑定具体人体或场景结构：

```text
白玉佩系在人物左侧自然腰线的腰带上，位于上衣下缘与裙身起点之间。
```

不要只写“玉佩在嫁衣旁边”，否则模型可能把玉佩放到裙摆、手中或地面。

服装按场次时间绑定。前夜常服、清晨婚服、回忆时期甲胄属于不同状态，不因后续剧情提前换装。

同一人物的年龄和服装变体应使用各自资产，同时保持身份连续。不同版本之间不要混用白发、胡须、甲胄和礼服。

## 11. 车辆、花轿与入口

车辆和花轿必须定义：

- 停放区域；
- 正门朝向；
- 人物从哪个入口进入；
- 入口与建筑大门的相对位置；
- 启动后的唯一方向。

例如：

```text
红色花轿停在府门外横向街道上，花轿正面中央轿帘朝向府门。丫鬟掀开正面中央轿帘，扶新娘从花轿正门进入，花轿侧面没有入口。
```

## 12. 匹配转场

匹配切换前检查：

- 主体是否为同一人物或同一道具；
- 主体在画面中的位置和尺度是否接近；
- 动作和摆动方向是否连续；
- 前后镜头是否具有清楚时间差；
- 下一镜是否错误保留上一场已经离开的背景人物。

匹配转场服务时间与情绪连接，不掩盖空间逻辑。
