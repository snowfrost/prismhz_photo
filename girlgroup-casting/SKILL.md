# 韩系女团选角与面部资产出图

为多人韩系女团编写可直接投喂图像模型的中文面部资产提示词，并批量生成定妆照。核心方法论：把「稳定妆容与摄影质感」和「可变化的人物身份」分成两层分开控制，多人不撞型，单人可迭代。

实战案例：棱镜Hz 四人女团（完整提示词与成图见 [references](references/) 与 [images](images/)）。

## 什么时候用这个技能

- 需要为一支多人女团（2-7 人）建立面部资产库
- 已有成员设定或参考图，需要写出可生成、可复现的提示词
- 需要批量出定妆照并做单成员返修迭代

## 核心方法论

### 两层锁定法

**固定层（妆容母版，全员一致，不得被稀释）**：

- 冷白粉瓷肌与真实细微皮肤纹理
- 韩系女团妆容：奶油粉、草莓牛奶粉、灰粉、浅玫瑰粉眼妆；下眼睑粉妆、自然卧蚕、空气感分束睫毛
- 眼下至苹果肌上缘连续的透明冷粉腮红
- 果冻唇：粉润鲜活、中央渐层、下唇中央透明高光
- 商业美妆质感：高明度、低至中等饱和度、柔和低反差
- 摄影规格：纯白背景、贝壳光（上方大柔光箱+下方白色反光板）、平视中长焦、完整头部清晰、无广角畸变

**可变层（身份区隔，每人独立设定）**：

- 脸型轮廓与面部长度
- 眉眼形态、双眼皮结构与眼尾方向
- 鼻梁、鼻尖、鼻翼关系
- 唇宽、唇峰、上下唇比例与静态表情
- 发际线、刘海、发长、发型轮廓、发色
- 一至两个不突兀的身份记忆点（痣、耳环、雀斑等）
- 服装领口可见部分与成员气质

**四项差异化铁律**：不同成员至少在「脸型轮廓、眉眼形态、鼻唇比例、发型与发际线」四项中的**三项**明显不同。不得只换发色或衣服，也不得用降低颜值的方式制造差异。短发成员超过一人时尤其警惕发型撞型。

### 主题色体系

多人团建议为每位成员分配主题色（呼应团名概念），写入提示词的服装与配饰色，如棱镜Hz（白光过棱镜分四束光）：

| 成员 | 定位 | 主题色 |
|---|---|---|
| Hz-01 | 主唱 VOCAL | 月光银白 `#DDE0EA` |
| Hz-02 | 领舞 DANCE | 琥珀金 `#F0A830` |
| Hz-03 | 门面 VISUAL | 蜜桃粉 `#F2A6A0` |
| Hz-04 | 忙内 RAP | 薰衣草紫 `#B4A0E5` |

### 确认门机制（流程控制）

1. **第一道门**：全员面部资产提示词 → 批量出图 → 用户逐人验收
2. **第二道门**：面部锁定后才进人物三视图（16:9 一行多格设定板，锁头身比与团服）
3. **第三道门**：三视图确认后才进 MV / 舞台视频提示词

未过门不进入下一阶段；返修只重掷被否决的成员，不全员重跑。

### 迭代返修模式

- **撞型检测**：出图后横向对比全员，发现两人发型/脸型过近 → 只改其中一人的可变层（如单马尾换高马尾/双马尾），固定层不动
- **气质微调**：用户要「更幼态/更成熟」时，调妆容母版的腮红位置、卧蚕强度与眼神词，不动骨相
- **回滚**：迭代版本不如初版时回滚，用 git 式命名（v2/v3 后缀）保留全部版本图
- **单张重掷**：只重跑问题成员，用完整提示词原文投喂，不改其他成员

## 出图链路（RunningHub G-2 经济版）

批量出图脚本见 [scripts/gen_prism_hz.py](scripts/gen_prism_hz.py)，流程：

1. 解析选角 md（按 `## Hz-XX｜` 分块提取面部资产提示词）
2. 2 并发投喂 RunningHub `rhart-image-g-2/text-to-image`（3:4、1k）
3. 下载后做 **PNG 完整性双重校验**：
   - 尾部 12 字节 hex 必须等于 `0000000049454e44ae426082`（IEND 块，注意是 `49454e44` 不是 `494e4444`）
   - 文件大小与响应 Content-Length 一致
4. 校验失败 → 用 taskId 重新查询 resultUrl 补下载

实测：单张约 50 秒、约 ¥0.015。

**使用前设置**：

```bash
export RUNNINGHUB_API_KEY=<你的key>
# 脚本从环境变量读 key，不落盘
```

脚本默认依赖 `runninghub.py` CLI 封装（OpenClaw_RH_Skills），也可按上述流程自行实现直连：`POST /openapi/v2/rhart-image-g-2/text-to-image` 创建任务 → `POST /openapi/v2/query` 轮询 taskId → 下载校验。

## 多参考图职责（图生图锁脸时）

同时提供多张参考图时，为每张分配唯一职责并写进提示词开头：

- 人脸参考：只锁脸型骨相、眉眼、鼻唇比例和身份记忆点
- 发型参考：只锁发长轮廓刘海发色，不继承该图的脸
- 服装参考：只锁品类剪裁材质配色，不继承脸与发型
- 摄影参考：只提取布光色调景别质感，不继承人物身份

参考冲突时，以已确认的面部资产为准，其余参考不得覆盖。

## 交付边界

- 默认只输出提示词文本；用户明确要求出图时才调接口
- 面部未确认前不进三视图，三视图未确认前不进 MV
- 出图后主动做撞型检测并报告，不等用户发现
