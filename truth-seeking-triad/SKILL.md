# 求真三定律分析框架（三棱镜分析）

李继刚谈「求真」：人脑子里可能装着三百个道理，但摊在桌面上是散的，遇到事随手抓一个不对。所以要一层层往下扒，扒到最底层那几个不变的东西——「秩」。扒出来的就三个：**贝叶斯定理、奥卡姆剃刀、万有理论**。看 AI、看投资、看人生，都从这三个地方出发。

本技能强制：任何被判定为「需要分析」的输入，三个定律必须各走一遍、缺一不可，且在最终输出显式呈现三条线。

## 三个原理各司其职（一句话记牢）

| 原理 | 认知角色 | 核心追问 |
|------|---------|---------|
| 贝叶斯定理 | 更新器 | 证据如何改变了我原先的判断？ |
| 奥卡姆剃刀 | 过滤器 | 真正定住骨架的「秩」变量是哪几个？ |
| 万有理论 | 统一器 | 有没有一个更简洁的结构同时覆盖这些现象？ |

三者是一条互锁的链，缺一个就废：

- **没有贝叶斯的更新**，剃刀和统一就会变成教条（一次剃对、一次统一就再也不改）；
- **没有剃刀的筛选**，贝叶斯会在无限变量里迷失（每个变量都给个概率，等于没给）；
- **没有统一的追求**，剃刀和贝叶斯只是碎片化工具，看见树看不见林。

所以顺序固定：**剃刀找变量 → 贝叶斯定权重 → 万有理论给结构**，然后交叉校验、循环迭代。

## 何时使用

触发条件（满足任一即用）：

- 分析某个事件、现象、新闻、人物、公司、决策、观点、谣言
- 研究某个领域、行业、技术趋势
- 解读/拆解某篇文章、一本书、一段报告、一个视频
- 预测某事走向、判断某说法可信度、比较多个选项

不触发：闲聊、翻译、格式化写作、纯工具操作、简单事实查询（「今天几号」这类无需判断的确定性任务）。

本技能是「底层世界观底座」，与 reasoning-foundation（按目标挑方法）不冲突——可叠加：先用三定律定住根本，再用 reasoning-foundation 选具体推演方法。

## 核心心态（贯穿全程，不每次复述）

- **谦卑与开放不是姿态，是定理的推论**：先验永远不完美，所以天然对新证据开放；你看到的只是某个「取景框」里的投影，不是本体。
- **结论永远是 0.x，不是 1**：说「99%」时想一想，缺的那 1% 藏在哪里。
- **观点与自我剥离**：结论只是「当前认知上限」，被更好的证据推翻不是打脸，是「破而后立」。进一寸有进一寸的欢喜。
- **汇报结论，不汇报动作**：三条分析线是幕后工序，交付结论本身；用户问「你怎么想的」时才展示推演过程。

## 第零步：接收与聚焦

接收输入。**只在输入确实过于模糊时**（如「分析一下经济」「聊聊AI」），追问一句把焦点收窄：「你希望聚焦在其中的哪个具体现象或问题上？」得到焦点后进入第一层。

约束：

- 输入已经足够具体（有人物、事件、领域、或明确的问题指向）→ 直接进入第一层，**不追问**。
- 追问只问**一个**决定性问题，不连环问、不阻塞可逆工作。
- 自己能用合理假设先聚焦的，就先做、把聚焦范围写在结论开头，让用户看到后纠正，而不是停下来等——这比停下来问更符合「汇报结论」的作风。

## 第一层：贝叶斯定理 —— 假说的概率迭代

把分析对象转成「几个互斥解释在抢概率」，而非「一个解释自说自话」。

1. **摆假说空间**：列出相互竞争的解释 H₁、H₂…（一般 2~5 个，一句话、可检验）。只有一个解释就没有概率，贝叶斯退化成断言。
2. **给先验**：基于已有知识与基准率，给每个假说初始概率或显式排序，并说明依据。承认先验必然片面。不确定就说「不确定」，禁止虚假精确。
3. **纳证据**：列出关键证据 E，逐条估它对各假说的似然——问「如果 Hᵢ 为真，看到 E 的概率多大」，而不是「E 看着像 Hᵢ 所以 Hᵢ 为真」。**警惕反绎谬误：「解释得通」≠「很可能为真」，好故事往往似然低。** 同时区分硬证据与噪声（传闻、情绪、二手转述）。
4. **出后验**：给出更新后的排序。它是迭代中间态——本轮后验是下轮先验。
5. **预承诺证伪**：明确写「出现什么证据，我会翻转当前排序」。

产出格式（写入最终答案时按需精简）：

> **假说空间 H₁…Hₙ** → **先验（含依据）** → **关键证据与似然** → **后验排序（附置信度）** → **翻转条件**

## 第二层：奥卡姆剃刀 —— 找到「秩」变量

一千个变量里通常约三个真正起决定作用。关键不是「删到少」，而是「删到骨架」。

1. **铺开全集**：把相关变量尽量摊开（越多越好），不预设谁重要。
2. **剃**：逐个追问「去掉它，现象是否依然成立？」能去掉的都是衣服（表象、噪声、跟风），去掉就塌的是骨架。没有「删除」这一步，就不算剃，只是罗列。
3. **定秩变量**：留下 ≤3 个。注意——**秩变量不是「最重要的变量」，而是「定义坐标系本身的变量」**：它们定了系统的骨架，其余变量只是在这个坐标系里的位置呈现。判据「去掉它整个分析坍塌成什么样」。有时「最重要的」其实是现象级，真正的秩在更底层（如分析公司，创始人特质可能是现象级，「行业结构」才是秩——结构定义了可能性空间，创始人只能在里面选位置）。
4. **重建检验**：用这几个秩变量重新推演主要表象，验证压缩没丢关键信息。推演不出来的，说明剃多了或找错了。

原则：如无必要，勿增实体。但剃刀剃的是「不必要的实体」，不是「必要的复杂」——对象真由多个独立机制驱动时，如实保留并说清关系。

产出格式：

> **变量全集** → **剃掉什么（及理由）** → **秩变量 ≤3（它们如何定义坐标系）** → **重建检验**

## 第三层：万有理论 —— 统一结构的追问

物理学上强/弱/电磁力之上应有一个更高维公式统摄。移植到分析是：**在众多自洽的局部解释背后，追问有没有一个更简洁的底层结构能同时覆盖它们。** 注意：这不是「解释一切的万能公式」，是一种认知姿态。

1. **盘点下层框架**：列出该问题域已有的主流解释、流派、常识观点——它们是待统摄的「四种力」。
2. **向上抽象**：把第二层的秩变量往上提一层，找它们共同的根源——一个机制、一条规律、一句能统领的话。找「生成关系」而非「并列关系」：统一结构不是说「两边都对」，而是指出「两边是同一结构在不同参数下的投影」。
3. **向下验证**：这个统一结构能不能把下层各框架都「推」出来？能不能同时解释至少两个看似不相关的现象？谁看到了哪个投影、忽略了什么？推出不来的地方就是失效边界，老实标出。
4. **命名结构**：找到了就给可复用命名（像 F=ma、梅特卡夫定律），让用户下次直接调用；找不到就诚实说「当前是未被统一的多元结构」，给出最接近的统一尝试 + 缺口清单，禁止硬凑公式。

产出格式：

> **下层框架盘点** → **统一结构（一句话）** → **如何推出各框架 / 失效边界** → **可复用命名 或 缺口清单**

## 三环互锁与交叉校验

三层结果要互相咬合，不能各写各的：

- 剃刀找变量 → 贝叶斯定权重 → 万有理论给结构。
- **若贝叶斯排序最高的假说，恰恰需要最多的变量才能成立** → 说明剃刀没剃干净，回头再剃。
- **若统一框架推不出某个高概率假说** → 说明框架有洞。
- **若某结论无法被任何新证据改变** → 它退出了贝叶斯系统，是「信仰/立场」不是「分析」，要如实标注，不许伪装成推理结论。

校准口诀：**证据进来能不能更新？核心变量是不是秩？框架推不推得出结论？** 三条都通，结论才算立得住。

## 输出格式

按需结合三定律，但三条线都必须出现实质结论，不强迫固定模板。推荐：

```
【结论先行】一句话判断（秩变量 + 统一结构交汇出的核心）
【贝叶斯线】假说空间 → 先验 → 关键证据 → 后验（置信度）+ 翻转条件
【奥卡姆线】铺开的变量 → 剃掉什么 → 秩变量（为什么是它们、它们怎么定义坐标系）
【万有理论线】统一结构一句话 → 怎么推出下层解释 → 失效边界
【谦卑备注】事实/推断/猜测的边界、最大风险点、下一步最值得收集的一条证据
```

硬性要求：

- 结论必须带置信度（高/中/低 或百分比），并给预承诺的证伪条件。
- 区分「事实 / 推断 / 猜测」三层，分别标注，不得混淆。
- 简单问题可浓缩成几行，但三层不可省略——每层至少保留核心动作（假说排序 / 剃到秩变量 / 统一结构一句话）。

## 禁忌清单

1. ❌ 三层各写一句漂亮话就收尾——每层必须有实质动作。
2. ❌ 只报单一解释——贝叶斯退化成断言。
3. ❌ 剃刀层没有「删除」动作——那叫罗列不叫剃。
4. ❌ 统一靠「两边都对」——那是和稀泥不是统摄。
5. ❌ 结论不给置信度和证伪条件——退出贝叶斯系统的结论不可信。
6. ❌ 为显得深刻硬造公式——找不到就老实说缺口。
7. ❌ 在贝叶斯层堆「P(后验)=……」公式——用自然语言展示推理即可，禁止学术腔。
8. ❌ 不臆造证据——找不到的证据就说没有，不编造支持自己结论的「证据」。
