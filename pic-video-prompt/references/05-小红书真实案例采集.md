# 小红书真实案例采集办法（进阶可选）

要抓小红书站内真实爆款笔记（图文博主的日杂/名著写真提示词原文 + 轮播图），用这套经过实测的流程。源自 creator-distiller 的 `references/xiaohongshu.md`，这里浓缩成本 skill 直接可用的步骤。

## 前置条件

1. Node 18+，`playwright` 已装（脚本 `xhs_collect.js` 依赖）。
2. 用 `msedge` 渠道（微软 Edge），**必须 `headless: false`** —— 无头模式会触发 300012 IP 风险，页面直接空白。
3. **必须登录**。由用户在弹出浏览器里自己扫码，脚本只读登录态，不导出／记录／分享 Cookie。
4. 笔记详情**必须带 `xsec_token`**，否则 `/explore/<id>` 404「当前笔记暂时无法浏览」。

## 命令流（`xhs_collect.js` 位于 creator-distiller/scripts/）

```bash
export XHS_PROFILE="<绝对路径>/_xhs_profile"      # 登录态持久化目录

# 1）一次性扫码登录（有头窗口，用户自己扫）
node xhs_collect.js login "$XHS_PROFILE"

# 2）枚举某个博主主页的可见笔记 + 抓每条笔记的 xsec_token
node xhs_collect.js notes "https://www.xiaohongshu.com/user/profile/<uid>" notes.json 80

# 3）逐条抓详情（标题/正文提示词/轮播图/互动），可断点续跑
node xhs_collect.js details notes.json details.json 0 40

# 单抓一条（URL 要带 xsec_token）
node xhs_collect.js one "https://www.xiaohongshu.com/explore/<id>?xsec_token=..." one.json
```

## 搜索爆款笔记（找案例，而非只盯一个博主）

脚本本身没有搜索子命令。两种做法：

1. **登录态下直接开搜索页**：让脚本人肉在浏览器打开
   `https://www.xiaohongshu.com/search_result?keyword=<关键词>`（如 `日杂风 摄影`、`猴哥九连拍`、`圣黛cp`、`林黛玉 写真`），滚动后从结果卡片里捞 `a[href*="/explore/"]` 的笔记 id。
2. 拿到 id 后接 `one` 命令抓单条详情。

## 取数字段（别用 document.body.innerText）

详情正文读 `window.__INITIAL_STATE__.note.noteDetailMap[<id>].note`：

| 字段 | 内容 |
|------|------|
| `note.title` | 标题 |
| `note.desc` | 正文（图文博主整段提示词通常在这里，700–1000 字） |
| `note.imageList[].urlDefault` | 该笔记轮播图原图 |
| `note.interactInfo` | 赞 / 藏 / 评 / 分享 |
| `note.tagList` | 话题标签 |

## 图片下载

- `imageList[].urlDefault` 形如 `http(s)://sns-webpic-qc.xhscdn.com/...!nd_dft_wlteh_webp_3`。
- **带上 `!nd_dft_wlteh_webp_3` 后缀才能下**（去掉后缀取原图通常 403），约 1080×1440 webp。
- 请求头带 `Referer: https://www.xiaohongshu.com/`，否则可能被拒。
- 按 `<序号>_<风格名>.webp` 命名，跳过已存在文件以断点续跑。

## 笔记挂「文件附件」（作者常把完整提示词放附件里）

网页端不渲染附件，`__INITIAL_STATE__` 里也没有，走独立接口：

```
# 列附件
POST https://edith.xiaohongshu.com/api/sns/web/v2/widgets
body: {"note_id":"<id>","scene":"web","mode":1,"source":"web_feed","exp_flags":{"web_support_related_search":true}}
→ data.widgets.widget_list[] 里 biz_type=="web_related_file"，model.biz_extra 有 doc_id

# 换下载地址
GET https://edith.xiaohongshu.com/web_api/sns/v1/file/preview?doc_id=<doc_id>&note_id=<note_id>&need_note_interact_info=true
→ data.download_url（带水印原件）/ data.preview_pdf_url（转档 PDF）
```

这两个接口要带 `X-s`/`X-t` 签名头，页面自带 `window._webmsxyw(path, data)` 可算：

```js
const r = window._webmsxyw(path, data);   // POST 签 (path, body)；GET 签 (path+'?'+query, null)
return { 'X-s': r['X-s'], 'X-t': String(r['X-t']) };
```

坑：GET 只签 path 返回 406；不带签名裸请求返回 500 `create invoker failed`。

## 稳定性与边界

- 每条笔记之间停 5–8 秒随机抖动，别猛刷。
- 详情脚本检测到「安全验证/滑块/当前笔记暂时无法浏览」就**立即停止并落盘**，稍后重跑续传。
- 主页枚举只代表当前浏览器可见范围，不代表全部作品。
- 一次抓取建议 ≤ 150 条。
- 图片版权归原作者，本地归档仅供个人学习；生成分享包时只带方法卡、提示词文字与出处链接，不打图片本体。

## 本 skill 的建议用法

抓到真实案例后，回到 `04-圣黛CP与名著日杂案例库.md` 的「现成提示词共通结构」做分类提炼（主体/服饰/动作/环境/光线/色调/画幅/负面），把新角色的锚点补录进 `02-名著角色锚点库.md`，再按 SKILL.md 的七段公式反复迭代输出。
