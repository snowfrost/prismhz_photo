# 视频提示词规则

编写完整提示词时，使用以下五个主板块并保持顺序：

```text
【故事前提与资产绑定】
【画面质感与光影】
【镜头与动作时间线】
【对白、环境声与BGM】
【负面提示词】
```

整份成品提示词命名为 `final_video_prompt`。它是视频节点提示词输入框的唯一文本来源，必须在节点创建前完成，禁止节点代理二次生成或重新排版。

只允许以上五个顶级标题，每个标题各出现一次。禁止使用【素材职责】【人物】【视觉风格】【声音】【镜头】【正文】作为顶级标题；禁止先列一遍镜头摘要，再在正文中重复写同一批镜头。

先分别完成五个正文变量，再按以下方式机械拼装，不允许自由增加第六个板块：

```text
final_video_prompt =
【故事前提与资产绑定】 + story_asset_block
+ 【画面质感与光影】 + visual_light_block
+ 【镜头与动作时间线】 + detailed_timeline_block
+ 【对白、环境声与BGM】 + audio_block
+ 【负面提示词】 + negative_block
```

`detailed_timeline_block` 直接承载每个镜头的完整画面、动作、构图、运镜、结果与光线，不先输出五行镜头概要，也不另建【正文】。五个主板块之外只能出现【镜头01｜0秒—2秒｜……】一类时间线子标题。

## 0. 已确认分镜的继承

用户已经确认标准分镜时，分镜是完整视频提示词的直接依据。保留原镜号、镜头顺序、动作结果、对白、人物站位、道具状态、转场关系与已锁定资产，不擅自合并、删除或新增剪辑镜头。

横向分镜中的每一行代表视频内部的剪辑镜头，不等同于一次视频生成。总时长处于所选模型单次生成上限内时，全部剪辑镜头固定写入同一个视频生成段和同一个节点；10秒5镜头必须写成一份10秒完整提示词，其中【镜头与动作时间线】包含五个连续时间段。只有总时长超过模型上限、用户明确要求拆分，或所选模型明确不支持内部切镜时才建立多个生成段。

面向视频生成平台交付时，先完整执行 [平台工作流](platform-workflow.md) 中的视频生成段划分、提示词编写与视频节点配置规则。一份提示词只对应一个生成段和一个独立视频节点；同一生成段内可以包含多个连续剪辑镜头。多段项目的每份提示词都必须独立完整，不使用“同上一段”省略资产、场景、质感、声音或限制。

分镜中的视觉规范转换为【画面质感与光影】，人物、场景、道具和初始状态转换为【故事前提与资产绑定】，镜头行转换为【镜头与动作时间线】，对白与声音统一进入【对白、环境声与BGM】，当前生成段的高风险制作备注进入【负面提示词】或正文中的准确正向约束。

## 1. 故事前提与资产绑定

按照以下形式逐行绑定，只列出当前生成段真实使用的项目：

```text
总时长：时长、画幅、内部镜头数量、视频模型与当前核心事件；用户未指定模型时写2.5模型。

女主：@女主人物资产＝人物身份、年龄版本与当前服装。

父亲：@父亲人物资产＝人物身份、年龄版本与当前服装。

场景：@场景资产＝环境身份、当前时间与固定空间结构。

道具：@道具资产＝道具身份、初始持有人与准确位置。

初始关系：第一镜开始时的人物位置、姿态、朝向与道具状态。

故事核心：A → B → C → D
```

示例中的 `@资产名称` 必须替换为当前平台原生、可解析的资产引用实体。不得把普通文字“@名称”当成绑定；平台不支持 `@` 时，使用其原生图片占位符或参考资产字段。人物称谓和数量根据剧情确定，不输出空项目。资产已经锁定的面部、发型、体型和服装只作简短绑定。道具位置绑定明确人体部位或场景结构；场景写清入口、门窗、道路、车辆和人物活动区域中与本段剧情相关的空间关系。本板块不提前展开摄影、光影、逐镜动作和声音。

每个资产引用只在本板块的对应资产行出现一次。进入【镜头与动作时间线】后使用稳定角色名、场景名与道具名，不在每句话重复资产引用。

## 2. 画面质感与光影

固定写成两个连续自然段，不增加“摄影参数”与“光影规则”小标题。

第一段负责摄影参数与成像质感。根据用户指令、参考资产、剧情类型、时代、天气和场景材质，直接确定：

- 一台具体摄影机或一种确定成像方式；
- 一套统一镜头系统；
- 一种扩散滤镜及明确强度；
- 一个统一光圈与一种全片景深；
- 一种胶片模拟或色彩科学；
- 颗粒、自然动态模糊、边缘柔化、锐度、高光扩散和解析度取舍；
- 一句明确的最终成像结论。

第二段负责全片光影与色调规则。明确：

- 当前时间、天气与主光来源；
- 全局色温或白平衡基准；
- 光线进入方向、软硬、落点和衰减；
- 人物眼睛、鼻梁、颧骨、嘴唇、双手、发丝、衣料与核心道具的受光关系；
- 多人物镜头中的主要受光者、次要人物与背景人物层次；
- 墙面、地面、窗户、水面和布料中实际存在的反射补光；
- 主色、辅助色、强调色、肤色、高光色和暗部色的具体分布；
- 整体明度、冷暖、饱和度、反差、黑位和背景亮度；
- 同一场次的光源方向、曝光、肤色和背景明暗连续性。

所有参数直接选择一套明确方案。镜头运动由时间线按剧情确定，不放入本板块。

色温数值只在本板块的全局规则中出现，不在逐镜时间线重复。

用户要求柔焦时使用：

```text
主体合焦 + 光学扩散 + 高光泛光 + 微反差降低
```

五官仍然清楚，不把整张脸直接失焦。

## 3. 镜头与动作时间线

时间段相加必须等于总时长。不要平均切分，根据动作复杂度分配。

标题格式：

```text
【0秒–3秒｜景别与机位：核心剧情动作】
```

根据已确认分镜转写时保留源镜号：

```text
【镜头05｜本段0秒–3秒｜景别与机位：核心剧情动作】
```

每个镜头固定写成两个自然段，不使用三个小栏。

第一段按自然顺序写：

```text
摄影机位置、拍摄方向、景别与构图
→ 人物和道具初始状态
→ 触发原因
→ 一个主要动作的完整过程
→ 动作结果
→ 一至两个可见情绪反应
→ 必要环境动态
```

第二段以“光线：”开头，只写一句当前镜头光线。写清真实光源方向、光线软硬、当前人物或道具受光位置、多人物受光主次及背景明暗变化，不写色温数值。特殊光影写清实际可见的受光变化；普通自然光统一写“光线：延续本场自然光，曝光与背景亮度保持一致。”

镜头的初始状态、动作过程、动作结果与情绪反应全部融入第一自然段，不拆成“开始时：”“结束时：”“承接上一阶段：”三个说明块。声音不使用尖括号插入时间线，统一写入【对白、环境声与BGM】。

时间线正文采用正向描述，直接确定人物停留区域、运动方向、视线、背景状态和道具位置。时间线正文清除“不、没有、无、禁止、避免、不能、不得”等否定表达：使用“目光始终停留”替代“没有回避视线”，使用“父亲停留原位”替代“父亲没有上前”，使用“摄影机保持固定”替代“摄影机不跟拍”。负面限制集中写入【负面提示词】。

正反打、过肩、门内门外和多人调度镜头在第一段中补充：摄影机所在区域与朝向、前景人物或遮挡物、清晰主体、主体画面左右、视线方向、主体背后的固定空间锚点。正反打机位保持在动作轴线同一侧，人物画面左右和视线方向连续。两侧反打分别使用各自拍摄方向真实存在的墙面、门窗、家具和庭院结构。环境资产只定义一个方向时，采用靠近动作轴线的小角度反打，并继续使用资产中已经明确的空间结构。

### 动作

动作要有起点和结果，但不要逐帧编程。只保留影响因果、空间和情绪的信息。

正确：

```text
父亲听见门外通报后停下系玉佩的动作，回头看向府门，随后站起走向门外。
```

动作过多时拆分：停手回头、站起离开、上马、队伍启动分别承担独立镜头。

避免：

- 无意义的左脚支撑、转身角度和手指逐帧变化；
- 同一动作重复开始；
- 已经佩戴的道具被重新摘下再佩戴；
- 为了电影感增加无因果动作。

### 运镜

每镜只选择一种主要运镜：

- 安静观察、仪式与等待：固定镜头或极缓慢推进；
- 人物行走与空间展开：平稳跟拍或横移；
- 亲密、局促与主观感受：轻微手持呼吸感；
- 冲突、逃跑与失控：明显手持；
- 队伍完整运动：固定全景。

不要为所有镜头统一添加手持感，也不要在一个镜头中同时推进、环绕、升降和变焦。

### 人物表演

先确定视线对象，再从以下内容选择一至两个可见反应：

- 目光停留或移开；
- 眨眼速度；
- 嘴唇轻抿；
- 下颌收紧；
- 手指收紧或松开；
- 肩背和身体重心变化；
- 步速改变；
- 与道具互动。

不使用抽象的“很感动、很悲伤、很紧张”代替表演。呼吸只在屏息、剧烈运动、哭泣、寒冷、疲惫和明确释然时出现，同一段不反复使用。

### 信息揭示

关键人物、道具、误会与反转按剧情顺序出现。需要延迟揭示时，使用“当前画面聚焦于……”“背景保持为……”确定当前镜头的信息范围，具体排除项写入【负面提示词】。

### 空镜与环境动态

空镜只用于：

- 交代新空间；
- 表示明确时间变化；
- 承担必要情绪停顿；
- 连接无法直接切换的场次。

用户未要求时不主动增加。花瓣、风、雨、树影、窗帘和烛火保持低存在感，不遮挡面部、对白动作和核心道具。

## 4. 对白、环境声与BGM

按时间说明：

- 说话者与准确台词；
- 语气、音量与语速；
- 环境底声；
- 动作同步声音；
- BGM状态。

对白遵守：

- 用户锁定台词原样保留；
- 人物进入场景后再开始面对面对话；
- 一句只表达一个意思；
- 不用对白解释观众已经看见的动作；
- 不使用总结主题的文学台词；
- 台词时长计入镜头时间。

声音来源必须合理。要求真实士兵通报时，画面中出现真实士兵或明确标记为画外声音，不使用来源不明的墙面影子。

默认写“无背景音乐”，只保留自然环境和动作同步声音。用户明确要求BGM时，确定一种乐器组合、节奏、情绪和进入时间，不写备选。

BGM状态只在本板块出现一次。【负面提示词】结尾不再追加“No BGM”“No soundtrack”或其他英文重复状态。

## 5. 负面提示词

使用一段精简文字，只列出当前任务高概率且会破坏剧情的错误。优先顺序：

1. 身份、年龄和服装漂移；
2. 道具位置、结构和状态错误；
3. 人物朝向、左右位置和空间边界错误；
4. 背景人物重复、影子和虚影；
5. 动作顺序和运动方向错误；
6. 新增人物、对白和剧情；
7. 夸张表演、文字、水印、Logo和未要求的BGM。

负面提示词不能与正文矛盾，也不能代替正文中的准确位置和动作。

## 6. 提交前校验

确认：

- 五个标题齐全且顺序正确；
- 五个标题各出现一次，开头为【故事前提与资产绑定】，结尾板块为【负面提示词】；
- 不包含【素材职责】【人物】【视觉风格】【声音】【镜头】【正文】六个替代顶级标题；
- 五个正文变量已经按固定顺序机械拼装，没有第六个顶级板块；
- 故事核心因果清楚；
- 时间线总和正确；
- 每个镜头标题包含连续时间码，不使用只有“镜头1、镜头2”的无时间标题；
- 使用已确认分镜时，源镜号、顺序、动作、对白和资产完整继承；
- 每镜只有一个主要动作和一种主要运镜；
- 每镜使用两个自然段，第二段以“光线：”开头；
- 时间线正文使用正向描述；
- 时间线正文不含否定表达；
- 正反打和过肩镜头明确摄影机位置、前景主体、清晰主体、画面左右与固定后景；
- 人物和道具状态逐镜继承；
- 对白发生时间和说话者明确；
- 光线、天气和时间连续；
- 全局光影可以包含色温基准，逐镜光线句不包含色温数值；
- 多人物镜头明确当前主要受光者与次要人物层次；
- 首镜与结尾严格执行用户要求；
- 负面提示词针对当前高风险问题。
- 每个镜头承担不同的叙事信息或情绪变化，不重复堆叠通用旅拍动作；
- 未经用户确认不新增对白，不使用“好美啊”一类通用感叹填补镜头；
- 前期确认无对白时，全篇不出现人物台词；BGM状态只在声音板块写一次，不在提示词末尾重复添加英文状态；
- 景别、人物朝向、背景位置和景深关系不存在冲突；
- 不在时间线之外增加镜头概览或重复正文；
- 时间线内部没有“开始时”“结束时”“承接上一阶段”三个重复说明块，没有尖括号声音标记；
- 当前生成段实际使用的每项资产只在第一板块出现一次原生引用；支持 `@` 时引用必须是可识别的 `@资产` 实体，时间线只使用角色名；
- 已确认分镜对应的视频节点数量、生成段数量与提示词数量一致；
- 每个节点的模型、时长、画幅、资产绑定和提示词均与对应生成段一致，用户未指定模型时节点使用2.5模型；
- 总时长处于模型单次上限内时只有一个生成段、一份提示词和一个视频节点，全部剪辑镜头位于同一时间线；
- 节点创建循环按生成段执行，不按剪辑镜头执行；
- 节点已经保存到可生成状态，未在缺少明确授权时启动渲染。
