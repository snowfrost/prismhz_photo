# 场景与道具资产规则

本文件用于执行用户在项目前期选择的资产范围。人物资产完成后，只有选择“人物和场景”才生成场景资产，只有选择“人物和道具”才生成道具资产；选择“人物”时不建立额外图片节点。

## 1. 共同规则

- 没有参考图时，根据已经确认的剧情、画面风格、时间、天气与人物行动直接确定一种具体方案，不再次弹出风格选择；
- 已有参考图时，将其作为空间结构或道具外观依据，不照搬参考图中的无关人物、文字、水印与品牌；
- 每个资产先在节点外完成唯一完整提示词，再创建图片节点并原样写入；
- 图片节点写入后回读提示词和真实画幅参数，内容或比例不符时先覆盖修正，再开始生成；
- 所选资产全部生成并获得连续图片编号后，才能进入标准分镜。

## 2. 场景资产

10—15秒且发生在一个连续地点的剧情只建立一张核心场景资产。剧情明确包含互不相连的室内外地点时，每个核心地点各建立一张，不把不同地点拼进同一张图。

场景提示词固定包含：

```text
【场景身份】
【固定空间结构】
【时间、天气与光线】
【材质、色彩与成像】
【负面约束】
```

具体要求：

- 明确国家或地区、具体地点类型、时间、天气和季节；
- 写清入口、道路、湖岸、门窗、墙面、地面、主要家具、远景锚点和人物活动区域中实际存在的结构；
- 只保留剧情会使用的空间信息，所有方位和朝向做出唯一选择；
- 场景资产为空环境，不出现人物、动物、车辆或临时道具，除非它们属于不可分割的固定环境结构；
- 场景画幅使用 `project_video_aspect`，即用户确认的视频画幅；不得套用人物资产固定的16:9；
- 场景节点真实画幅必须与 `project_video_aspect` 完全一致。

```text
场景图像生成能力(
  prompt=scene_asset_prompt,
  title="【场景名】场景资产",
  tag="scene",
  aspect_ratio=project_video_aspect,
  参考资产=[已有场景参考图；没有时省略]
)
```

生成后将图片绑定为空间结构、环境材质、时间天气与光线参考。后续镜头可以改变机位和景别，但不能改变入口、道路、湖岸、门窗与固定家具的空间关系。

## 3. 道具资产

从剧情中选择真正参与人物动作或推动情节的一个核心道具。存在多个不可替代的核心道具时分别建立节点；装饰物、普通衣物和固定环境物件不单独生成。

道具提示词固定包含：

```text
【道具身份与用途】
【结构、材质与尺寸】
【固定道具资产构图】
【一致性要求】
【负面约束】
```

固定构图：横向1:1道具设定板，纯白无缝#ffffff背景；左上为正面，右上为完整侧面，左下为背面，右下为45度结构细节。四个视图属于同一个道具，结构、材质、颜色、磨损、尺寸比例和配件完全一致，画面中不出现人物和手。

```text
道具图像生成能力(
  prompt=prop_asset_prompt,
  title="【道具名】道具资产",
  tag="prop",
  aspect_ratio="1:1",
  参考资产=[已有道具参考图；没有时省略]
)
```

生成前必须明确道具的具体名称、用途、长度或直径、主体材质、准确颜色、连接结构、初始状态与一至两个识别细节。节点真实画幅固定1:1，不继承项目视频画幅。

## 4. 资产数量检查

```text
选择“人物” → 人物节点数量≥1，场景节点=0，道具节点=0
选择“人物和场景” → 人物节点数量≥1，核心场景节点数量≥1，道具节点=0
选择“人物和道具” → 人物节点数量≥1，核心道具节点数量≥1，场景节点=0
```

实际节点数量与所选资产范围不一致时，先补齐缺失资产，不进入分镜阶段。
