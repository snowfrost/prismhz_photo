## 十二、续写、修改与失败修复

已确认或效果良好的提示词作为母版。用户要求局部变化时，保留未受影响原文、人物、服装、镜序、时间、台词和限制，仅修改相关完整板块或镜头，并同步必要依赖。

续写以实际接受的结尾为准，确认姿态、朝向、视线、手、物品位置和环境状态。原计划中没有生成成功的动作，不算已完成。

| 问题 | 优先修复方向 |
|---|---|
| 人物呆板、像摆拍 | 补具体事务与注意力对象，减少固定笑容和无目的动作。 |
| 表情跳变、目光乱飘 | 写清刺激与视线目标，让少量可见变化从原状态连续发生。 |
| 动作顺序错误、接触不成立 | 补初始姿态、可达位置、接触和完成结果，删除隐含瞬移。 |
| 手不够用、道具消失或换手 | 锁定持有人、左右手、放置与交接，更新后续继承。 |
| 内容只有两件事、互动单调 | 在片段剪辑中增加不同生活信息，简单互动控制在一个合适镜头。 |
| 时间线太简略 | 补拍摄位置、构图、表演、动作结果和受光，保留事件本身的简短。 |
| 手持太稳、像商业广告 | 加强呼吸、步伐、跟随滞后与构图调整，保留自然现场光。 |
| 晃动和失焦盖住表演 | 调整缺陷发生时机与恢复，给关键反应及接触清晰观察窗口。 |
| 质感混乱、滤镜过重 | 保留一种影像体系，删除不相符的介质缺陷，恢复自然肤色。 |
| 新角色容貌不符合精致上镜目标 | 检查正向五官与整体选角目标，调整协调结构与眼神，不用负面词代替设计；既有身份不擅自替换。 |
| 肤色沉闷、面部发灰发黄 | 检查白平衡、曝光、主光与体积阴影，保留本人肤色，修正无依据的色偏与过暗。 |
| 穿搭老气、臃肿或不适合季节 | 重写季节、面料、版型、衣长、腰线与完整搭配，脸部身份保持不变。 |
| 人物资产缺失面部图 | 修正设定板构图与实际比例，保留身份与完整面部细节要求。 |
| 多镜头被拆成多节点 | 按实际模型上限重新组织生成段，把内部镜头写入同一节点。 |
| @资产无效、结构被重写 | 检查真实引用、实际输入框和回读内容，不能只修改展示文字。 |

只有文本时，说明检查的是文本风险，不声称看过成片。以用户提供的实际画面为事实依据，错误结果不作为必须继承的风格。修复不自动更换整套人物、摄影、场景或声音。

## 十四、交付前检查

1. 当前入口与用户请求一致；已知信息不重复问，尚未回答的关键选择没有被擅自越过。
2. 时长和镜头数量作为组合处理；连续节拍、剪辑镜头与生成段没有混淆。
3. 所选人物、场景、道具制作范围已落实，或准确说明实际功能未完成项。
4. 新建主角的审美目标与协调五官、健康肤色、妆发和自然比例落实；穿搭适合季节与活动、有完整搭配和清楚轮廓，既有身份保持。设定板包含完整三视图和独立面部细节，实际比例正确。
5. 内容符合单人日常主体，互动自然且有不同生活信息，不机械重复固定动作清单。
6. 时间覆盖完整，总和准确；动作与对白容得下，简单事件没有无意义拆镜。
7. 视线、表情、姿态、双手、物体接触和后续状态成立，关键表演能被看清。
8. 纯手持和DV成像统一，光源与肤色连续，没有电影式增稳、布光或过量故障堆叠。
9. 完整提示词五板块齐全，时间线有执行密度，每镜有独立光线段，声音与负面限制一致。
10. 平台操作依据实际功能；节点比例、模型、时长、资产引用与写入内容经过回读，没有把普通文字标记当作有效绑定。
11. 已生成、已配置、可生成与未完成的状态如实报告；局部修改保留未受影响母版。
