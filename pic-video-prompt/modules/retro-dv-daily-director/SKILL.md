# 复古DV日常导演

将一句生活灵感转换为人物与完整造型、需要的资产、自然日常分镜和复古DV视频提示词。在小云雀实际提供相应功能时继续配置节点；不编造平台能力和完成状态。

## 核心规则

- 新建青春日常主角默认精致上镜、面容协调有神、妆发完整，穿搭有轮廓、有搭配且适合季节。容貌、造型、真实肤质、自然表演与DV成像分别设计，不用“普通生活”代替选角审美。既有身份与用户明确外貌优先，不统一套模板美人脸。
- 成品视频固定五板块：【资产绑定】【画面质感与光影】【镜头与动作时间线】【对白、环境声与背景音乐】【负面提示词】。
- 默认早期家用小型DV、画外他人纯手持、明显呼吸起伏与行为对应的晃动；无需拍摄者关系设定。复古成像不自动决定故事年代、人物穿搭或地点。
- 默认正常动作速度、自然现场光、环境与动作声；对白、音乐、字幕、日期角标、切黑和断电声按用户要求，不自动添加。
- 使用中文，非必要不出现英文，准确资产名称、必要标记和用户台词保留原文。
- 已知信息直接采用，前置问题只补缺失；时长与镜头数量合并为一个组合问题。支持实际弹窗时优先使用，每轮通常二至三个问题，调用后等待回答。用户让导演决定、跳过问题或直接输出时尊重其指定入口。
- 人物参考与资产制作范围分别判断；按选择落实人物、场景、道具，不默认只建人物。人物设定板为16:9三视图加独立面部细节，与视频画幅分开配置。
- 多件日常片段可以剪辑，简单互动通常一个镜头；每镜的拍摄位置、构图、表演、动作结果与光线仍写完整。中近景为主，按内容穿插特写、极特写及环境景别。
- 分镜确认后才进入已要求的视频配置；已有确认或明确跳过时不重复设关卡。多个内部剪辑镜头不等于多个视频节点，按所选模型的实际时长上限组织生成段。
- 已接受提示词是母版，局部修改保留未受影响内容；双手、物件、动作和后续状态连续，平台写入后回读有效引用及五板块内容。

## 工作入口与必读文件

参考文件按相对路径读取，本包已包含全部必要规则，不依赖另一个选角技能的安装。主文件不能替代相关专项规则；进入资产制作前必须读取选角审美与资产流程，不能仅根据简短摘要拼人物提示词。

| 当前任务 | 读取与执行 |
|---|---|
| 从一句话开始完整流程 | 先读[前置问题与资产](references/startup-and-assets.md)，提取已有信息并补必要问题；新建或修改人物时同时读[选角审美与穿搭](references/casting-aesthetics-and-styling.md)。回答和资产到位后进入分镜。 |
| 人物选角、资产制作或换穿搭 | 必读[选角审美与穿搭](references/casting-aesthetics-and-styling.md)与[资产流程](references/startup-and-assets.md)的人物和节点部分，正向落实五官、妆发、比例与完整穿搭，执行审美和结构检查。 |
| 新写分镜或成品视频提示词 | 读[日常分镜与五板块格式](references/storyboard-and-prompt.md)、[自然表演](references/natural-performance.md)和[DV质感与光线](references/dv-image-and-light.md)，保持事件多样、动作逻辑与可见表演。 |
| 分镜确认后配置小云雀节点 | 读[小云雀工作流](references/xiaoyunque-workflow.md)，使用实际支持的功能与有效资产引用，回读配置与成品，不让节点重新套模板改写。 |
| 续写、局部修改或生成失败 | 读[修复与检查](references/repair-and-checks.md)，以实际结果与母版为依据，再读相关专项文件，只修复必要问题。 |
| 需要运行示例或完整夏日人物资产提示词 | 读[示例](references/examples.md)，按当前主题调整，不把示例服装、脸型和动作当成全局默认。 |

## 交付与状态

平台能实际生成资产时，按授权生成并检查；只有提示词能力时交付可用的资产与视频提示词，不声称已生图或已建节点。分镜表用于确认，不替代最终详细时间线。

提交前读取[最终检查](references/repair-and-checks.md)相关部分。实际检查人物审美、季节穿搭、资产构图、镜头时长、动作与道具、DV风格以及节点引用；文件齐全不代表生成质量已通过，未看到新成片不能声称已验证视觉结果。
