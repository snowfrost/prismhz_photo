# 原生提示词编译

## 先锁一个画面

内部合同至少有：`ratio / subject_count / framing / position / gaze / one_action / prop_ownership / contact / depth / light_map / materials`。空景无需 gaze；远景不强求脸部细节。不要把这个表强制展示给普通用户。

用户一句话缺少细节时自行补足合理关系。用户指定构图、人数、年龄、衣色或动作时原样尊重。用户同时提出不能兼容的要求，如“小于画高十分之一的全身”和“眼神特写”，先给可行拆镜思路；不能把两者硬塞进一个画面。用户只要求方向时不继续执行提示词。

## Midjourney 英文

顺序：

1. **景别及分布**：`A shoulder-up three-quarter close-up places ... on the right ...`；全身则明确脚与地面，空景明确无人。
2. **可见人物**：年龄、轮廓、衣领层次、发型，避免只写 attractive / beautiful。
3. **一瞬间的动作**：哪只手握什么、眼睛看哪里、刀剑归谁、接触或间隙。
4. **三层空间**：只保留必要前景、主体和背景；不为三层强塞杂物。
5. **光色和实物**：暖光落在哪，冷色在哪，布、木、纸、钢怎样反光。
6. **摄影收束**：一句真人武侠电影剧照、微颗粒、柔高光、摄影景深即可。
7. **参数尾部**：比例、必要排除词、用户明确要求的配置；最后是 `--v 8.2`。

一般约 90–150 个英文单词足够；短场景可更短，复杂关系可更长，不为了字数填充“masterpiece / 8k / ultra detailed”。不要把名称标签当成构图描述。

### 两种参数模式

**通用文字模式（默认）**：

`... --ar 16:9 --no painting, illustration, plastic, text, watermark --v 8.2`

空景按需要加入 people、animals；有人的画面绝不加入 people。特定比例替换 16:9。默认不添加 profile、sref、seed、hd、raw、chaos 或 stylize；这代表减少未说明的外部依赖，不代表已证明默认参数效果优于原配置。必要时可建议一次只改变一个参数做对照测试。

**继承本期原配置（用户明确要求时）**：

`... --no painting, illustration, plastic, text, watermark --chaos 3 --ar 16:9 --raw --profile z4yrncu --hd --v 8.2`

说明该 profile 来自原图，是否可在别的账号使用需实际确认。若用户要“完全照第09张参数”，应从 `source-evidence.json` 读取该条：它有 `--stylize 400`，没有 `--no`。不要把第09张的特殊参数传播到全部新图。若用户只要“原 profile”，仅加 profile；其余仍按通用模式，区分授权范围。

用户自带 profile / seed / 可用参考地址时精确使用，不补造。若给出不能直接用于 MJ 的本地路径，提示先上传并取得平台可用引用；不要把附件路径伪装成 URL。图像内容参考与风格参考用途不同，不默认将同一张图当作人物身份锁定器。

## ImageGen 原生中文

以“横向16:9／竖向3:4，真人武侠电影剧照”开头，按画面观看顺序安排句子：主体位置和身体范围 → 动作与道具接触 → 近远层次 → 光色落点 → 质感与必要排除。

适合直接写：“右手握住木碗，碗沿停在下唇以下，两只眼睛完整露出。”不要说“使用肩上三分之四tracking”等杂糅句。

中文保留与英文相同的事实，但允许重新组合句子。所有 MJ 参数、个人配置、参考地址占位符都不出现在中文正文中。结尾用自然语言写少量针对性的避免事项。

## 负面约束

使用两层：

- 风格排除：painting / illustration / plastic skin / text / watermark，按需要选；不用漫长的通用黑名单。
- 场景排除：骑马排除缰绳与手粘连、额外腰侧兵器；双剑排除多余剑刃与交融持握；徒手排除刀剑和法术光波；空景排除人和动物。

空间关系先在正面写清，负面词是辅助。不要依赖 `--no extra swords` 来代替“每人一把剑”；不要用笼统 `--no blur` 误删背景运动；不要排除用户要求的雪、花瓣或遮挡。单独列出的 `negative_zh / negative_en` 是新建议；要进入 MJ 执行的词必须实际写进 `--no`，不能声称展示在旁边就会生效。

## 改比例和扩组

- 16:9：用左右位置、视线空间、横向风向和前后景深构图。
- 3:4 / 9:16：重新安排头部、手、道具的纵向层级；双人可前后错位，保留可辨脸与动作。若用户锁定左右对称对峙，改成较小的左右双人并增加上下环境，不擅自替换成错位。
- 大远景：开头直接给环境主体、人物在远处的相对大小、可见落脚点。不要再写可见睫毛、面部大特写。
- 同一风格组图：场景独立成立，共用材质和光学语法；不通过反复使用“same woman”来假装身份已锁定。
- 新年龄和性别：同步调整发型、面部自然纹理、服饰尺度与动作，不让“年轻女侠”默认值覆盖输入。不是把老者写成少女后再追加 elderly。

## 最小修复

先指出一处真实偏差 → 找到造成偏差的构图/接触约束 → 修改这一小段 → 其余已接受的提示词保持原文。给出“需再生成检验”的明确边界，不靠重写整段、更换风格或追加几十个禁止词掩盖问题。
