# 参数、输出和来源

## 默认 profile 的优先级

1. 用户明确“关闭风格码／不要情绪板／纯文字版”：本条不使用 profile，正文补足风格；提醒一句同时关闭网页可能开启的自动 Personalization。
2. 用户明确给替代 profile：只用指定的新值，不与默认码叠加。
3. 其余调用：每条 MJ 自动附带 `--profile e1u2l58`。包括首次调用、没有参考图、只改比例、验证一张、组图和修复。

默认参数尾部为 `--ar 16:9 --profile e1u2l58 --v 8.2`。负面参数放在它前面；其他比例替换 `16:9`；显式选定其他模型版本时使用该版本并核实兼容性。不要追加并非用户要求的 `--hd`、`--chaos`、种子或 sref。

## 代码来源

- 用户明确提供 `--profile e1u2l58`，要求打包并为其他调用者自动附加。
- 随包九条实际 PNG 提示词也都记录了该代码。
- 旧方案的 `--p m7499435492987895834` 仅是历史来源，当前默认已由用户确定为 `e1u2l58`，不自动退回旧码。
- 原图还有 `--raw --chaos 3 --hd` 等记录；它们保留在历史样本中，默认新提示词仅继承本 Skill 明确设定的参数。
- 这里只保证提示词带上用户指定的参数，没有验证其他账号能否访问该 profile。若 MJ 报无权限或无效，说明实际错误，保留已写正文，按用户选择换码或提供纯文字版本；不要编造替代码。

## 每张默认输出

1. 标题与一行构图。
2. 英文 MJ 完整代码块，含实际采用的 `--no` 和完整参数。
3. 中文释义，说明同一个画面。
4. 中英文针对性负面约束：已加入 `--no` 的内容标注“已加入”；尚未加入的修复候选标注“补充建议”。不要重复给互相矛盾的版本。

用户只要英文时只给英文；组图每张独立可复制。不要用中文释义冒充原生 ImageGen。

## ImageGen 可选输出

把同一画面重新组织成中文：横纵画幅、人数、人物大小、左右位置、视线、手和道具、环境、光色、保持和排除的细节。没有 `--profile`、`--ar` 等 MJ 后缀；无法通过文字承诺等效使用此 MJ profile。

## 证据标签

- `actual_mj_prompt`：历史 PNG 记录，移除 Job ID 后保留原文。
- `translation_zh`：该历史英文的中文翻译。
- `observed_zh` / `deviation_zh`：成图观察与原词差异。
- `suggested_negative_*`：当时按画面整理的补充词，未证明用于原始生成。
- examples.md：本 Skill 新写的教学示例，没有新一轮 MJ 或 ImageGen 成图。

文本格式测试、目录校验、压缩包校验都不证明画面准确、人物同脸或 profile 跨账号可用。
