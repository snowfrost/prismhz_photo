# 视觉规则

## 风格依据

这是从用户的日式校园成图提炼的青春电影视觉方案。它描述这套作品的特点，不把所有岩井俊二电影归结为一个配色，也不把 AI 画面称作真实电影剧照。

## 可迁移的规则

| 维度 | 画面决策 | 随场景调整 |
|---|---|---|
| 冷暖 | 深橄榄绿环境、冷青阴影；自然暖肤色、奶白衣物形成焦点 | 换冬天、海边或夜间时保留冷暖关系，不给所有实物染绿 |
| 光线 | 自然窗光、侧光、后侧光照到脸部局部、发丝或手中物件 | 让光源符合地点和时段；雨天使用柔和天光，夜晚使用具体灯光 |
| 明暗 | 高光柔和扩散，暗部有层次；人物表情可读 | 避免把低对比写成整张泛灰，也避免大片死黑 |
| 肤质 | 自然皮肤与柔润白布；极轻的颗粒 | 不强加磨皮、蜡感或颗粒层；不宣称真实胶片或某镜头拍摄 |
| 空间 | 门框、桌沿、窗帘、扶手适量构成前后层次 | 遮挡服务于观看位置，不挡住关键眼神和道具 |
| 动作 | 手停在工作中、回头等一下、笑意刚出现 | 单帧选择一个主动作，不堆“奔跑、递物、转身、拥抱” |
| 表情 | 对当前事件的自然反应：期待、疑问、忍笑、专心 | 不把每张都写成看镜头微笑，也不要求人物总是忧郁 |

## 画面里的情绪如何成立

- 距离：一臂之内能看到停顿的手，几步之外可以看到她身边留出的位置。
- 视线：指明目光落点；“她喜欢你”要转化成眼睛先转向观看者、或抬头等待回应等可见事件。
- 道具：递纸星时，纸星仍在她掌上，另一只手尚未接触；不要用悬空物件表达动作。
- 时间：风只在发丝、窗帘或衣角留下有限变化；动作最重要的部位可读。
- 留白：空位、走廊和窗边可支持等待。保留人物大小，不自动改成贴脸特写。

## 角色和适用范围

可用于日式校园、大学、通学街道、车站、河堤、书店和普通生活空间；明确的新人物、年龄、关系、服装和地点优先。默认人物关系温和日常。用户要求空景时，只保留环境、光线和时间感。

“长发女生＋短发阳光男生”是当前系列预设。“第一视角”是可选镜头方法。这两项都不构成所有新画面的强制题材。
