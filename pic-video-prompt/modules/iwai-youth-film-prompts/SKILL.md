# 岩井俊二 · 青春情愫提示词

把一句新场景写成带有自然光、含蓄人物关系和日常空间的青春电影画面。风格依据是随包的用户成图与实际提示词；人物、地点、年龄和季节按新请求变化。

## 默认配置：每一条 MJ 都自动带上

**本 Skill 的默认 MJ 风格配置是 `--profile e1u2l58`。用户已经指定将它分享给调用本 Skill 的人，无需再次索取代码或询问是否启用。**

默认后缀：

```text
--ar 16:9 --profile e1u2l58 --v 8.2
```

- 单张、验证图、扩写、改稿和组图中的**每一条完整 MJ 提示词**均包含一次 `--profile e1u2l58`，并以版本参数结束。不能只在说明中给代码，也不能写“其余沿用”。
- 用户明确要求关闭情绪板、不要个人风格码或纯文字版时：移除 `--profile` / `--p`，用文字补全光色和空间。用户明确提供替代代码时：只用替代代码。只改场景、人数、比例、负面词或要求简短，继续保留默认代码。
- 代码是 MJ 的 profile 配置，不能改写成 `--sref e1u2l58`。不叠加旧编号 `m7499435492987895834`；它与当前代码没有已确认的等价关系。
- 默认比例 16:9。用户指定其他比例时重新安排画面，再改比例参数；提示词卡片的 3:4 不自动改变生图比例。
- 项目约定版本为 8.2，用户明确另选版本时依其要求。默认不附加 `--hd`、`--chaos`、种子或额外参考。详见 [参数与来源](references/profile-and-output.md)。

## 用户会得到什么

一句普通想法：给一行构图说明、完整 MJ 英文提示词、中文释义及针对画面的中英文负面约束。只要英文或只要一条时按要求精简，保留完整后缀。

指定数量就逐条给足。只说“一组”时可说明默认四张并执行。要求“先给思路”则只交付构思。未要求生图时只写提示词。

需要 ImageGen 时，另写原生中文，明确人数、位置、动作和光源，不带 MJ 参数；MJ 中文释义不冒充 ImageGen 提示词。只有 MJ 的用户成图作为当前验证依据。

## 创作顺序

先读 [视觉规则](references/visual-dna.md)。根据任务读 [镜头与组图](references/shot-recipes.md)，需要完整写法时看 [示例](references/examples.md)。

1. 明确人物数量、身份、观看者位置、比例、景别、人物占画面大小、视线和一个主要动作。缺少普通创作细节可补充；用户已给定的设定优先。
2. 选择模式：第一视角／双人相处／单人与环境。新场景不强加固定女主、制服或连续剧情。
3. 安排可读的动作与道具关系、前中后景，再确定真实可解释的主光方向和冷暖关系。
4. MJ 正文顺序：机位与景别 → 人物位置与可见特征 → 动作、视线与接触点 → 环境 → 光色、质感 → 必要负面词 → 参数。
5. 最终核对人物和空间，检查每一条 MJ 的默认 profile。需要可靠拼接时使用下面的辅助脚本。

## 三种模式

- **他眼中的她**：镜头是画面外男生的视点。明确他坐着、站着或位于台阶下；女生的视线可以回应他，也可以落在手中物件。第一视角不等于自拍或第三人称过肩。只在动作需要时让观看者的一只手进入前景。
- **两个人的青春**：为两个人分别安排位置、朝向和动作。日常的等待、共同任务或错开的目光都可以形成关系。新请求指定两位男性、朋友或其他关系时完整保留。
- **青春片段**：单人与环境、背影、人物较小的远景，以及用户要求的空景。留白承载等待；空景删除所有面部、肤色和人物动作残留。

《他眼中的她》人物预设为长发女生、白色短袖水手服、海军蓝领口和裙装；男生短发、阳光型，第一视角通常不露脸。仅在用户调用这个系列或要求同一人物时沿用。描述连续性不保证生成结果同脸。

## 修复与检查

收到新成图时先看实际画面，按景别、人数、视线、动作接触、发长、光色与噪点定位偏差，参考 [修复表](references/drift-repair.md)。修复一处时保留其他已确认部分。

- 远景与全身不要同时要求脸占大部分画面；白衬衫高光柔和，暗部仍有层次。
- 颗粒极轻，氛围优先通过光线、颜色与空间体现。不要把风格写成全画面模糊或强磨皮。
- 负面词按场景编写；双人图不禁止所有人物，递物图不禁止手。补充负面建议与原始生成记录分别标注。
- 每一条默认 MJ 都有且只有一次 `--profile e1u2l58`。ImageGen 正文没有 MJ 参数。
- 文本校验不代表新图已生成、跨账号可用或画面准确；实际图像仍需生成后检查。

## 可选的后缀辅助脚本

脚本仅处理本地文字，不调用 MJ，也不产生图片；只需 Python 3 标准库。

```text
python scripts/finalize_mj.py --input prompt.txt --output ready.txt
python scripts/finalize_mj.py --input prompt.txt --output ready.txt --ratio 3:4
python scripts/finalize_mj.py --input prompt.txt --output ready.txt --no-profile
python scripts/finalize_mj.py --input prompt.txt --output ready.txt --profile 用户指定的新代码
```

每个输入文件是一条英文提示词，不含 Markdown 围栏。脚本可补默认后缀、归一化相同 profile、去重；遇到不同历史代码会要求调用者明确选择，避免静默混用。正文中的已有其他参数原样保留。

历史来源在 [source-evidence.json](references/source-evidence.json)。其中 `actual_mj_prompt` 是实际记录，`suggested_negative_*` 是后补建议；三个原始参考 PNG 保持字节不变，路径可在记录中找到。
