# 岩井俊二 · 青春情愫提示词 Skill

## 安装

解压后把整个 `iwai-youth-film-prompts` 文件夹复制到所用工具的用户级 skills 目录，保留 `SKILL.md`、`agents`、`references` 和 `scripts` 的相对结构。Codex 使用已配置的 `$CODEX_HOME/skills`；未另设时通常是用户目录下的 `.codex/skills`。不要只复制 SKILL.md。

本压缩包提供完整 Skill，不包含其他账号的登录信息。制作时仅进行本地封装与隔离目录检查，没有替收件人写入其全局目录。

## 调用

```text
使用 $iwai-youth-film-prompts，给我一张16:9画面：放学后，她在车站等我，发现我来了就笑起来。
```

```text
使用 $iwai-youth-film-prompts，做六张“他眼中的她”，先给构思。
```

```text
使用 $iwai-youth-film-prompts，两个男大学生坐在河边聊天，3:4，只要MJ英文。
```

默认每条 MJ 提示词自动包含 `--profile e1u2l58`，无需重复提供。默认生图比例是 16:9，用户可更改。若只要纯文字版，请明确说“不要风格码”；若更换配置，请明确提供新 profile。

需要 ImageGen 时明确提出，Skill 会另写原生中文提示词。MJ profile 只属于 MJ，不能放进 ImageGen。

## 参数辅助

辅助脚本只做后缀拼接，需要 Python 3，不依赖第三方库。正常用 Skill 写提示词不要求用户手动运行脚本。可选命令见 SKILL.md。

## 验证范围

九条历史 MJ 提示词、观察记录和三张原始参考 PNG 来自这套用户作品；新示例用于说明写法。目录、后缀脚本和压缩包通过检查不代表新画面已生成，也不证明该 profile 对所有账号可访问。若平台报代码不可用，保留提示词正文并核对账号访问或换用明确要求的纯文字版。
