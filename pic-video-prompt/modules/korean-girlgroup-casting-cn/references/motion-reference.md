# 视频与灰度动作参考迁移

用户提供视频、灰度或深度参考并要求借鉴时，先明确参考的职责：动作、摄影机路径、构图、空间关系、切镜节奏，或其中几项。只借鉴气质时不锁定全部分镜；明确复现时才沿用指定的镜头顺序、人物数量、相对位置、动作轨迹、遮挡与切镜时机。

人物面容和当前造型来自已确认资产，场景与道具来自当前项目参考。动作参考不自动覆盖人物身份、服装、背景或音轨，也不把灰度图像、技术输入的黑帧或原片画面直接拼入新镜头。

## 迁移步骤

1. 说明每份参考负责哪些内容，以及哪些内容需要替换。沿用用户已有资产标识，逐一核对人物映射，避免编号、图中位置与服装描述交叉。
2. 能实际查看参考时，按可见内容分析动作起止、人物重心、摄影机运动与空间关系。不能查看时，只依据用户提供的描述，不声称已经识别原片镜头或精确时间点。
3. 保留用户指定的动作和镜头关系，绑定目标人物、造型、场景与道具。参考中的帽子、动物、武器、伴舞等只有被用户选用时才进入目标设定。
4. 动作依赖目标资产没有的道具或空间结构时，指出需要补充的资产；允许自由改编时可替换为同方向、同节奏的可执行动作，并说明替换。严格复现模式下不擅自新增道具或改变关键动作。
5. 用户要求重分配时长时，在已知参考时码与目标时长基础上调整，核对动作是否仍能自然完成；不将比例缩放当作动作可执行性的保证。

开口演唱与静音补充镜头按用户当前音频要求处理，不继承动作参考音轨。运镜和动作已有明确参考时，不再同时要求自由重排全部镜头。收尾是否切黑、保留动作或淡出，以当前任务为准。
