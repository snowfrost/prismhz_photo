# 旅行纪念票根 · 建筑照片 → 手账风票券

给一张建筑照片，先看出这栋楼什么气质，再决定背景怎么搭，出来一张能拿在手里的旅行纪念票。全程统一**线描淡彩插画语言**与**票券结构逻辑**。

适用模型：中文长自然语言系（GPT Image 2 图生图 / 即梦 Seedance 图生图），整段投喂，无需 JSON。

## 核心机制：先读气质，再分两路

拿到建筑照片第一步**判断场景属性与气质**，据此定背景路线（这是本 skill 的灵魂，不是票根版式）：

| 气质判断 | 场景举例 | 背景路线 |
|------|----------|----------|
| 松弛、度假感 | 海滨度假建筑、海岸景观、休闲酒店 | **A 沉浸式融合** |
| 正式、有纪念感 | 历史地标、规整公共建筑 | **B 海报式悬浮** |

- **A 沉浸式融合**：票根近乎撑满横向空间，背景与插画贯通、元素延伸出边缘；雾蓝／浅杏／奶油白打底，加淡墨水浪与落日圆，海浪天光从边缘过渡进插画。
- **B 海报式悬浮**：票根独立悬浮居中、占核心面积；背景抽象几何拼贴，浅象牙白纸纹打底，叠 2–3 块大尺度柔边色块错落四周，配低对比光斑与邮戳暗纹，四周留足白。

## 工作流程

1. **读图判气质**：用户给建筑照片，先看图（本机直接读，不外送），判断松弛/正式，定 A/B 路。
2. **组装提示词**：从 `references/01-提示词模板与三个坑.md` 取整段模板，选定背景路线，按坑 1/2/3 修正负向清单（水上场景必须做「水面改写」）。
3. **补右侧信息区实文**：地名、副标、日期、标语向用户确认或按照片自拟；编号自拟 4-6 位数字。
4. **图生图锁建筑**：照片作参考图，提示词开头加锁图句「Keep the architectural structure, proportions and key details of the building in the reference photo completely unchanged」。
5. **交付与迭代**：整段提示词交用户投喂生图；不满意时优先微调负向清单与背景路线，不推翻重写。

## 铁律

0. 本 skill 只出提示词；生图调用遵循用户最高优先级规则（图像生成走「提示词→确认→调用」流程）。
1. **先判气质再动笔**，A/B 路选错整张味道就不对（度假酒店配海报式悬浮会僵，纪念地标配沉浸式融合会飘）。
2. **三个坑必查**（负向清单写死 / 海景禁水改写水面 / 云上限12%+夜景淡彩化），完整写法见 `references/01-提示词模板与三个坑.md`。
3. 识图只用本机读图，禁止外送图片到第三方 API。
