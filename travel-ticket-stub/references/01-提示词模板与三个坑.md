## 二、三个坑（血泪换来的，组装提示词前必查）

### 坑 1：负向清单必须写死

不写，模型会自己塞汽车、喷泉、路灯、空调外机。陆上场景标准负向：

> 负向：汽车、喷泉、路灯、空调外机等一切现代街道设施；车辆、水体、路牌、电线逐项禁掉；多图拼接、网格排布、透视样机。

### 坑 2：海景/江景要把「禁止水体」反过来写

主题自带水，禁水会打架（模型不知道该画不画水面）。**不禁水，主动描述水面**：

> 水面：浅蓝绿与雾蓝平涂、留五到七道柔波纹线；只禁船和浪花。

同时把负向清单里的「水体」一条**删掉**，否则自相矛盾，模型容易直接不画水或画成怪异干地。

### 坑 3：云给上限，夜景给反向约束

- 光写「柔边团状白云」→ 它会画满厚云。必须写死：**「云面积不超过画面 12%」**。
- 夜景别硬写夜色：模型会往深夜蓝黑里堆色，淡彩感全毁。把夜色翻译成淡彩语言——**月亮改「柔边淡金圆月」**，并明写**「这是清淡明亮的水彩写生」**。

## 三、快速修正速查

| 症状 | 修法 |
|------|------|
| 画面出现汽车/喷泉/电线 | 坑 1 负向没写全，逐项补 |
| 海景票根没有水/水很怪 | 坑 2：删负向「水体」+ 主动写水面五到七道柔波纹 |
| 天空全是厚云 | 坑 3：加「云面积不超过画面 12%」 |
| 夜景黑成一团 | 坑 3：淡金圆月 + 「清淡明亮的水彩写生」 |
| 建筑走形不像原照片 | 检查锁图句是否在最前 + 参考图清晰度 |
| A/B 路味道不对 | 回 SKILL.md 气质判定表重判 |
