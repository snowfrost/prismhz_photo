## 二、直接 curl 会被 403，必须走浏览器通道

- `curl` 抓 `movie.douban.com` → 返回「加载中」反爬页；加 `bid` cookie 后 → **403**
- 豆瓣图片域名 `img*.doubanio.com` 在 shell 里 curl 直接 `http=000`（连不通）
- **可行方案**：用已装的 playwright + msedge（有头），页面能正常渲染，图片能正常加载

## 三、可复用脚本（放在工作区 04_temp，可复制到别处）

### 1) 列图 + 下载：`db_download.js`
```bash
node db_download.js <albumUrl> <outDir> <count> [profileDir]
```
要点：
- 打开页面 → 滚动 6 次触发懒加载 → 抽取 `img[src*="doubanio.com"]` 里的 `p\d+` 图片 ID
- 页码尺寸：缩略图是 `/view/photo/sqxs/public/pXXX.webp`，**换 `sqxs` → `l` 才是大图**（`raw` 更大）
- 下载必须经 `ctx.request.get`（浏览器网络栈），**且必须带 `Referer: https://movie.douban.com/`**，否则 403
- 建议 4 个图片域名轮询：img1 / img2 / img3 / img9
- 首次运行会生成 `_db_profile` 持久化目录，后续复用无需重新点击

### 2) 搜索 ID：`db_search.js`
```bash
node db_search.js "西游记" ./_db_profile
```

## 四、选脸标准（关键，选错脸等于白做）

从下载的剧照里筛出可用参考脸，逐张过识图端点判定，标准四条：
1. **本人在画面里**（拿不准先用识图反问「画面里有 XXX 吗」）
2. **单人出镜**最好；多人合影可用，但脸要够大够清晰
3. **脸部正面或近正面**，侧脸/背身/大笑扭曲不适合
4. **戏装造型**（不是演员生活照）

⚠️ 实测坑：抓「三国演义」关键词的图混进了红楼演员；某豆瓣 ID 一抓是《赵氏孤儿》。**每次下载前先用识图确认 1-2 张，认定剧集无误再批量。**

**已被证伪、禁止再用的错误素材**（2026-09-19 实测踩坑）：
- ❌ 某「孙悟空」参考图实为**蜘蛛精水中嬉戏群像**，画面里根本没有猴哥 → 图生图直接失效
- ❌ 某「孙悟空」参考图实为**师徒四人合影**，猴哥挤在最右侧且脸极小 → 锁不住脸
- ❌ 白裙执扇的林黛玉图，**扇子挡住半张脸** → 不适合做参考脸

⚠️ **教训**：图生图的参考脸只要「画面里没有目标人物」或「人物太小/被遮挡」，模型就会自由发挥，产出和原版毫无关系的通用脸。**归档前必须逐张识图确认「有本人 + 单人/脸够大 + 正面」三条全过。**

### 批量识图筛脸脚本（可复用）

`04_temp/scan_db.py`：
```bash
python scan_db.py <图片目录> "<目标人物+剧集+演员>" <输出txt>
```
逐个调 `rhart-text-g-3-flash-preview/image-to-text`，输出 `文件名 | 有无本人+是否单人+脸部朝向`。40 张约 5 分钟，¥0.4。跑完 grep「有XXX」直接锁定候选。

## 七、其它可用源（豆瓣之外的备选）

| 源 | 特点 |
|---|---|
| 搜狐文章（itc.cn 图链） | curl 可直下，`/q_70/` 去掉即高清；纪念类文章常有大张单人剧照（张飞的脸就是这么拿到的） |

| 美篇 / 今日头条 | JS 懒加载，抓不到直链，不推荐 |
