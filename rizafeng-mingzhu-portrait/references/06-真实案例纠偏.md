# 06-真实案例纠偏（小红书三案例 2026-09-13 实测）

> 本文件是 skill 的一次重大认知纠偏。之前把「日杂风」理解成「给角色换现代日系少男少女穿搭 + 低饱和清新滤镜」，导致角色丢了原版神装、风格跑偏，被用户指出「角色完全不像、风格完全错」。下面是三条真实小红书爆款案例的正确范式，已通过 RunningHub 识图逐张核对。

## 一句话纠偏

**角色戏装 100% 保留原版剧集造型，日杂/杂志感体现在「场景年代反差 + 怀旧胶片色调 + 电影海报/杂志排版 + 荒诞记忆道具」上，绝不是给角色换现代衣服。**

## 铁律更新（覆盖旧写法）

- 旧（错）：日杂化改造只动「穿搭」，保留一件标志性元素。
- 新（对）：**神装保留，动的是场景和时代。** 四部剧的标志造型一件都不能换——
  - 悟空 = 凤翅紫金冠（珍珠+红绒球）+ 红底金纹戏铠 + 胸前护心镜 + 额间紧箍咒 + 黄红绸带 + 现实猿猴脸金毛（86 版）
  - 黛玉 = 淡蓝白对襟襦裙 + 唐宋发髻 + 白花发簪 + 金属步摇 + 玉镯玉坠耳环（87 版）
  - 张飞 = 深褐鳞甲 + 络腮胡 + 青铜浮雕护具 + 黑色冠帽（94 版）
  - 沙僧 = 绿紫僧袍 + 月牙头饰 + 浓密卷黑发 + 念珠 + 行李法器（86 版）
- 「杂志感」四个可动维度：① 场景做「古今穿越」反差（古人进快餐店/海边步道/书店咖啡馆）② 怀旧胶片+暖调逆光 ③ 电影海报/杂志排版（竖排标题、日文假名、色块、大留白）④ 荒诞记忆道具（爱心烤痕面包、汉堡薯条、耿鬼玩偶、冰淇淋棉花糖）。

## 案例二 · 盐系男孩 = 张飞（作者「LawY」）

标题「大头柴犬？不！是穿越时空的盐系男孩！」。tag 里 #张飞# #飞飞# #三国演义#，正文是一段《穿越时空的少女》剧情梗概（真琴穿越）。18 张图。

- 手法：**拿「中年糙汉张飞」套「盐系少男 / 穿越时空少女」的日系电影框架**，反差即笑点。
- 图 01：张飞（深褐鳞甲+络腮胡）腾空跃起、低仰拍、蓝天背景，致敬《穿越时空的少女》海报，**腰间挂紫色耿鬼玩偶**；右上竖排日文「時をかける少女」、下方「待ってられない 未来がある」。

## 案例三 · 忧郁的老沙（作者「FrameLab｜AI 创意实验室」，图生图）

正文即完整提示词（旅行照片 → 杂志插画海报，3:4），已存 `02_assets/xhs_cases/laosha/`，核心：

- 人物：86 版沙僧**保留真实面部特征**（卷黑发、胡须、月牙头饰、绿紫僧袍、念珠、法器），真实摄影面部结构。
- **表情是最重要记忆点**：疲惫、忧郁、无奈，又带一点荒诞搞怪，像长途旅行后看透人生，**不要夸张鬼脸，自然克制耐看，让人第一眼想拿它当头像**。

- 色彩：米白纸底 + 墨绿/灰绿/暗紫/棕褐 + 秋叶金黄，低饱和褪色怀旧。
