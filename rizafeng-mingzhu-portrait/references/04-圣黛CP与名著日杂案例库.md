# 名著日杂案例库 + 「圣黛 CP」反差萌手法

补充从小红书爆款笔记与二创社区蒸馏出的具体案例与手法，重点是「圣黛 CP」（孙悟空 × 林黛玉）这一跨次元拉郎配现象及其提示词写法。

## 一、「圣黛 CP」现象：为什么孙悟空 × 林黛玉会爆火

2024–2025 短视频与二次元圈的现象级拉郎配，全网同人漫画、小说、剪辑、AI 图井喷。核心是一个词——**反差萌**：

- 孙悟空：西游里的超级战神，筋斗云十万八千里，金箍棒一挥妖魔退散，浑身「老子天下第一」的霸气。
- 林黛玉：红楼里娇滴滴的才女，伤春悲秋、动不动抹泪、走路怕踩死蚂蚁。
- 两人一凑，火星撞地球，反差大得离谱却莫名上头。

**文化符号级的天然 CP 基因（写进提示词就是现成的记忆点）：**
- 「补天石 × 绛珠仙草」是两本书钦定的前世梗（一个石头、一株仙草），「前世情缘」设定自带宿命感。
- 火眼金睛 × 含露目、金箍棒 × 花锄、花果山 × 大观园，处处可形成意象对位。

## 三、圣黛 CP 提示词写法（在七段公式上的专用扩展）

双人/CP 场景在标准七段公式之外，必须多写三行，否则模型会把两人画糊或风格打架：

```
[CP 反差锚定] 一人（林黛玉）淡颜清瘦、弱柳扶风、低头垂目；一人（孙悟空）灵动机敏、少年气、蹲姿/挠头
[CP 意象对位] 补天石 × 绛珠仙草（可化作一块青石 + 一株仙草作前景小物）；金箍棒 × 花锄；花果山 × 大观园
[互动关系] 用「蹲在枝头/递来花瓣/为她遮风」这类有空间高低的动作，让体格与气质反差落在同一画面里，别让两人并排站成证件照
```

完整示例（中文，胶片款）：

> 日系杂志感写真，低饱和低对比，柔和漫射自然光，浅景深，细腻胶片颗粒。画面是两位古风角色的现代治愈向同框。左边林黛玉：清瘦骨相，罥烟眉含露目，神情温婉带一点矜持，长发松松挽起，穿一件素白oversize衬衫配浅灰半身裙，怀里抱一束刚落的瓣花。右边孙悟空，少年气，灵动眼神，抓耳挠腮，蹲在一棵低矮的桃树枝桠上，穿宽松米白针织衫，一条淡金色发绳束着，正伸手把一瓣桃花轻轻递向黛玉。背景是午后干净街道与一树盛开的桃花，远处有淡淡晚霞。黛玉侧身微微仰头看他，似嗔似喜。竖版 3:4。避免：浓妆、高饱和红金、戏服堆砌、僵硬并排、塑料皮肤、过度磨皮。

英文版可直投 GPT Image 系列（把「罥烟眉/含露目」换成 `delicate willow-leaf brows, misty dewy eyes`，把「弱柳扶风」换成 `slender and fragile like a willow in wind`）。

参考和服樱花/汉服樱花 FLUX 提示词的「极简主体 + 留白 + 光影」结构：

> 中文：日系复古杂志胶片写真，低饱和灰绿雾蓝影调，柔和窗光侧逆光，浅景深，细腻颗粒。清瘦少女斜倚窗边，罥烟眉含露目，神情疏离带一点忧郁，长发松散垂落。白色宽松亚麻裙，腕上一缕红绳（记忆点），手下压着一本旧诗集，窗外有淡淡雨丝。整体留白多、呼吸感强，暗调里白衣只露三分，像从宋画留白里走出来的。竖版 3:4。避免：浓妆、甜笑、满屏道具、高饱和。

## 七、金角银角：「叫你一声，你敢答应吗？」呆萌兄弟


## 十、杂志内页排版感（日杂风的隐藏必杀）

日杂感和普通写真的差别，很大一块在**画报排版**——同一张人像，加上杂志内页的版式元素，日系味立刻翻倍。生图时两种用法：

### A. 把「杂志内页」当成画面 meta 场景

让模型直接生成「一张杂志内页」，人物是内页里的写真。提示词里显式写版式：

> 一本日系时尚杂志的整页内页扫描，跨页大图版式。左页占七成是一张人物写真（接上面的单人主体描述），右页与页脚有大面积留白，左侧竖排大字标题与几行假名标注，右上角有刊名与期号，右下角有很小的页码与摄影署名。纸张是带一点反光的铜版纸质感，扫描感、轻微阴影与装订线。竖版或正方形。避免：文字乱码、文字过满、字盖住人脸。

### B. 先出图、后排版（更可控，推荐）

生图只出干净人像（大留白、主体偏左或偏下三分之一），排版交给设计工具补字。这能绕开生图模型「多文字必乱码」的通病——模型写汉字/日文几乎必然出错，不如后期叠加真字。

手工排版骨架（贴进 PPT/PS/长图工具即用）：

```
┌────────────────────────┐
│  刊名 masthead（左上）  期号（右上）│
│                                    │
│    〈人物图，占画面 60–70%〉        │
│   人物偏左或偏下，右/上留白          │
│                                    │
│ 竖排大字标题（左）  引语/正文栏（右）│
│ 假名/英文小字：摄影师名 · 日期      │
│ ＿＿＿＿＿＿＿ 页码（右下）          │
└────────────────────────┘
```

### 版式元素速查（中英对照，贴进提示词或排版用）

| 元素 | 中文 | 英文提示词 |
|------|------|-----------|
| 刊名/刊头 | 杂志名 | magazine masthead / magazine logo |
| 竖排标题 | 竖排大字 | vertical Japanese headline text |
| 假名标注 | 日文假名小字 | small furigana / kana annotation |
| 引语框 | 大字引用 | pull quote |
| 栏线/网格 | 版面网格 | editorial grid / column rules |
| 页码 | 页码 | page number |
| 期号/日期 | 期数 | issue number / date |
| 摄影署名 | 摄影师 | photographer credit |
| 铜版纸质感 | 扫描感 | glossy magazine paper, scanned spread, binding crease |

关键约束（踩过坑）：**别让模型写具体汉字或日文**，文字一律用占位条/抽象竖线，或后期补真字；文字别压脸；竖排标题放在留白最大的一侧。这一条跟本 skill 「只出提示词、不自造示意图」不冲突——排版是文字层的设计，不涉及伪造字体。

## 十一、单人日杂案例收集（姿势库 + 摄影师 + 名著单人 AI 范例）

补充一批「单人独出」的真实案例方法与可抄作业的素材，主角单人照时直接调用。

### A. 单人姿势动作库（带参数，可直接量化进提示词）

来源：汉服/汉元素单人拍照动作教程（好摄影、太平洋摄影）、沈月同款日系姿势合集。

| 动作 | 关键参数 | 踩坑提醒 |
|------|----------|----------|
| 侧身回眸 | 侧身约 35–45°，回头温柔看镜头，一手轻扶发簪/裙摆 | 别正对镜头僵硬 |
| 倚栏远望（虚靠） | 手肘离栏 8cm 虚靠、肩胛骨轻触、腰悬空 5cm，下巴抬 15° | 别把重量压栏杆上变驼背 |
| 蹲姿抱膝 | 大腿小腿约 95°、双脚分开 35cm、裙摆铺成扇形 55cm | 蹲前先拨开裙摆，别堆成睡袋 |
| 双手拢袖遮面笑 | 袖口重叠 10cm、遮到鼻尖露出眼眉 | 别遮到眉毛变蒙面侠 |
| 单手提裙摆转身 | 提至膝盖上 12cm、上身右后转 50° | 别提太高像撩裙过河 |
| 日剧跑 | 先慢跑再增大动作、发丝自然飘、原图带点糊也 ok | 太急动作糊一团 |
| 躺着俯拍 | 收下巴、身体舒展、阳光下闭眼 | 别仰拍双下巴 |
| 仰头看天空（《情书》感） | 侧脸、微抬头、可抬手挡雪花/遮阳 | 情绪要「想你在释怀」 |
| 逆光行走 | 日落前 2h、拍向光反方向、发丝/衣物轮廓金边 | 需反光板补面光 |
| 走路裙摆飘动 | 步幅 45cm、三步停 1 秒、逆光曝光 -1 档 | 走慢配合裙摆节奏 |

通用心法：**慢动作 + 用道具 + 别盯镜头**（低头看花 / 侧头回望 / 闭眼感受），重心下沉、肩膀放松是消除僵硬的根。

### D. 单人出片小抄

1. 单人照主体永远偏左或偏下三分之一，另一侧留白，日杂感就靠这口气。
2. 一件记忆点（羽扇/金箍手环/青龙偃月伞）就够了，多了变 Cosplay。
3. 铁道口、斑马线、便利店门口、咖啡店窗边，这四类场景是日杂单人万金油。
4. 白平衡往 6000k 偏一点、画面颜色别超三种、棉麻材质的褶皱比熨平整更日杂。
5. 生图抽卡：同一段提示词多抽几次选最好的，别指望一次到位。
