# 四风格 × 名著人像提示词生成器

把「日系杂志感写真」「怀旧复古日常照」「电影剧照感」「时尚杂志企划感」四条摄影语法线，嫁接到 86 版《西游记》、87 版《红楼梦》、94 版《三国演义》等经典名著角色上（已破圈到金庸TVB、还珠格格等一切经典剧角色）。产出一整段可直接投喂生图模型（首选 RunningHub GPT Image 2）的提示词，交给用户自行测试。

## 风格线选择（2026-09-18 起新增，先于一切）

拿到需求第一步先判风格线（用户没指明就按用途判，拿不准就问）：

- **风格A 日系杂志感（日杂风）**：Kodak Portra 400 胶片感、柔和漫射光、高调低饱和、大留白、人物「慢」而静。适合情绪片、杂志内页、写真企划。
- **风格B 怀旧复古日常照**：90s/2000s 家用胶片快照（Kodak Gold/傻瓜相机/机顶直闪/影楼BTS）、暖黄褪色、高光溢出、生活流随意构图、人物「真」而鲜活（狂喜/呆萌/痞气）。适合头像、表情包、朋友圈背景图、群像。隐藏变体：50年代黑白中画幅纪实。
- **风格C 电影剧照感**：80-90年代电视剧剧照质感、35mm颗粒、柔光镜、戏中戏名场面复刻。适合 CP 叙事、章回体连载、动漫世界观入侵（頭文字D式）。
- **风格D 时尚杂志企划感**：刊名/页码/栏线排版、影棚大片或外拍 editorial、经典海报版式致敬（Kill Bill式）、摩登混搭（名牌元素×戏装）。适合封面、整期企划、致敬海报。

**风格线可混合**（爆款常见）：杂志排版+胶片质感（乔峰慕容公园）、剧照+动漫致敬（头文字D关云长）。

四条线的完整参数表、13个爆款案例拆解、提示词模板、英文质词速查见 `references/07-双风格体系与识图反推法.md`（必读）。

## 铁律

0. **【最高优先级 · API 调用红线】本 skill 只有「生图」可以自动调 RunningHub，其余一律先问用户。**
   - ✅ 可自动调用：`rhart-image-g-2/text-to-image`、`rhart-image-g-2/image-to-image`（出图本身）
   - ❌ **禁止自动调用**：`rhart-text-g-3-flash-preview/image-to-text` 等一切识图/理解端点，以及任何视频、音频、3D、AI App 端点。**必须经用户明确同意才能调用。**
   - **识图 / 反推 / 筛脸 / 出图后复核，一律用「本机自带模型直接读图」**（直接把图片读进上下文看图判断），不得外送任何图片到第三方 API。
   - 理由：①用户已明确要求；②图片素材可能是用户私有资料，外送等于泄露；③本机模型读图零边际成本、且判断质量更高（可多轮追问细节）。
   - 2026-09-19 违规记录：筛脸+复核共误调 173 次识图端点（约 ¥1.73）。**此为反面教材，不得再犯。**
1. **只出提示词，不直接生图。** 提示词整段输出、可复制、不拆散。
1.5 **要「像」就必须图生图。** 文生图只能保证妆造对（服装/道具/场景），**保证不了脸像原版演员**。用户强调角色相似度时，默认走图生图 + 原版剧照参考脸（见 4. 输出规范）。
2. **角色锚点必须来自原版剧集。** 先从 `references/02-名著角色锚点库.md` 取该角色在原版剧中的造型特征。**重要纠偏（2026-09）：戏装 100% 保留原版**——悟空金冠铠甲、黛玉蓝白襦裙、张飞鳞甲、沙僧僧袍一件都不能换；「日杂/杂志感」只落在「场景年代反差、怀旧胶片色调、电影海报/杂志排版、荒诞记忆道具」四点上，**绝不换成现代穿搭**。详见 `references/06-真实案例纠偏.md`。
3. **不自造示意图。** 参考图一律引用真实存在的原版剧照（见 `references/03-原版剧照素材索引.md`），禁止用 AI 生成或手绘替代。
3.5 **参考脸必须准确且只认经典版本**：94 三国演义 / 86 西游记 / 87 红楼梦 / 98 水浒传。张冠李戴的参考脸会直接毁掉整张图（2026-09-19 实测：参考脸找错导致角色完全不像）。取图标准流程见 `references/08-参考脸素材获取方法.md`（豆瓣 subject ID 已核实 + 浏览器通道下载 + 选脸四条标准）。**下载后务必先用本机模型逐张读图确认剧集与人物身份，再用于图生图。**
4. 画幅默认竖版 2:3 或 3:4（小红书调性），用户点名 9:16 或 1:1 时按用户的来。

## 工作流程

### 1. 确认角色与流派

向用户确认（或在需求明确时自行判断）两个参数：

- **角色**：如林黛玉、孙悟空、貂蝉、女儿国国王……
- **流派**（从 `references/01-日杂风核心法则.md` 的三流派取一）：
  - 少女款 → 元气软嫩（适合 孙悟空/哪吒/红孩儿/史湘云 这类少年气角色）
  - 偶像款 → 温柔干练轻熟（适合 貂蝉/小乔/女儿国国王/薛宝钗）
  - 胶片款 → 复古疏离故事感（适合 林黛玉/诸葛亮/关羽 的清冷或悲情面）

### 2. 取角色锚点

读 `references/02-名著角色锚点库.md`，摘出该角色的：原版演员气质关键词、标志性妆造（可保留的部分）、神态名场面（用于姿势与表情设计）。锚点库没收录的角色，先让用户描述或提供剧照，提炼后补录进锚点库再继续。

### 3. 套日杂改造公式

提示词按下述七段结构组装（顺序即权重，越靠前越稳）：

```
[1 摄影质感底座] 怀旧剧照/复古胶片质感（vintage film still）、暖调逆光、浅景深、细腻胶片颗粒；不强行低饱和，保留戏装本色
[2 角色锚点] 原版角色的脸型/五官/发型/神韵（写具体，如"丹凤眼卧蚕眉"）
[3 戏装保留] 原版神装整件保留并写具体（如「凤翅紫金冠+红底金纹戏铠」「淡蓝白襦裙+花簪步摇」），另加一件荒诞记忆道具（爱心烤痕面包/汉堡薯条/耿鬼玩偶/冰淇淋棉花糖）做反差记忆点
[4 场景] 生活化场景（窗边/街道/草坪/天台/海边），背景干净有留白
[5 光线时刻] 清晨侧光或傍晚逆光发丝光，避开正午顶光
[6 姿势情绪] 自然抓拍感、不直视镜头或浅笑望远方（可借用"猴哥九连拍"式放飞动作做反差萌）
[7 画幅与负面] 竖版 2:3；避免：浓妆、影楼感、高饱和红金撞色、戏服堆砌、僵硬正面照
```

三流派的关键词差异：

| 流派 | 底座加词 | 色调倾向 | 情绪 |
|------|----------|----------|------|
| 少女款 | 元气、空气感刘海、过曝柔光 | 白+浅蓝+嫩绿 | 明亮松弛、微表情俏皮 |
| 偶像款 | 轻熟、极简、质感面料 | 米白+燕麦+浅杏 | 温柔干练、浅笑 |
| 胶片款 | 复胶片、颗粒、灰调留白 | 灰绿+雾蓝+褪色暖 | 疏离、放空、故事感 |

### 3.5 CP / 双人场景（如「圣黛 CP」孙悟空 × 林黛玉）的专用扩展

双人同框比单人容易「画糊、风格打架」，除了七段公式，还要多写三行：

```
[CP 反差锚定] 两人各写一句气质 + 体态，故意拉开反差（淡颜清瘦 vs 少年灵动）
[CP 意象对位] 补天石 × 绛珠仙草、金箍棒 × 花锄、花果山 × 大观园，各取一件做前景小物或背景符号
[互动关系]  用「一高一低、蹲枝头/递花瓣/为她遮风」这种有空间高低的动作，别让两人并排站成证件照
```

完整案例（反差萌公式、名场面构图清单、中英提示词）见 `references/04-圣黛CP与名著日杂案例库.md`。

### 4. 输出规范

- 中英双版本各一段（英文版给 GPT Image 2 / MJ，中文版给即梦类国产模型）。
- 整段连续文本，不用换行符切段，不用 JSON。
- 每段提示词后附一行「改造说明」，点明保留哪个原版元素、动了哪些地方，方便用户微调。
- 用户要「像原版演员」时，**必须走图生图**（文生图锁不住脸）：用 `references/../02_assets/人物脸参考/` 里的原版剧照（或在素材索引找），投 RunningHub `rhart-image-g-2/image-to-image`，提示词开头写死锁脸句「Keep the exact facial identity, face shape and features of the man in the reference images completely unchanged」+ 演员名 + 五官特征，再接自设计的场景动作。单角色给 2-3 张参考图最稳。完整写法与 B线防 CG 漂移的强制风格段见 `references/07-双风格体系与识图反推法.md` 第六点八节。
- 图生图参考图本地路径：`02_assets/人物脸参考/`（张飞/孙悟空/林黛玉已有）；原版剧照全集见 `02_assets/{西游记,红楼梦,三国演义}/`，索引在 `references/03-原版剧照素材索引.md`。
- 用户要「杂志内页感」时，两种做法见 `references/04-圣黛CP与名著日杂案例库.md` 第十节：A 生图直接做「杂志内页 meta 场景」（文字用占位条，别让模型写具体汉字/日文，几乎必乱码）；B 先出干净人像后叠加真字排版（推荐，更可控）。

### 5. 避坑清单（写进负面提示词的依据）

- 浓妆 + 假睫毛 + 高饱和唇色 → 变影楼风，日杂感全毁
- 把角色戏装换成现代日系穿搭 → 角色认不出、完全跑偏（2026-09 实测错误，已废弃）
- 大红大金撞色 → 破坏低饱和底色
- 正面僵硬直视镜头 → 除非刻意做「与镜头互动感」（猴哥九连拍的招手式可以直视）
- 过度磨皮 → 保留皮肤质感与自然不对称
