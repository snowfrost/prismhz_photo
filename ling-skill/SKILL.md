## 第 0 步 · 先定路线（最重要，最易错）

**三条路线，只选一条，风格锁不得混写。** 判定顺序如下：

```
用户说了「2D / 动漫 / 番剧 / 赛璐璐 / 水墨」   → 路线 ③ 2D 漫打斗      → references/10
用户说了「真人 / 实拍 / 演员」                 → 路线 ② 真人实拍        → references/11
用户说了「写实 / 电影感 / 高武 / 奇幻 / 机甲」 → 路线 ① 写实渲染        → references/12
用户什么都没说                                → 路线 ① 写实渲染（默认）→ references/07 + 12
```

| 路线 | 地位 | 占比（本批 174 条） | 专属禁用要点 |
|---|---|---|---|
| **① 写实渲染 / 3D CG** | **默认** | 133 条（76%） | 禁手绘插画感、二维赛璐璐分色 |
| **② 真人实拍** | 明示启用 | 25 条（14%） | 禁超自然特效、血腥处决 |
| **③ 2D 漫打斗** | 明示启用 | 16 条（9%） | 禁写实摄影机成像、多色高饱和 |

> ⚠️ **历史教训**：SKILL.md 曾只列"双工作流 A/B"而不写默认值，导致下游误选 2D。
> **技能文档必须显式写默认，不能只列选项**（被王老师当场指出）。

**模型代际**：2.0 玩高动态（但会全糊）；2.5 自动偏写实，高动态提示词喂 2.5 会变噪点 → 高动态那套只给 2.0。

## 一、五维模型（三条路线共用的通用法则）

打斗成败 = 五维**同时成立**，缺一即崩：

| 维度 | 定义 | 崩坏表征 | 抓手 |
|---|---|---|---|
| **打击感** | 每次接触都"看得见重量" | 花拳绣腿、无反馈 | 对撞特写帧 + 尘屑粒子 + 短促震镜 + 冲击环 |
| **节奏** | 动静相位与切镜密度的编排 | 全程匀速、结尾泄气 | 首帧起战 → 疯切 → 唯一一次升格 → 大招定音 |
| **镜头** | 景别/机位为动作服务 | 站桩正打、看不清谁打谁 | 低机位仰拍、OTS 正反打、环绕、俯拍封位、前景遮挡 |
| **逻辑性** | 攻防因果与空间连续 | 瞬移、站位重置、武器变形 | 攻→挡→退→反击回合 + 固定站位 + 规则化博弈 |
| **丰富性** | 招式/道具/环境/敌群的变化量 | 一套动作重复、纯特效堆叠 | 单人 3–5 招 + 环境互动 + 群敌分层 + 统一特效语汇 |

**核心判据（棂的元规则）**：*清晰可读 > 花哨剪辑*。观众必须先看清"谁在攻击、谁在躲避、谁在反击"。

**低动态 ≠ 低质量**：棂的真人竹林对决（v1 #23，动态 21.6）靠 OTS 正反打 + 环境互动取胜，不必用大动作撑。
（v1 全量中位动态 34.3；v2 combat 中位 32.7；动态 TOP5 全是 2D —— 2D 运动强度系统性高于写实。）

## 二、执行步骤

0. **先定路线**（上一节）—— 决定用哪套风格锁与禁用清单。
1. **问/定四件事**（缺则问，不要瞎编）：① 路线（默认写实）② 角色资产与武器 ③ 场景与时长（15s / 30s） ④ 谁赢、怎么收。
2. **按五维写事件节拍表**：每 0.5–1s 一格，格内写明景别 + 机位 + 动作 + 接触反馈。
3. **套对应路线模板**（`10` 2D / `11` 真人 / `12` CG）+ 时间轴骨架（`references/03`）。
4. **加风格锁 + 禁用清单**：所选路线的正向锁 + 反向禁用，**两套不得混**。
5. **过质检红线**（`references/13 §一`，14 条）——任一条不过即回炉。
6. **输出去 AI 化中文提示词**，不拆散、可整段复制。

## 三、五维技法速查（细节见 `references/01`）

### 打击感
对刃特写帧 · 尘屑反馈 · 短白闪收回合 · 冲击环扩散 · 受击物惯性 · 短促震镜 ·
**慢动作只给三处**（大招 / 附魔 / 惊险躲过）· 落地重量

### 节奏
首帧即战 · 全片持续运动 · 疯切密度（高潮 0.2s/切）· 静爆相位（停 1 拍再爆发）·
三段式 30s 结构（0–10 起战 / 10–20 升级 / 20–30 大招）

### 镜头
低机位贴地仰拍 · OTS 正反打 · 环绕旋镜 · 俯拍封位 · 跟随武器运动 ·
前景遮挡分层 · 焦段（50mm 中近景 / 85mm 半身，焦点锁眼与刃口）· **镜头不重置空间**

### 逻辑性
攻防回合制 · 规则化博弈 · 空间错位需参照物 · 武器恒定 · 真假身可区分 · 环境物理一致

### 丰富性
角色招式表（3–5 招 + 大招 + 偏好）· 道具/召唤物 · 群敌分层 · 环境互动 ·
**特效语汇统一** · 招式密度递进 · 主题化道具

## 四、收尾（按体裁分流，治"结尾尬"）

> **先问体裁，再选收尾**（王老师 2026-10-07 裁定）：

| 体裁 | 收尾规则 |
|---|---|
| **完整打斗片**（要求完整情节与胜负） | **收束三段式**：大招命中 → 余波回落 → 收黑，1 秒内 |
| **15–30s 短视频**（单条，不要求完整情节） | **收尾三型**，见下 |

**收尾三型（短视频专用）**：A 余韵型（打完不停，召唤物/环境继续动）｜B 拔高型（拉远到天地全景，末 2 秒静止）｜C 定型式（收在具体可读的动作或物件）

**两条铁律**：① 最后 1–2 秒必须有"新东西"进入画面 ② 定格在**具体可读的画面**而非情绪形容词。

**反面模式（出现即判不合格）**：白闪收黑 / 主体静止摆拍 / 硬加没人引导去看的信物 / 0.5s 内演两种崩解。

> ❌ 短视频不要再写"白闪收黑"——实测这是短视频"结尾尬"的首要原因。棂 10-07 五连新作无一例用。
> 详见 `references/08 §三`（含 5 条新作逐条拆解）。

## 六、角色与招式设计

给每个出场角色写：**身份一句话 → 武器/媒介 → 3–5 招（含 1 个大招）→ 战斗偏好 → 视觉签名**。
招式必须与武器媒介一致（例：伞 = 闭伞反敲/半开弹回/旋伞卸力/伞柄勾荡/伞狱结界），禁止万能拳脚。

## 七、角色 / 武器 / 三视图分工（与 seedance25-prompt）

```
[资产层 seedance25-prompt]  人物四视图 + 武器图 + 场景图 → 参考图绑定
                ↓ 喂给
[导演层ling-skill]  路线判定 + 五维判据 + 招式卡 + 节拍表 + 风格锁 + 收尾三型 + 质检红线
```

| 问题 | 答案 |
|---|---|
| 只控角色，要控武器吗？ | **要**。贴身媒介（鞭/锁链/绷带）写进角色资产；独立武器（刀/枪/棍）单独出图 |
| 角色要出三视图吗？ | **只在多镜头/系列片/换装时出**。单条 30 秒连续在场不必 |
| 冲突裁决 | 硬参数（格式/时长/红线）听 seedance25；审美与节奏（好不好看、尬不尬）听 ling-skill |

## 九、路由

* `seedance25-prompt` —— **上级宿主**：参数速查、红线审核、文戏、情绪、延长与转场仍由它负责。
* `white-lang-director` / `story-director` —— 分镜结构与叙事骨架由它们给，本 skill 只做打斗段落的五维落地。
* 生图（首帧参考图）配方见 `references/05`，与 `image-prompt-director` 配合。
* 收尾三型见 `references/08`；角色/武器/三视图分工见 `references/09`。

## 十、输出格式

优先「**时间戳分镜式**」，单条 ≤30s；全局约束（角色锁 + 风格锁 + 禁用清单）只写一次，段内不重置站位。

```
[0–1s] 景别/机位 + 动作 + 接触反馈
[1–2s] ...
```

## 十一、自检（交付前最后一遍）

1. **路线选对了吗**（默认写实）？两套风格锁有没有混？
2. **14 条质检红线**（`13 §一`）逐条过了吗？
3. 谁打谁看清了吗？有无站位重置？每次接触有没有可见反馈？
4. 大招前有没有唯一一次升格？特效语汇统一吗？
5. 收尾选对型了吗？最后 1–2 秒有新东西进画面吗？
6. 禁用清单整段附上了吗？每个动词都写了形态/方向/结果吗？
