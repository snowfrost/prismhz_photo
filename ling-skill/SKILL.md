### I · 解读（模型骨架）

打斗的成败 = 五个维度**同时成立**，缺一即崩：

| 维度 | 定义 | 崩坏表征 | 抓手 |
|---|---|---|---|
| **打击感** | 每次接触都"看得见重量" | 花拳绣腿、无反馈 | 对撞特写帧 + 尘屑粒子 + 震镜 + 冲击环 |
| **节奏** | 动静相位与切镜密度的编排 | 全程匀速、结尾泄气 | 首帧起战 → 疯切 → 唯一一次升格 → 大招定音 |
| **镜头** | 景别/机位为动作服务 | 站桩正打、看不清谁打谁 | 低机位仰拍、过肩正反打、环绕、俯拍封位、前景遮挡 |
| **逻辑性** | 攻防因果与空间连续 | 瞬移、站位重置、武器变形 | 攻→挡→退→反击回合 + 固定站位 + 规则化博弈 |
| **丰富性** | 招式/道具/环境/敌群的变化量 | 一套动作重复、纯特效堆叠 | 单人 3-5 招 + 环境互动 + 群敌分层 + 统一特效语汇 |

**核心判据（棂的元规则）**：*清晰可读 > 花哨剪辑*。观众必须先看清"谁在攻击、谁在躲避、谁在反击"，特效与运镜才有意义。

### A1 · 棂的实例

* **红中道人 15 秒剧本**（2026-09-10）：逐秒时间轴，含"两帧白闪后硬切""全片唯一一次极短升格""俯拍红绳如落雨封位""伞狱结界"收尾——五维俱全的范本，全文见 `references/03`。
* **真人竹林对决**（视频 #23，2026-09-23，28s，动态 21.6）：低动作幅度靠 OTS 正反打 + 环境互动（湿石、竹叶、雨雾）取胜。
* **兽人奇幻对撞**（视频 #56，2026-09-30，30s，动态 40.8）：对刃火花特写 + 环绕 + 大招光柱起爆。
* **七彩爆散 × 动漫格斗**（视频 #3，2026-09-19，30s，动态 43.3）：粉彩粒子特效贯穿全场 + 群敌包围 + 逆光收尾。

### A2 · 触发场景（description 已含）

用户在以下情境会需要本 skill：写打斗提示词、打斗分镜、招式设计、诊断打斗视频问题、要棂式审美。

### E · 执行步骤

0. **先定画风（最重要，最易错）**：默认 = **写实影视质感**（实拍/引擎级渲染 + 后期特效合成），
   不是 2D 赛璐璐。2D 只在用户明确要求时才用。详见 `references/07`。
1. **问/定四件事**（缺则问，不要瞎编）：① 画风（默认写实 / 用户指定 2D）② 角色资产与武器 ③ 场景与时长（15s / 30s）④ 谁赢、怎么收。
2. **按五维写事件节拍表**：每 0.5–1s 一格，格内写明景别 + 机位 + 动作 + 接触反馈。
3. **套时间轴模板**（`references/03`）：起战 → 三轮交锋 → 中段升格转折 → 大招 → 崩解收黑。
4. **加风格锁 + 禁用清单**（`references/02` + `references/07`）：棂式 DNA 或用户指定风格，两者不混。
5. **自检六问**：画风选对了吗（默认写实）？谁打谁看清了吗？有无站位重置？每次接触有没有可见反馈？大招前有没有唯一一次升格？特效语汇统一吗？
6. **输出去 AI 化中文提示词**，不拆散、可整段复制。

### B · 边界

* 不做文戏/情绪戏主体（交 `seedance25-prompt`）；不做剧本结构压缩（交项目剧本流）。
* 棂式风格是**默认选项而非强制**：用户给了别的风格（如导演指定的写实武侠），以用户为准，五维法则照用。
* 写实路线 + 高武处决/血腥按棂实测**默认劝退**，除非用户明确坚持。

## 一·补 · 默认画风（先读这段，别跳）

**棂的默认画风是写实影视质感，不是 2D 赛璐璐。**

实帧证据（5 组）+ 棂原话双重锁定，详见 `references/07`：

| 证据 | 内容 |
|---|---|
| detail_03 | 实景废墟 + 真人质感皮肤 + 真实扬尘 + 后期粒子爆散 + 半透明能量护盾 |
| detail_23 | 真人竹林、真实雨雾湿石，**几乎无特效**，靠 OTS 正反打与环境取胜 |
| detail_56 | 引擎级3D 渲染 + 沙漠景深、扬尘、火花、体积光 |
| frames_01 | 赛博都市 + 机械义肢 + 体积光导弹尾焰，纯 3D CG |
| 棂原话 | 「**2.0喜欢玩高动态 2.5给我干写实去了**」「**转真人是这样子了**」「3D CG」 |

**默认风格锁**（写实影视质感，直接抄）：
真实摄影感与引擎级渲染 · 真实景深浅虚化 · 真实肤质保留血色与细微纹理 ·
胶片颗粒 + 轻微色差 + 暗部噪点 · 强光比硬交界 · 冷青环境 × 暖灯/朱红对撞 ·
边缘光切发梢与刀锋 · 体积光丁达尔光束 · 空气里永远有雨雾/烟尘/水汽/雪烟 ·
地面材质必参与动作（积水起涟漪、湿石反光、沙尘扬起）· 前景遮挡 ·
特效只在接触帧/冲击帧/大招帧出现且单一主色。

**默认禁用**：廉价游戏 CG 感 · 塑料皮肤与磨皮脸 · **手绘插画感与赛璐璐分色**（这是 2D 特征，写实路线禁止）·
3D 软体面条感 · 武器变形 · BOSS 拟人化 · 普通站桩对砍 · 血腥断肢处决 ·
只写单个动词 · 不描述动作指望模型自己编。

**2D 赛璐璐仅在用户明确说"要 2D / 动漫 / 番剧风"时启用**，并配套切换禁用清单。
两套不得混写。

**模型代际**：2.0玩高动态（但会全糊）；2.5 自动偏写实，高动态提示词喂 2.5 会变噪点 → 高动态那套只给 2.0。

## 二、双工作流分流（务必先分流）

> ⚠️ **B 是默认，A 是备选**。此前文档把 A 当默认，导致下游误选，已在 `references/07` 记录更正。

| 工作流 | 地位 | 适用 | 关键调法 |
|---|---|---|---|
| **B · 写实影视质感** | **默认** | 棂 2026-10 主力路线；武侠交手、高武、群战皆可 | 引擎级渲染而非手绘；真实肤质与景深；体积光与空气介质在场；特效为后期附加、单一主色、只在冲击帧出现；禁血腥处决 |
| **A · 2D 动漫赛璐璐** | 备选，需用户明示 | 高武夸张招式、召唤物、大招对波 | "纯平面2D剧场版赛璐璐、细密手绘线稿、硬边分层阴影"；速度线/集中线/残影链；禁 3D CGI 与塑料皮肤 |

> 棂原话：「2d用多了结尾处决技 真人是真给处决」→ 2D 他玩腻了才转真人。
> 「最好分2个工作流吧」——分流是必要的，但**默认是 B**。

## 三、风格锁与禁用清单（详见 `references/02`、`references/07`）

**正向锁**：苍白冷艳人物 · 白发/黑长直 · 高密度材质服饰（蕾丝/流苏/锁链/金属机械）· 冷色环境 + 暖色对撞 · 米白银白主调 + 单点高饱和强调色（朱红/青蓝/**洋红**）· 强光比边缘光 · 开阔场景 + 前景遮挡。

**反向锁（必写）**：禁止 3D CGI 感、廉价游戏引擎感、2.5D木偶感、塑料皮肤、低成本国漫 CG、**手绘插画感与赛璐璐分色**（写实路线专禁）、人物脸崩、武器变形、BOSS 拟人化、普通站桩对砍。

## 三·补 · 收尾规则（按体裁分流）（2026-10-07 定稿 · 治「结尾尬」）

> **先问体裁，再选收尾**（王老师 2026-10-07 裁定）：
>
> | 体裁 | 收尾规则 |
> |---|---|
> | **完整打斗片**（有成片结构，要求完整情节与胜负收束） | **遵循收束三段式**：大招命中 → 余波回落 → 收黑，1 秒内完成 |
> | **15–30 秒短视频**（单条，不要求完整情节） | **不走收束三段式**，用下面的**收尾三型** |
>
> ❌ 短视频不要再写「白闪收黑」。实测这是短视频「结尾尬」的首要原因。
> 5 条棂 10-07 新作（全部是短视频）无一例用白闪收黑。

**收尾三型（短视频专用）**：

| 型 | 做法 | 适用 |
|---|---|---|
| **A · 余韵型**（默认） | 打完不停，召唤物/环境继续动，主角被"结果"包围 | 群战、召唤物路线 |
| **B · 拔高型** | 从战场尺度拉远到天地全景，最后 2 秒静止 | 史诗、大场面 |
| **C · 定型式** | 收在一个**具体可读的动作或物件**上（踩在光阵上/手按住伤口/回头） | 人物收束、留人物印象 |

**三型共同的两条铁律**：
1. **最后 1-2 秒必须有"新东西"进入画面**（围过来的群狐 / 沉降的火光 / 重新亮起的灯）
2. **定格在具体可读的画面上，不定格在情绪形容词上**

**反面模式（短视频出现即判不合格）**：白闪收黑 / 主体静止摆拍 / 硬加一个没人被引导去看的信物 /
0.5 秒内要求同时演两种崩解效果。

详见 `references/08` §三（含5 条新作的收尾逐条拆解）。

## 三·补之二 · 与 seedance25-prompt 的分工（角色/武器/三视图）

> 常见疑问：本skill 只控角色，seedance25-prompt 要控角色+武器+三视图，到底听谁的？
> 答案：**分层，不是二选一。**详见 `references/09`。

```
[资产层 seedance25-prompt]  人物四视图 + 武器图 + 场景图 → 参考图绑定
                ↓ 喂给
[导演层ling-skill]  六维判据（含画风第零维）+ 招式卡 + 节拍表 + 风格锁 + 收尾三型
```

| 问题 | 答案 |
|---|---|
| 只控角色，要控武器吗？ | **要**。贴身媒介（鞭/锁链/绷带）写进角色资产即可；独立武器（刀/枪/棍）单独出图 |
| 角色要出三视图吗？ | **只在多镜头/系列片/换装时出**。单条 30 秒连续在场不必（这已被王老师实测印证） |
| 不出三视图会怎样？ | 单镜头无风险；切到背面/侧面、分段生成、独立武器时才出问题 |

**冲突裁决**：硬参数（格式/结构/时长/红线）听 seedance25-prompt；
审美与节奏（打斗好不好看、结尾尬不尬）听 ling-skill。


## 四、角色与招式设计（棂的建议，本 skill 落地）

给每个出场角色写：**身份一句话 → 武器/媒介 → 3–5 招（含 1 个"大招"）→ 战斗偏好 → 视觉签名**。
招式必须与武器媒介一致（例：伞 = 闭伞反敲/半开弹回/旋伞卸力/伞柄勾荡/伞狱结界），禁止万能拳脚。

## 六、输出格式

优先「**时间戳分镜式**」（Seedance 2.5 可合镜）：

```
[0–1s] 景别/机位 + 动作 + 接触反馈
[1–2s] ...
```
单条 ≤30s；一镜到底只写一次全局约束，段内不重置站位。
