# 25 · 图生多参考图与导演简写

> **参考来源**：《武戏导演进阶版》（公开版），2026-11-17 参考入编。
> **定位**：面向**多参考图、以 `@图片N` 分工绑定人物/场景/形态**的图生视频模型，提供一套与 ling 五维模型兼容的导演简写流程。
> **不是另一条打斗路线**：写实 / 真人 / 2D 仍由 SKILL.md 第 0 步决定；单条 / 多镜仍按交付形态 A/B 决定。本文件只改变**提示词的组织密度与参考图绑定方式**。
> **默认不变**：文生、单张首帧图，或未明确使用多参考图分工时，仍走现行逐拍执行级写法；只有命中 §〇 才启用本文件。

---

## 〇、先判定输入方式（与既有规则的分流总表）

| 条件 | 写法 | 必须配套 |
|---|---|---|
| 文生视频；只有一张首帧图；用户要逐拍控制 | **逐拍执行级**（默认） | `03` + 路线文件 + `13`；首帧图仍过 R17 |
| 多张参考图，用 `@图片N` 分别指定人物、场景、兵器、形态 | **导演简写（本文件）** | 读图五样 + 参考分工 + 五成分段；不再套用单张首帧 R17 |
| 用户明确要求“导演简写 / 按多参考图格式 / 反推成这种格式” | **导演简写（本文件）** | 同上；用户要求优先 |
| 多参考图 + 长片 / 多镜剪辑 | **16 管交付与连续性，25 管每条生成稿** | 每段独立完整重写；跨段按 `16 §4.4` 选交接方式 |

**冲突裁定：不是“写得越少越好”，也不是“写得越细越好”。**
多参考图平台已能从图像获得人物、材质和构图，正文若再把每个站位、米数、起幅落幅写死，容易保守呆板；因此最终稿采用导演简写。但内部仍须先完成五维设计、空间锁与时间预算，不能把“简写”理解为不设计。

---

## 一、先判断要交付什么

| 用户意图 | 交付 |
|---|---|
| “你有什么想法 / 先想想” | 只给主线、双方打法、高潮画面、时间分配，不直接写完整稿 |
| “出一版 / 按这些图写” | 直接写完整提示词 |
| “反推这个视频” | 走 §八；先还原，用户要求“强化”时才另列新增设计 |
| “把旧稿改成这个格式” | 走 §九；保留招式编排和卖点，只改有平台风险的表达 |
| 一分钟以上、有故事和台词 | 先交分段设计，确认后按每条约 30 秒逐段写；每段生成反馈后再续写下一段 |

改稿以用户贴回的版本为基线做最小修改，不借“套用新规则”重写用户未要求改动的部分。

## 二、读图五样：先取来源，再用词库执行

每张图先回答五问：

| 读取项 | 要提取的内容 | 进入成稿的位置 |
|---|---|---|
| 人物与姿态 | 谁在场、拿什么、正在做什么、谁占画面主导 | 参考分工、开场动作、主视角 |
| 既有能量与材质 | 火焰、电弧、光屑、铜锈、水膜等图中已经可见的语汇 | 能量锁定、技能外观 |
| 潜在对手 / 威胁 | 剪影、门窗后的实体、远处巨物、群体中可升级者 | 对手与交锋设计 |
| 场景锚点与反馈介质 | 地标、地面、积水、长草、碎石、可破坏结构 | 场景段、环境反馈、连续性 |
| 图中正在发生的事件 | 潜伏、追逐、围困、对视后的即将出手 | 首段攻防，不另造无关开场 |

**图里没有的内容原则上不硬加。** 用户点名新增时，也从图中既有颜色、材质、道具和空间关系延伸。

### 与词库层的关系（解决“读图优先”与“主动取词”的表面冲突）

1. **26 场面语料库**只提供情境、道具利用、攻防因果的灵感；不能覆盖参考图已确立的身份、场景和武器。
2. **17–22**提供招式骨架、轨迹、异象、反馈的执行词；先由图定“是什么”，再由词库补“怎么写清楚”。
3. **24**提供人体动作与受击分级；真人/徒手段按力度和距离选动作，不能为凑名录改变人物设定。
4. 取词后必须过 `04 §八` 变奏与反模板化；**图里没有来源、又不能由用户要求或场景因果支持的整句词库描写，不搬进成稿**。

## 三、设计：先定节奏曲线与上限

### 3.1 段落预算

* 30 秒通常写 **8 段**，每段 3–4 秒，末段可到 6 秒；内容特别满时压成 7 段，原则上不超过 8 段。
* 不足 30 秒，每段约 2–4 秒；仍按动作完整性分配，不机械均分。
* 每段内部设计 **2–4 个连续动作**；开场可只写“一次清楚出手 + 一个结果”。
* 这 2–4 个动作是段内攻防链，不再把每个 0.2 秒微拍都写成独立标题。内部节拍设计仍须满足 `13 R16`，不能用抽象频率代替动作。

| 节奏位置 | 内容 | 配额 |
|---|---|---|
| 开场 | 潜伏暴露、第一次出手或图中动作的直接延续 | 1 段 |
| 主交锋 | 同一种打法逐段加密、加重；双方始终有应对 | 约 4 段 |
| 升级与终结 | 新机制、尺度升级、最后一击 | 最后三分之一，约 3 段 |

### 3.2 三条密度上限

1. **新机制、变大、换地点各最多 1 次**，集中在最后三分之一；换地点不与终结挤在同一段。
2. **能量不超过 3 种，同时出手不超过 2 种**；角色自身服饰与固有材质不另算一种能量。每个技能/阵营固定一个主色系，对手之间可用固定对冲色区分，但不得在同一特效里堆杂色。
3. 主交锋段不每段发明新招，优先让既有打法**更快、更密、更重**。首领中段登场并正面交手属于交锋加重，不必然属于新机制。

### 3.3 卖点与攻防

* 速度型：越打越快、越打越密；不要在中途改成武器变大、双方顶着对推。
* 力量型：攻击落在实体上，位移、破坏与受击逐级加重。
* 体量型：才使用巨物、法相和超远视角；尺度必须服务打法，不为“大”而大。
* 每段都要有来有回：一方出手，另一方当场有可见应对，再反击。“一步不退”只指脚下不退，手上仍须还击。
* 一打多，杂兵只承担围攻、扑咬、遮挡、受击、击飞等功能；一对一才给对手完整招式链。
* 见血只在改变局面的时刻出现，全片极少次；真人路线继续执行 `11` 的禁血腥与人体极限。

## 四、成稿结构：开头写“是什么样”，正文写“怎么发生”

### 4.1 开头：参考分工 → 场景 → 能量 → 技能 → 群体结构 → 全局

开头**只定义外观与约束，不预演剧情**。不要在这里写因果链、逐段空间调度、镜头运动和声音变化，否则模型可能只照开头生成而略过正文。

#### ① 参考分工

* 每张图写“使用 `@图片N` 作为……参考”，紧邻说明图中有什么、取什么、不取什么。
* 人物图通常写“只取人物，不取背景”；多张图时**只保留一个场景出处**：一张场景图，或明确“场景只按下面的文字”。
* 写清角色身份映射，加“全程不变脸、不换装、不改变身材比例”。参考图编号全片固定。
* 图片水印与图上文字不进画面；技能名只用于定义，不在画面中生成文字。
* **形态参考图**：用于文字难说清的大型特效或终结构图。开头说明只取形态、质感、颜色和构图；正文到达该画面时再次 `@图片N`，并放在成形过程的终点，避免段首直接跳图。
* 形态参考图只适用于写实/CG 的奇幻形态；真人路线仍执行 `02`：不用特效参考图喂真人特效。

#### ② 场景

写近、中、远三层材质和锚点，给出纵深与主色彩关系；巨物用数字尺度并与地标比较。场景只能有一个来源，色彩稳定不跳色。

#### ③ 能量锁定

每种能量写：**材质 + 颜色 + 运动方式 + 覆盖范围 + 明确不是什么**。这里只写它长什么样；何时离体、在哪里命中、如何爆散留到正文。

#### ④ 技能

**招式卡与成稿技能不是同一层**：正式角色设计先按 `04/R20` 独立成卡（3 常规 + 1 破招 + 1 大招），此处只展开**本条成稿实际调用的技能子集**，通常每名主要角色 2–3 个；只出手一次的配角只写 1 个。若整片确实用到卡内全部 5 招，保持卡与正文一致即可，不为压数量删招。每个被调用的技能先定义可看见的过程，正文用技能名调用；不得只写抽象招式名让模型自行补全。

#### ⑤ 群体结构

万剑、龙群、飞魔等需要群体运动时，采用 `08 §十一` 的鱼群结构，不写剑墙、剑板或机械螺旋。

#### ⑥ 全局一段

写清战斗类型、唯一场景、朝向句、前半打法与后段升级方向、最后一击，以及无血腥/无配乐/台词语言等必要约束。复杂空间因果先在内部理清，不在此堆一张设计清单。

### 4.2 正文：每段五成分

```text
【时间】功能标题。{镜头小字}。{有来有回的交锋}。{特效过程与环境反馈}。音效：{A} → {B}。
```

1. **功能标题**：2–4 字，说明这段在节奏中的作用。
2. **镜头小字**：先写镜头在主角哪一侧，再写画面怎样被动作推动；不只报机位名。
3. **交锋**：2–4 个连续动作，写清谁攻、谁如何应对、结果是什么。
4. **特效与反馈**：能量怎样出现、蔓延、命中、消散；再写一个环境物理反应。
5. **音效**：只选 1–2 个最能卖这一刻的声音，用 `A → B` 写变化。

全文最后单独一行写：**严禁画面生成字幕。** 多段长片每一段都要写。

**终结放在最后一段**：本体与最大力量同步出手，对手有迎击，碰撞后冲击由近到远扩散；写完扩散即结束，不回到开场、不收势摆拍、不另加总结段。此输入方式下，完整打斗片也不强制再收黑；纯打斗片段仍按 SKILL.md §四在动作中结束。

### 4.3 称呼与台词

* 多角色、多参考图时，叙述尽量写角色名，不用容易错指的“他 / 她 / 它”；能量和兵器挂上主人名字。
* 台词接在动作后，用叙述句自然带出；一句只说一件事，每段最多 1–2 句。
* 不写替观众解释剧情的台词，不用括号堆砌语气标签；有台词时写明语言与声线。

## 五、朝向句与镜头小字

### 5.1 朝向句（防“一直对镜头打观众”）

全局只写交锋时的**比例与倾向**：

> 交锋时【主角名】面朝【对手名】打，镜头多从侧面、侧后方拍，出招时可以露出正脸和侧脸，不做正对镜头的摆拍。

* 不在全局写“全程背对镜头”，否则整片可能都是背影。
* 升空、举兵器、变身、对峙等非交锋段，必须在当段镜头小字另写方位。
* 让镜头后退的压力应来自**对手攻势或碰撞冲击**；不要写“镜头被主角逼退”，那会把主角推向正对镜头出招。

### 5.2 镜头小字四种写法

| 手法 | 写法 |
|---|---|
| 镜头被卷入动作 | 被激波推开、被迫让出距离、只捕捉到攻击轨迹 |
| 距离变化 | 用清晰的远近距离变化写推进或后退，避免无目的“拉远” |
| 速度留痕 | 音爆锥、衣发延迟、动态模糊、末端减速；本体仍须可读 |
| 材质反应 | 碎石遮镜、烟尘埋镜、衣摆撕裂、暗影沿石阶蔓延 |

焦段可翻成画面感受；若平台能稳定执行镜头五要素，则与 `12 §六` 联用，不为了“简写”删除跟随目标和空间方向。

**两种转场**：
* 掩埋转黑：烟尘迎面埋住镜头，下一拍攻击从烟幕中切开；不是无条件白闪收黑。
* 跟物飞行：跟刀光、碎块或被召回兵器到落点再切；必须符合 `16 §二` 动势衔接。

## 六、平台敏感的表达替换

### 6.1 近战与远程

* **近战刀光贴刀锋**，一闪即散，在命中处炸开；不靠刀光离体制造密度。
* **远程气刃可以离体**，但必须有出处、有形、有去向：从兵器/拳面成形，写体积或借介质显形，射向谁、在哪里命中都要清楚。
* 近战与远程的完整裁定见 `12 §7.6`；特效词可从 `17/21/22` 取，但不能绕过来源和轨迹。

### 6.2 速度、静压与闪帧

* 高速写本体动作：急退、跃开、贴地冲锋、沿清晰轨迹换位；不要写“本体化作残影 / 烟雾 / 一道光”。
* 原处残留残影、身后水花迟半拍炸开、刀锋弧光等**痕迹**可以写；痕迹不等于本体变形。
* 在这类平台出现“停死 / 慢放失控”的实测时，不写“定在半空、几乎静止、持续约、子弹时间、抽帧、定格、升格慢放”。命中改写为“一闪 → 立刻碎裂”。
* 闪帧写在发生段：`闪一帧【具体画面】，一闪即过`。它是瞬时视觉反馈，不替代攻防动作。
* 静压再爆发仍可保留**设计意图**，但改写为“动作密度骤降 + 环境声像被抽空 + 衣发/尘雨仍动”，下一拍统一爆发；不要写“停住 / 骤然的寂静”。
* 默认 Seedance 文生或单首帧路线仍按 `13 R2/R19` 使用升格两级制，不能把本平台的禁令反向套到所有模型。

### 6.3 套路与可读性

不写擦鼻尖、差一毫米、切断发丝、对视后再出手、蓄力停顿、双向弹开、主动后仰闪避等无新信息套路。替换为侧身卸开、攻击擦过肩甲、格挡被压弯、借势转体等具体受力。

**受击后仰是物理反馈，不在此禁令内**；被打后的轻/中/重反应按 `24 §1.2` 分级。

## 七、长片、多段与台词

1. 先交设计：素材分工、每段主线、结尾钩子、双方技能、台词草稿、所需道具图和首帧；确认后再逐段写。
2. 每段都是独立完整提示词，完整重写人物外观、参考分工、能量锁定、朝向句和结尾禁字幕行；不能写“同上”。
3. 参考图编号全片固定；每个人脚下介质、武器去向、伤损状态必须承接。上段砸进浅水，下段就从水中起身；要回沙滩必须有动作带过去。
4. **同场景动作连续**：优先用 `16 §4.4` 的末帧状态 + 末帧截图交接，下段从该姿态启动。
5. **需要剪辑感、时间跳跃或重建视角**：下段可换新机位，但仍须完整复写状态；不能用“新机位”掩盖站位、伤损或道具重置。
6. 长片非末段可用“招式已成形、尚未出手”的悬念钩子衔接；不把同一命中动作拆跨段，最终段才完成终结与扩散。
7. 台词短、冷、少，全片控制总量；请神或念咒可使用符合设定的正式称号，不借台词解释全部世界观。

## 八、视频反推

1. 读取时长、尺寸、帧率；检测黑帧与切镜，避免把短黑帧误判为创作停顿。
2. 高密度抽帧看动作；关键镜头再提高采样，先确认主体、攻击来源和命中关系，不凭几张单帧猜。
3. 检查饱和度、亮度、高光、暗部、灰雾与颗粒，提炼一句可执行的质感描述。
4. 动作密度照原片还原；原片一秒多次切换时，每段应容纳相应连续动作，而不是写成空旷单动作。
5. 原片超过单条时长上限时按剧情拆成最少条数；保留原片结局。用户只说“反推”时不虚构看不到的内容；说“强化”时单独列出新增设计。

## 九、旧稿改写（保留卖点，只换危险表达）

| 旧写法 | 改成 |
|---|---|
| 逐镜参数堆满、每镜重新解释人物 | 合并为 7–8 段，每段五成分；参考与外观在开头一次定义 |
| 抽帧 / 定格 / 子弹时间 / 升格慢放 | 本平台改“闪一帧……一闪即过”；默认平台仍按 R2/R19 |
| 后仰规避 / 擦鼻尖 | 侧身卸开 / 攻击擦过肩甲 |
| 本体化作残影、烟雾、光 | 本体沿轨迹冲过，原处留残迹 |
| 定格姿态 / 一切静止 | 落地顺势俯身并接下一动作，或静压时保留环境微动 |
| 法相“轰然浮现” | 触发 → 气浪/扭曲 → 材质堆高成形 → 尺度参照 → 压迫环境，本体持续动作 |
| 环形气浪一圈圈 | 冲击向四周排开，由近到远一片接一片压弯 |
