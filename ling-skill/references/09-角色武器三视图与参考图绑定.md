# 09 · 角色 / 武器 / 三视图与参考图绑定（资产层自包含）

> 本文档回答打斗任务里的资产准备问题：**角色要不要出三视图？武器要不要单独锁？参考图绑几张？**
> 结论先行：**按需分层**——单条 30 秒连续在场，一张立绘 + 一张场景图即可；多镜头 / 系列 / 换装才上四视图。
> 本文档为 ling-skill 自包含文档，不依赖任何外部 skill。

---

## 一、资产层与导演层（本 skill 内部的两层）

| | 资产层（准备什么） | 导演层（本 skill 核心） |
|---|---|---|
| 管什么 | 角色长什么样、武器长什么样、参考图怎么绑 | 这场戏怎么打、五维怎么落地、收尾怎么收 |
| 关键产出 | 人物立绘/四视图、武器图、场景图、参考图编号绑定 | 招式卡、节拍表、风格锁、特效语汇、收尾三型 |
| 解决的问题 | 「同一个人别换脸」「同一把刀别变形」 | 「别站桩」「别只放特效」「结尾别尬」 |

**两者不冲突，是同一部片子的上下游。**

```
[资产层]  人物立绘/四视图 + 武器图 + 场景图 → 参考图绑定
                ↓ 喂给
[导演层]  五维打击模型 + 招式卡 + 节拍表 + 风格锁 → 完整视频提示词
```

生图版式与风格配方见 `references/05`（本 skill 自有，自包含）。

## 二、直接回答三个高频疑问

### Q1：现在只控角色，不需要武器吗？
**需要。** 但不需要单独写「武器三视图」，而是要把武器**锁进角色的资产里**。

猫耳女用「右前臂三圈红绸皮鞭」这种**可穿戴于角色身上的媒介**——它本身就是角色外观的一部分，跟着人走就不会错。
但如果换成「她手里有一把长剑」而没有锁武器图，跨镜头时刀型必变。

**判据**：
|武器类型 | 需要单独出三视图吗 | 原因 |
|---|---|---|
| 贴身媒介（鞭、锁链、绷带、戒指、伞） | **不需要**，写进角色资产 | 不会脱离角色 |
| 独立武器（刀、枪、棍、斧） | **需要** | 会脱离角色被换形 |
| 一次性道具（酒瓶、椅子、石头） | 不需要，但要在节拍里写明何时碎/何时丢 | 状态变化即可控 |

### Q2：角色要出三视图吗？
**要，但只在「多镜头 / 系列 / 要跨段复用角色」时出。**

单条 30 秒且角色只有一个连续镜头的段落，**不必出三视图**——
猫耳女 vs 裸上身男之所以满意，是因为它就是**单条、单场景、两个角色全程在场**，没有跨镜换场的需求。

边界说明：写实四步法适合真人角色定妆/多镜头一致性项目（对话戏、系列片）；纯风格化/卡通风角色不需要真实感四步法。

**出三视图的触发条件**（任一命中就要出）：
1. 同一条视频里有**任何切镜换角度**（人物转到侧面/背面）
2. 同一条视频超过 30 秒且要分段生成再拼接
3. 同一角色要出现在多条不同视频里（系列片）
4. 有换装需求（多套造型各出一张）

### Q3：不三视图会怎样？
**实测：不三视图 + 单镜头连续在场 = 没问题。**

风险点在于：
* 切镜到**背面/侧面**时，脸和发型会漂
* 分段生成时，每段的人物细节可能不一致
* 武器是独立道具时，形态会变

## 三、标准工作流（按场景选）

### 场景 A · 单条 30 秒、连续在场（最省事）
```
1. 用本 skill 出角色六格卡（身份/武器/招式/大招/偏好/视觉签名）
2. 用 9:16 立绘版式生成角色定妆图（版式与配方见 references/05）
3. 武器写进角色提示词里（贴身媒介）或单独出一张武器图（独立武器）
4. 用本 skill 的五维 + 节拍表 + 收尾三型，写视频提示词
5. 参考图只绑 1-2 张（角色 + 场景），图少反而更稳
```
**不用三视图。** 这是性价比最高的组合。

### 场景 B · 多镜头 / 系列片 / 有换装
```
1. 出角色四视图（三视图 + 表情图）→ 锁跨镜一致性
2. 独立武器出一张三视图（正面/侧面/握持态）
3. 每套换装各出一张四视图
4. 用本 skill 出节拍表，五维自检
5. 视频提示词开头按【素材描述】写明参考图编号与用途（人物/武器/场景），再绑定
```

### 场景 C · 群战 / 召唤物
```
1. 主角出立绘（不必四视图，主角通常全程在场）
2. 召唤物出**一张群像图**即可（同款不同个体，见 references/08）
3. 环境级实体（伞/法阵/陨石）单独出一张，因为要反复出现
4. 参考图绑 3 张：主角 / 群像 / 环境实体
```

## 五、案例：结尾尬不是资产层的问题

用户反馈「结尾处有点尬」。复盘后确认是**收尾层的问题，不是资产层的问题**——
所以**加三视图也解决不了**。

根因（详见 `references/08` §三）：写的是
> 「骨钉化作白灰 + 符纸烧尽」+「背对镜头立于阶上」+「白闪收黑」

三重问题：
1. 0.5 秒内演两件事必然降级
2. 主体静止，**没有新信息进入画面**
3. 收在黑屏上，观众记住的是黑屏不是角色

**修正方案已写入 `references/08` §七**：
改用「余韵型 + 拔高型」收尾，最后 1 秒要有新东西进入画面（灯重新亮起 / 群狐围过来）。

> **教训**：资产层（三视图/武器/一致性）解决的是「不穿帮」；
> 导演层（节奏/收尾/特效语汇）解决的是「好不好看」。
> 「尬」属于后者，加三视图是南辕北辙。

## 六、案例结论（实测复盘）

实测「整体挺满意，除了结尾有点尬」——恰好印证了分层判断：

| 现状 | 判断 |
|---|---|
| 角色没出三视图，效果满意 | ✅ 印证「单条连续在场不必三视图」，Q2 有答案了 |
| 武器只写在角色提示词里（红绸皮鞭/麻绷带） | ✅ 印证「贴身媒介不必单独锁」，Q1 有答案了 |
| 结尾尬 | ⚠️ 属导演层，不是资产层 → 用收尾三型修，加三视图无用 |

**所以单条连续在场的工作流是对的**，只需把结尾换成余韵型/拔高型即可。
