## 〇、一句话结论

**棂 10-07 的五连全部是「一人 + 召唤物群 + 巨型场景」的大场面路线**，

新技法集中在三处：**召唤物分层、尺度对撞、收尾不收在胜负上**。

## 一、召唤物：分层而非同款复制

`01` 早就有「群敌分层」的方法论（主敌/精锐/杂兵），这批把视觉证据补齐了：

| 层 | 数量 | 外观 | 证据 |
|---|---|---|---|
| 主角 | 1 | 兽耳/羽饰/红眼，**高辨识度符号** | 五条全有，占画面主体 |
| 中型召唤物 | 8–20 | **同款不同个体**：白狐群，体型毛色略有差异，围成半环或扇面 | new_1e95bee5（雪原围困）、new_311ec85b（浮空岛环列）|
| 环境级实体 | 1–3 | **巨型不可完全消灭的载体**：红伞、法阵光柱、坠落的陨石 | new_1e95bee5 红伞、new_4c71d720 光柱、new_311ec85b 陨石 |

**新技法**：召唤物不是"多开几个副本"，而是**围成几何形状**——
半环包抄（1e95bee5）、扇面列阵（311ec85b）、**从画面四周向中心挤压**（1e95bee5 结尾的白狐群把主角包在最中间）。

> 为什么这样有效：观众一眼能数清"有几个、在哪、往哪聚"，
> 这正是五维模型里「逻辑性」的可读性要求。

## 二、尺度对撞：用巨型物给主角当标尺

三条都用了**超大尺度的环境实体**（new_4c71d720 / new_311ec85b / new_f418fd1d）：

| 手法 | 描述 | 效果 |
|---|---|---|
| **垂直尺度** | 主角站在浮空岛边缘，身后是垂落到云海的瀑布 | 一眼给出"人是多小" |
| **地面尺度** | 脚下的光柱阵/符阵远大于身体，红光铺满地面 | 空间纵深被拉开 |
| **天体尺度** | 从行星地表拉远到太空视角（new_1c1816aa 尾帧：地球弧线 + 极光） | 收尾突然拔高，情绪从"打"变成"念" |

**可执行写法**：每条视频至少给主角一个 10 倍以上尺度的参照物，
且这个参照物**要么参与动作（被劈开/被踩过/被击穿），要么作为收尾的定格对象**。

## 三、收尾：不收在胜负，收在"余韵+ 拔高"

这是本次最值得吸收的一条，**正好对上你说的"结尾有点尬"**。

> **补充规则（王老师 2026-10-11）**：如果这条视频**只是打斗片段**（不讲情节与胜负）——
> **打到一半直接结束、不定格**（只有 A 余韵型可兼容；B/C 的静止收法不用）。
> 写法：最后一个动作只做到一半，镜头随动作快速拉开放走即止。

### 昨天我写的收尾（用户反馈：尬）
```
[28-29s] 傀儡向内缩一帧后无声炸散，骨钉化作白灰，符纸烧尽
[29-30s] 霜雾回落，残碑重新露出；沈霜降背对镜头立于阶上，双刀垂在身侧；
         一枚断裂伞骨落下插进水洼，涟漪扩散；白闪收黑
```
**为什么尬**：
1. 「骨钉化作白灰 + 符纸烧尽」= 模型要在0.5 秒内同时演两件事→ 降级成单纯炸散
2. 「背对镜头立于阶上+ 双刀垂在身侧」= 主体静止，**没有新信息**
3. 「信物落进水洼」= 硬加的抒情道具，观众没被引导去看它
4. 「白闪收黑」= 收在黑屏上，观众记住的是黑屏不是角色

### 棂的收尾（三条实测）
| 视频 | 最后 3 秒 | 手法 |
|---|---|---|
| new_1e95bee5 | 金粉飘散 → 主角被白狐群从四面**扑住** → 群狐定格 | **不收在胜负**：赢没赢不重要，被围住才是余韵 |
| new_311ec85b | 陨石坠地 → 火光沉入地平 → 主角背对镜头立于崖边，身后光环收束 | **尺度拔高**：从战场拉到天地全景 |
| new_4c71d720 | 红光脉动 → 悬浮符文阵 → 特写一只脚踩在光阵上 | **定格在一个具体动作上**，不做抒情 |

### 提炼出的收尾三型

> **适用范围（王老师 2026-10-07 裁定）**：收尾三型是**短视频（15–30 秒、不要求完整情节）**的收尾规则。
> **完整打斗片**（有成片结构、要求完整情节与胜负收束）**仍遵循收束三段式**：大招命中 → 余波回落 → 收黑，1 秒内完成。
> 判据见 `seedance25-prompt/references/10-动作戏与打斗.md` §22.2 第 7 条。

| 型 | 做法 | 适用 |
|---|---|---|
| **A · 余韵型** | 打完不停，让召唤物/环境继续动，主角被"结果"包围 | 群战、召唤物路线（**本作默认**）|
| **B · 拔高型** | 从战场尺度拉远到天地全景，最后 2 秒静止 | 史诗、大场面 |
| **C · 定型式** | 收在一个**具体可读的动作或物件**上（踩在光阵上/手按住伤口/回头） | 人物收束、要留人物印象 |

**共同点（三型都有）**：
1. **没有一个是白闪收黑**——5 条全没有
2. **最后 1-2 秒一定有"新东西"进入画面**（围过来的狐群 / 沉降的火光 / 收束的光环）
3. **定格在具体可读的画面上，不定格在情绪形容词上**

> 这就是"尬"的根因：**收在情绪上而不是收在画面上**。

## 九、群战弹药库增补（吸收自叩叩哥参考包，2026-10-11）

### 9.1 敌人强度阶梯（E1 → E2 → E3 递增）

| 阶 | 单位 | 配置 | 职责 |
|---|---|---|---|
| **E1 试探杂兵** | 2–4 个同制式 | 造型统一简洁、能力单一 | 让主角亮出基础身法与第一套招式；单个不抢特写，成组运动减少身份漂移 |
| **E2 精英 / 重装** | 少量 | 体型 / 武器 / 速度 / 防御 / 技能至少**两项**明显强于 E1 | 能挡住主角一次关键招并完成**有效反制**，逼出进阶招式 |
| **E3 首领 / 巨型** | 1 | 轮廓、尺度、压迫感、技能范围全片最高 | 必须能**改变战场结构**或制造大范围威胁，逼出主角核心大招 |

★ **换代要可读**：前一阶被击退 / 解除行动能力 / 甩出战区后，下一阶再从**更深区域**接管；
**禁止三档敌人同时挤在画面里**。每一阶必须有独立轮廓、主色、武器/能力与入场方式。
★ **入场菜单**（先见环境反应，再见完整敌人，禁凭空刷新）：门窗/墙体被撞开 ｜ 屋顶/高处落地 ｜
远景列阵逼近 ｜ 载具后冲出 ｜ 阴影中轮廓亮起 ｜ 空间裂口有过程地张开 ｜ 沿上一阶撤退方向追击入场。

### 9.2 场景破坏规模递增（S1 → S4，保留前级痕迹）

| 级 | 范围 | 表现 |
|---|---|---|
| **S1 局部物件级** | 杯盘、桌椅、门窗、石砖、栏杆、小型掩体 | 只给裂纹、凹陷、短距离碎屑与局部尘环 |
| **S2 房间 / 结构级** | 墙体、立柱、楼层、桥面、庭院、车厢、甲板分区 | 出现贯穿、错位、局部坍塌与跨房间冲击波 |
| **S3 建筑群 / 地形级** | 整栋建筑外壁、街区、山谷、舰体分区、城市高架 | 战线冲出原场景，破坏沿明确方向连续扩散 |
| **S4 地标 / 天象级** | 巨塔、城门群、山体外壳、巨舰主体、能量穹顶、云层 | 只给最终首领战与末招，形成全片唯一最大视觉尺度 |

★ **递增写法**：上一层破坏痕迹在后续镜头**仍可见**，新一层从旧痕迹向更远处扩展；
**不可 S1 直跳 S4**，也不可大招之后又退回只砸桌椅。

### 9.3 动势衔接词库（治"疯切 → 疯乱 / 发飘 / 接不上"）

* **接力连词**（缝合相邻招式/切点）：顺势、借力、劲道不断、收招不停、一气呵成、衔尾续挥、承着上一击、势头未歇、余力顺转、劲走连贯
* **方向延续**（切前切后同向 · match-cut）：顺同一弧线续挥、残影链指向落点、速度线顺移动方向铺满、自上一击落点直接续出、动势不折、切点落在挥砍/突进中途
* **弧线跟随**（给动作留收势）：完整挥出带 follow-through、收势自然坠落、惯性带动身形续转、末端拖尾顺势甩出
* **反面禁写**：相邻两镜方向/姿态互不相干地硬拼 ｜ 在静止帧/姿势停顿处切 ｜ 只写发力帧不写承接

## 十、S 级多人群战电影化规范（吸收自叩叩哥参考包，2026-10-11）

> 来源：S 级多人群战视频拍摄 SKILL（飞驰影漫社）。适用：仙侠 / 玄幻 / 国漫 3D / 武侠 / 奇幻战争。
> 核心目标：**大场面看得出规模，中场面看得懂局势，近场面看得清动作；群战不乱、主角不丢、攻防有因果、情绪持续升级。**
> 定位：本条是 **90–120s 级群战**的规范；15–30s 短群战精选 §九 的 E 阶 / S 阶弹药即可。
> **交付形态（与 R9 配合）**：90–120s 是**成片总时长**；单条生成仍 ≤30s（`13 R9`）→ 必须走**形态 B 多镜剪辑**（SKILL.md 交付形态判定），五阶段各拆 2–4 条单镜，跨镜用 `16 §四` 连续性三件套 + `16 §二` 切点规则衔接；或与 seedance25-prompt 的延长接力配合。

### 10.1 铁律：不要"所有人同时乱打"

每段战斗先定六件事：**双方阵营位置**（甲军哪侧 / 乙军哪侧）｜**主攻方向**（左→右，整段不翻轴）｜
**战场纵深**（前 / 中 / 远景各是谁）｜**本段目标**（夺旗 / 破阵 / 斩将 / 突围 / 守城）｜
**胜负变化**（谁先占优、何处反转）｜**主角位置**（在哪条战线、面对谁、下一步去哪）。

> 一句话原则：每一个镜头都必须让观众同时看懂"谁在打谁、往哪打、为什么打、打完局势有什么变化"。

### 10.2 群战五层结构（不是一镜到底）

| 层 | 内容 |
|---|---|
| 1 战争格局 | 两军规模、地形、天空、旗帜、战鼓、阵势与压迫感 |
| 2 冲阵碰撞 | 谁先冲、冲击方向、骑兵/先锋如何撕开第一道防线 |
| 3 局部绞杀 | 从小区域切入：盾阵、刀阵、弓箭手、法修、精锐小队 |
| 4 主角线 | 镜头始终回到主角：面对的强敌、战术目标、受伤与突破 |
| 5 局势反转 | 敌军增援 / 主将出手 / 护城阵崩裂 / 妖兽降临 / 旗帜倒下 → 推动下一阶段 |

### 10.3 战场空间设计（防漂移）

**固定空间轴线**（以观众视角为准）：己方军阵=左/左前 ｜ 敌方军阵=右/右后 ｜ 中央杀场=中 ｜
己方后阵=左后（弓兵/法修/医疗/战鼓）｜ 敌方后阵=右后 ｜ 高空战区=上 ｜ 地下战区=下/地裂。

**连续性强制**：己方绝大多数镜头**朝右攻击**、敌方**朝左**；若必须换方向，先用俯拍大全景/环绕重建轴线；
主角冲入中央后不能无过渡出现在远端；**每一次突破补一镜"冲过谁、越过什么、落在哪里"**。

**可识别地标 5 资产**（防场景漂移）：己方主旗（色/图腾）｜ 敌方主旗（与己方明显不同）｜
中央地形（壕沟/巨石/断桥/碑阵）｜ 高点建筑（城墙/山坡/祭坛）｜ 战场天气（黄沙/暴雨/雪夜/夕阳/雷云，**只选一套主基调**）。

### 10.4 群战镜头五阶段（90–120s 模板）

| 阶段 | 时间 | 要点 |
|---|---|---|
| **A 战前压迫** | 6–10s | 高空超远景（两军对峙）+ 地面低机位（靴/马/兵器/握紧的手）+ 主角特写 + 敌将特写（开战信号）。节奏"安静→局部细响→鼓点→爆发"；别立刻铺满爆炸，鼓点/风声/盔甲摩擦比台词重要 |
| **B 第一轮冲阵** | 10–18s | 攻防链：战鼓落 → 前锋冲刺 → 弓法压制 → 盾阵顶住 → 骑兵/重甲撞入 → 首次兵器碰撞 → 中央失控。**动作逻辑链**：加速冲刺→兵器先触→身体受力后仰→阵线挤变形→后排顶上→被击飞者撞倒友军→缺口形成（不是"人冲过去就飞"） |
| **C 局部绞杀** | 15–25s | 每个局部只聚焦 **3–8 个可识别角色**（不能一镜塞几十张脸）；模块轮换：盾阵硬顶 / 骑兵穿插 / 弓法压制 / 空中剑修对撞 |

### 10.5 群战运镜库 + 禁止事项

| 用途 | 推荐运镜 | 效果 |
|---|---|---|
| 展示规模 | 高空俯拍 / 航拍横移 / 持续拉远 | 大、稳、清楚 |
| 冲阵速度 | 贴地跟拍 / FPV 穿阵 / 低机位前冲 | 快、狠、压迫 |
| 正面碰撞 | 横向平移 / 正面后拉 / 震动镜头 | 阵线冲击 |
| 主角突围 | 环绕跟拍（≤180°，`12 §6.6`）/ 侧后跟拍 / 希区柯克变焦 | 主角突出 |
| 刀剑近战 | 近身手持感 / 短促横移 / 动作定格（按 `13 R19` 分流） | 看清招式 |
| 重击爆炸 | 撞击定格（按 `13 R19` 分流）/ 镜头震动 / 快速拉远 | 力量反馈 |
| 法术覆盖 | 高空俯冲 / 仰拍升空 / 横向掠过 | 法术规模 |
| 局势反转 | 从人物上摇至天空 / 由局部拉至大全景 | 危机扩大 |

**禁止**：全程 FPV 乱飞 ｜ 连续多镜同样横扫或爆炸 ｜ 镜头运动比人物动作快导致看不清 ｜
每个角色都飞天、每件兵器都发光 ｜ 只拍主角脸不交代战场胜负 ｜ 只拍大全景看不清谁赢。

### 10.6 景别配比（90–120s 群战）

超远景/远景 15%（建立战场、重置轴）｜ 全景 25%（冲阵、阵形）｜ 中景 25%（小队交锋）｜
中近景 15%（主角拆招）｜ 特写 15%（眼神/兵器碰撞/阵眼）｜ 主观/非常规 5%。

**规则**：连续两个特写后必须回中景/全景重建空间；连续两个大全景后必须切进局部人物（给情绪落点）。

### 10.7 群战特效分层（四层）

| 层 | 内容 | 纪律 |
|---|---|---|
| **环境层** | 风沙/灰烬/飘雪/雨水/黑雾、战旗飘动、碎石滚落、远处术法闪烁 | 始终存在，但不抢戏 |
| **战术层** | 阵营色可识别：己方青白/金白/玄黄，敌方黑赤/土黄/暗紫；箭雨/盾阵/剑阵/法阵有固定视觉语言 | 同阵营特效不跳色 |
| **动作层** | 剑气跟剑锋轨迹、拳风跟受力方向、地刺由下破出、雷法由天劈落、卸力气流沿转腰沉肩方向 | 只跟攻击走 |
| **高光层** | 只给关键一击：短暂停顿→静音半拍→能量压缩→一击释放→冲击波→敌我反应→余波落尘 | 全片极少次 |

> **高光静音法**：关键一击前环境声瞬间抽空 0.2–0.5s，只留心跳/耳鸣；击中后所有声音回灌，冲击力明显提升。

### 10.8 输出前强制自检（10 条）

阵营颜色/旗帜/服装/武器语言固定了吗 ｜ 攻方方向全程稳定吗 ｜ 每隔 5–8 镜重建战场空间了吗 ｜
主角始终有明确位置/目标/路径吗 ｜ 大招有蓄力/释放/命中/破坏/余波五步吗 ｜ 群演避免无意义重复挥砍了吗 ｜
有前/中/远三层战斗信息吗 ｜ 宏大战争与局部情绪镜头交替了吗 ｜ 每次重击的受力/击飞/落点写了吗 ｜ 结尾有局势反转或更强危机吗。

> **执行口诀**：先定阵营，再定方向；先看大局，再切局部；先有受力，后有特效；先有目标，后有高光；**一镜一因果，三镜一变化，十镜一反转**。
