## 二、15 秒逐秒骨架（棂的红中道人结构，三条路线通用）

以下表格即 SKILL.md 提到的「时间轴骨架」，2D / 真人 / CG 三条路线都可套用，
只需替换景别与动作的内容（2D 换成残影链/集中线，真人换成近身缠斗，CG 换成光效几何）。

| 时间 | 功能 | 写法要点 |
|---|---|---|
| 0–1s | **首帧即战** | 不插空镜；低机位中近景贴面；环境压迫纵深 |
| 1–2s | 试探/第一次交锋 | 远程/中距攻击 + 主角连续 5 个化解动作，末尾两帧白闪硬切 |
| 2–3s | 第一次错位 | 空间/方位突变，敌人弹射逼近 |
| 3–4s | 高压封锁 | 俯拍封位 + 主角借环境分流卸力 |
| 4–5s | 二次错位 | 视角滚转 180°，真假身分野 |
| 5–6s | 主角逆境反打 | 被控 → 自救 → 连击 3 点（每点不同方向速度线） |
| 6–7s | 撞击峰值 | 微观碰撞特写 → 硬切大全景，冲击环扩散 |
| 7–8s | 阶段转场 | 逼退主角，战斗进入第二阶段 |
| 8–9s | **唯一一次名场面大升格** | 默认稿使用；命中微升格另计。多参考图易停死平台改闪帧+持续微动（`13 R2`） |
| 9–11s | 敌人大招 | 密集封锁网 + 主角穿网（5 个连续动作） |
| 11–12s | 主角夺回主动 | 抛武器/夺武器，牵引全场力量 |
| 12–13s | **密度拉满** | 7 个连续动作，每 0.2s 疯切镜头 |
| 13–14s | **大招定音** | 静 1 拍面部超近景 → 瞬移贴脸 → 结界/必杀 |
| 14–15s | 崩解收尾 | 按体裁与输入方式选收尾（完整片默认三段式，多参考图可扩散即止；短视频→收尾三型，见 `08 §三`、`25 §四`） |

## 三、30 秒扩展

按「0–10s 起战与试探 / 10–20s 升级与错位 / 20–30s 大招与崩解」三段各铺 2–3 个回合，
中段默认插入唯一一次名场面大升格，命中微升格另计；多参考图易停死平台按 `13 R2` 改闪帧。短视频收尾走 `08 §三` 收尾三型（**不要白闪收黑**）。

### 节奏密度上限（防“每秒一个新点子”）

* **默认逐拍执行级**：仍按 0.5–1s 设计动作节拍，但相邻节拍必须服务同一攻防因果；不能每拍换机制、换能量或换地点。
* **多参考图导演简写**：走 `25`，30s 通常合并为 7–8 段，每段 2–4 个连续动作；不是减少设计，而是把同一交锋的微拍合并成可读段。
* 新机制、尺度跳级、换地点各最多 1 次并尽量靠后；多数段让同一打法更快、更密、更重。多参考图平台此项为硬上限，其他输入作为防堆料约束。
* 能量不超过 3 种、同时出手不超过 2 种是**上限而非配额**；写实路线仍默认 `12 CG-2` 的单一主色，不为凑满上限加色。

### 时间预算铁律（2026-10-11 实战反馈后加）

**先算时间，再写 beat；总时长 = 各 beat 时间之和，超配的 beat 一律前移或删掉。**

* 末段（最后 7s）至少留给 **2 个完整 beat**，每个 beat **≥3.5s**；纯打斗片段收尾不定格（见 `SKILL.md §四`）。
* **严禁把大段空间调度挤进末尾 3.5s**（例：穿层 + 入中庭 + 缠斗三段塞进最后 3.5s）——
  实测模型会直接吃掉这个 beat，**视频在上一拍就结束**（v5 紫峰大厦版：中庭栏板滑行后视频即止，收尾全部丢失）。
* 换景 / 穿层 / 下楼这类"推进型 beat"要**占满自己的时间**，且由上一拍的物理动作（坠落 / 破窗 / 撞击）承接。
