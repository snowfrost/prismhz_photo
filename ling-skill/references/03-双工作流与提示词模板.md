# 03 · 双工作流与提示词模板

## 一、分流决策（先问这三句）

1. 要**2D 动漫**还是**真人写实**？
2. 时长 **15s** 还是 **30s**（Seedance 2.5 单条上限 30s）？
3. 谁赢、用什么收尾（击杀 / 打退 / 收刀 / 崩解）？

> 棂的实测：真人路线不适合高武打斗与处决技；2D 路线全套放开。混合题材（武侠+奇幻）默认 2D。

## 二、工作流 A · 2D 动漫赛璐璐（高武打斗首选）

### 全局约束（一镜到底时只写一次）

```
严格以统一转绘后的首帧作为整段视频的唯一视觉基准，@图片1 主角的脸型、发型、妆面、服装、饰件与武器全程稳定不漂移；
全片核心风格固定为：纯平面2D剧场版赛璐璐、细密手绘线稿、硬边分层阴影、冷青月光与<强调色>对撞、局部水墨烟尘、胶片颗粒、极强作画张力，发丝与布料持续运动。
禁止：3D CGI、游戏引擎感、2.5D木偶感、塑料皮肤、低成本国漫CG、人物脸崩、武器变形、普通站桩对砍。
全片持续运动，仅允许一次极短升格且不能变成静止摆拍。
```

### 15 秒逐秒节拍（棂的红中道人结构，可直接套）

| 时间 | 功能 | 写法要点 |
|---|---|---|
| 0–1s | **首帧即战** | 不插空镜；低机位中近景贴面；环境压迫纵深 |
| 1–2s | 试探/第一次交锋 | 远程/中距攻击 + 主角连续 5 个化解动作，末尾两帧白闪硬切 |
| 2–3s | 第一次错位 | 空间/方位突变，敌人弹射逼近 |
| 3–4s | 高压封锁 | 俯拍封位 + 主角借环境分流卸力 |
| 4–5s | 二次错位 | 视角滚转 180°，真假身分野 |
| 5–6s | 主角逆境反打 | 被控 → 自救 → 连击 3 点（每点不同方向速度线） |
| 6–7s | 撞击峰值 | 微观碰撞特写 → 硬切大全景，冲击环扩散 |
| 7–8s | 阶段转场 | 逼退主角，战斗进入第二阶段 |
| 8–9s | **唯一一次升格** | 眼部微距起，倒退中定点，反作用力位移 |
| 9–11s | 敌人大招 | 密集封锁网 + 主角穿网（5 个连续动作） |
| 11–12s | 主角夺回主动 | 抛武器/夺武器，牵引全场力量 |
| 12–13s | **密度拉满** | 7 个连续动作，每 0.2s 疯切镜头 |
| 13–14s | **大招定音** | 静 1 拍面部超近景 → 瞬移贴脸 → 结界/必杀 |
| 14–15s | 崩解收尾 | 敌人向内缩一帧 → 无声炸散 → 余波回落 → 白闪收黑 → 信物落下 |

### 30 秒扩展

按「0–10s 起战与试探 / 10–20s 升级与错位 / 20–30s 大招与崩解」三段各铺 2–3 个回合，中段插入唯一一次升格，末尾保留 1s 余波收黑。

## 三、工作流 B · 真人写实（武侠文戏式交手）

* 动作幅度收敛，回合少（2–3 回合），每回合以"拔刃—交错—分开"的清晰因果呈现
* 镜头以 OTS 正反打 + 大远景对峙 + 近景缠斗 + 俯拍落地为主
* 环境必须参与：竹叶遮挡、湿石水光、雨雾空气透视
* 收尾用**遮挡式留白**（竹叶/衣袖/雨幕挡住镜头后切景），不做处决
* 禁止：血腥、断肢、处决技、超自然特效参考图

## 四、输出格式（Seedance 2.5）

优先时间戳分镜式，可合镜：

```
[0–1s] 景别/机位：… 动作：… 反馈：…
[1–2s] …
```

单条 ≤30s；全局约束（角色锁定 + 风格锁 + 禁用清单）只写一次，段内不重置站位。
