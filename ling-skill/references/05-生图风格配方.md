## 二、每一段写什么

| 段 | 要点 |
|---|---|
| 人物与动作 | 姿态 + 手持物 + 一个可见的微动作（雨丝击打剑身/衣袖静垂） |
| 服饰与材质 | 结构（立领交领/窄袖/护片）+ 材质对比（金属 × 织物）+ 状态（被雨浸透） |
| 环境与纵深 | 前中后景分层写清（前景细雨 / 中景主体 / 后景虚化光点） |
| 镜头语法 | 景别 + 机位高差 + 焦段（50mm 中近景 / 85mm 半身）+ 裁切线 + 焦点落点 + 景深 |
| 光影 | 环境光基调 + 对撞辅助光 + 边缘光位置 + 空气透视 |
| 超清 | 明写要读到的纹理层级（水滴/纤维/钢铁细纹） |

## 三、棂的角色 DNA（默认值）

* 写实皮肤质感（保留血色与细微纹理）**× **幻想元素（兽耳、金属机械、符饰）
* 米白 / 银白主调 + 单点高饱和强调（朱红、青蓝）
* 强光比、边缘光切轮廓、逆光发丝
* 9:16 竖幅，人物占画 2/3 以上，浅景深
* 材质密度高：蕾丝、流苏、锁链、金属件、旧织物

## 四、工作流（他的实际做法）

1. 先出**单张形象参考图**（他"风格一直是玩单参考图"）
2. 第一张可用其他模型垫图，后续 **MJ 垫 MJ**（原话"第一张用gpt的图垫 后面就mj的图垫mj好了"）
3. 参考图选**近景人像**效果最好（原话"传近景人像感觉效果比较好"）
4. 用"反推画风描述"从已成图提取风格词，再回写提示词（原话"材质就mj的图反推吧""反推画风描述就好了"）
5. 参考图直接作为视频首帧喂给 Seedance 2.5
