# 13 · 质检红线（生成前 / 生成后两段式）

> **用途**：这是本 skill 的**强制关卡**。任何打斗提示词在交付给用户之前，
> 必须逐条过完 §一（生成前自检）；用户回传成片后，必须逐条过完 §二（生成后诊断）。
> **判定原则**：任一条命中"红线"，**该提示词/成片即判不合格，必须回炉**，不得交付。
> 层级：红线（必过）> 建议（尽力）。红线共 **20 条**（R1–R20；第 0 关画风 R0 为单项否决）。
> R16–R19 为 2026-10-11 吸收叩叩哥参考包新增；R20 为 2026-10-16 王老师批准新增。

## 一、生成前自检（写提示词时，逐条打勾）

### 第 0 关 · 画风（最易错，必须最先过）

| # | 红线 | 判定方法 |
|---|---|---|
| **R0** | **画风已锁定且只有一套** | 用户没说"2D/动漫/番剧/水墨"→ 必须走 `07` 写实路线；说了 → 走 `10` 2D 路线。**两套风格锁不得混写**。混写 = 直接不合格 |

### 第 1–5 关 · 五维齐备

| # | 红线 | 判定方法 |
|---|---|---|
| **R1** | **打击感：每次接触有可见反馈** | 逐格检查每个"攻/击"是否写了：对撞特写帧 or 尘屑粒子 or 短促震镜 or 冲击环。**有接触无反馈 = 不合格** |
| **R2** | **节奏：首帧即战 + 动静相位** | 第一格必须是攻防动作（不得空镜/铺垫）；全片至少一次"静一拍再爆发"；**升格两级制**：名场面大升格（≥1s）全片 1 次、只给三处，普通连招不得用；命中拍微升格 0.3–0.5s（`16 §2.3`）属接触反馈、可多次、不计入 |
| **R3** | **镜头：站别/机位在服务动作 + 切点密度下限** | 不得出现"站桩正打"。必须使用至少 3 种机位（低机位/OTS/环绕/俯拍/前景遮挡）。**切点密度下限（2026-10-16 增补）**：机位事件数 ≥ 时长秒数 × 0.8（基准：红中道人模板 15s 15 格 ≈ 1s/格）；高潮/近战段 ≤1s/切。只数机位种数不数切点频率 = 不合格 |
| **R4** | **逻辑：攻防因果 + 空间不重置** | 每回合可见"攻→挡→退→反击"；全段同一空间坐标系，**机位变化不得让站位跳变** |
| **R5** | **丰富性：招式/环境/群敌有变化量** | 单人 ≥3 招；环境元素必须参与动作；群敌必须分层（主敌/精锐/杂兵） |

### 第 6–9 关 · 硬约束

| # | 红线 | 判定方法 |
|---|---|---|
| **R6** | **禁用清单已整段附上** | 提示词末尾必须带禁用段（风格禁用 + 通用禁用）。**缺禁用段 = 不合格** |
| **R7** | **每个动词写了形态/方向/结果** | 禁止"喷火""攻击"这种单词。必须是"喷出锥形火柱向左侧横扫"这种完整动作 |
| **R8** | **角色/武器已锚定** | 有 @图片引用或文字锁（脸型/发型/服饰/武器）；武器全程同一，**禁止变形、禁止中途换** |
| **R9** | **时长与站位合规** | 单条 ≤30s；一镜到底只写一次全局约束；段内不重复写站位重置 |

### 第 10 关 · 收尾（按体裁分流，治"结尾尬"）

| # | 红线 | 判定方法 |
|---|---|---|
| **R10** | **收尾选对型** | 完整打斗片 → 收束三段式（大招→余波→收黑，1s 内）；15–30s 短视频 → 收尾三型（`08 §三`），**禁白闪收黑** |
| **R11** | **最后 1–2 秒有新东西进入画面** | 围过来的群兽/沉降的火光/重新亮起的灯。**主体静止摆拍收尾 = 不合格** |

### 第 11–14 关 · 路线专属（按所选画风二选一）

| # | 红线（写实/CG 路线） | 红线（2D 路线） |
|---|---|---|
| **R12** | 手绘插画感、二维赛璐璐分色 → **禁止出现** | 写实摄影机成像、浅景深毛孔质感 → **禁止出现** |
| **R13** | 血腥断肢、处决特写 → **禁止** | 多色高饱和同时出现 → **禁止**（只留单/双色刃光） |
| **R14** | 能量特效必须单色系、只在冲击/大招帧出现 | 动作痕迹必须抽象（墨迹/笔触/集中线），不得用实体粒子 |

### 第 15 关 · 逻辑锁（R15，空间调度复杂的打斗必过）

> 源自 2026-10-11 紫峰大厦垂直打斗实战（王老师四连反馈，v5 全踩、v6 修正）。
> 凡是"多空间连续推进"（穿层 / 下楼 / 追逐 / 连续换景）的打斗，**必须手写一段【逻辑锁】**，
> 逐条写死下列四问；写不出来 = 这条提示词还没想清楚，不许提交。

| # | 红线 | 判定方法 |
|---|---|---|
| **R15** | **逻辑锁四问已逐条写死** | ① **先后次序**：同一动作牵涉两人时，写明"谁先谁后"（先跳 → 触发下一拍 → 后追），**严禁"同时"**；② **一次性事件只许一次**：碎裂 / 破门 / 坠地这类不可逆事件，全片只出现在**一个** beat，其余 beat 只写前兆（裂纹 / 晃动 / 裂响）；③ **结构件不做支点**：栏板 / 栏杆 / 玻璃 / 扶手只做背景与遮挡，人物动作不得以其为受力面（**禁滑行、禁翻越、禁从外侧翻回**）；④ **换景有因果 + 末段有预算**：每次空间推进由上一拍的物理动作直接导致；最后 7s 至少 2 个完整 beat，每个 beat **≥3.5s** |

**反例（v5 实测，全部踩过）**：两人同时跳进吊篮 ｜ 玻璃前后碎两次 ｜ 被按在玻璃栏板上滑行、从栏杆外侧翻回 ｜ 末尾 3.5s 塞两个 beat → 视频在上一拍就结束。

### 第 16–19 关 · 交付形态与素材锚定（2026-10-11 吸收叩叩哥参考包）

> 适用范围：R16 写近景对招/连招时必过；**R17/R18 专用于 img2video（给了参考图）**；R19 只在使用定格/静一拍时适用。

| # | 红线 | 判定方法 |
|---|---|---|
| **R16** | **招式序列化（禁抽象频率）** | 近景对招 / 连招段必须**逐拍写招式链**：招式名称 + 攻击落点 + 防守/闪避反馈（例："右摆拳打脸→左勾拳打下巴→右直拳打鼻梁→左横肘切眉骨→右标指刺咽喉；防守方依次侧偏、下潜、拍开、架桥、后撤"）。**长近景段（4–6 拍）必须含肘击或指 / 腕变化**（源 `11 §6.5`；腿法 / 兵器近景用等效短程重拍，不强制肘击）。禁止用"每秒攻击 ≥N 次""每击间隔 ≤X 秒"等抽象频率参数替代动作链——AI 对定性节奏词执行偏差约 30–40% |
| **R17** | **首帧锚定（img2video）** | 给了参考图 = 参考图是视频**第 1 帧**。镜头 1 必须从图中主体的**当前姿态、当前景别**直接启动，第一个动作是主体自身的起手（眼神骤变 / 拔刀 / 转身 / 蓄力 / 迎击）。**严禁**在开头加参考图里没有的环境空镜或运镜。镜头 2 后才进入疯切瞬移 |
| **R18** | **武器三级判定** | ① 明确武器（刀 / 剑 / 枪 / 弓 / 法杖）→ 锁定为**全片核心武器**，按真实攻击属性设计招式；② 可临时利用的工具（棍 / 伞 / 链条 / 折扇）→ 最多服务 **1–2 个动作节点**；③ 生活道具（茶杯 / 书卷 / 餐具 / 首饰）→ **默认不是武器**，镜头 1 内以放下 / 抛出 / 脱手 / 打碎等**动作因果退场**，退场后**不得再次生成、不得回到手中**；④ 图中无武器 → 默认空手格斗 |
| **R19** | **定格 / 静一拍按模型代际分流** | **2.0**：禁真定格（会停死）→ 用"**白闪 + 震镜**"替代定格；**2.5**：允许静一拍，但必须**绑流动元素**（衣摆 / 发丝 / 雨滴 / 尘埃持续在动）+ ramp 进出。裸停死帧 = 不合格 |

### 第 20 关 · 招式卡成卡与末段张力（2026-10-16 王老师批准新增）

> 源自 2026-10-15/16《弓箭vs长矛》三连实战（王老师三连追问：招式设定呢 → 为什么每次偷懒 → 节奏偏慢）。
> 病灶：R1–R19 管「不能错什么」，不管「必须做完什么」——招式卡被跳过、末段拿静一拍凑 beat，两层都不覆盖处即偷懒高发区。

| # | 红线 | 判定方法 |
|---|---|---|
| **R20** | **招式卡成卡 + 末段禁死静** | ① 有武器的角色**必须成卡**（六格制：身份一句话 / 武器媒介 / 战斗偏好 / 视觉签名 + 招式表 3 常规 + 1 破招 + 1 大招），每招标注词库底稿与变奏法（兵器库无现货 → 按降级路径取最近体系变奏，SKILL §六）；**未成卡，或分镜出现卡上没有的招式 = 不合格**；② 末段（最后 7s）**禁止静一拍占满整个 beat**——静一拍 ≤1s 且必须绑威胁升级 / 二次峰值结构（败者爬向武器 + 胜者搭弦威慑这类「不动手的峰值」）；拿「静」凑 beat = 不合格 |

## 二、生成后诊断（用户回传成片后，逐条排查）

### 高频崩坏模式速查表

| 症状 | 病根 | 处方 |
|---|---|---|
| **动作像站桩** | 提示词只写了一个动词 / 没写逐拍动作 | 回到 `01 §2.2`，每 0.5–1s 补一格动作 |
| **打击感软** | 接触帧没有反馈 | 补 `01 §1.1–1.6`：对撞特写帧 + 尘屑 + 震镜 + 冲击环 |
| **看不清谁打谁** | 站位混乱 / 缺 OTS / 缺前景层 | 回到 `01 §3.9`，锁死空间坐标系，加 OTS 正反打 |
| **穿帮（瞬移/武器变形）** | 站位重置 / 未锁武器 | 回到 `01 §4.3–4.4`，补参照物与武器恒定声明 |
| **结尾尬** | 用了白闪收黑 / 静止摆拍 | 回到 `08 §三`，换收尾三型 + 补"新东西进场" |
| **特效像 PPT** | 用了特效参考图 / 多色杂特效 | 回到 `02`，改纯文字描述 + 单色系 |
| **风格打架** | 写实与 2D 混写 | 回到 `07`/`10`，锁定单一路线 |
| **人物脸崩** | 缺角色锁 / 缺脸部锚点 | 补 @图片引用 + 焦点锁眼 |
| **同型事件演两遍**（玻璃碎两次） | 一次性事件被拆进两个 beat，模型各演一遍 | 该事件全片只写进**一个** beat；其余只写前兆（蛛网裂纹 / 晃动 / 裂响） |
| **两人同时入场 / 同时动作** | 没写先后次序，模型默认并行 | 写死"先 A 后 B"：A 的动作触发下一拍（如吊篮启动），B 再追入 |
| **被结构架空**（栏板滑行 / 栏杆外翻回） | 把栏板栏杆写成了动作受力面 | 结构件只做背景与遮挡；人物始终在**安全侧一步内**；借力只用地板与墙面 |
| **视频提前结束 / 末尾 beat 被吃** | 末段 beat 时间预算不足 | 末段 7s 至少 2 个完整 beat（≥3.5s / 个）；**总时长 = 各 beat 之和**，超配一律前移或删 |
| **近景对招稀薄**（全片只有远景大动作） | 缺 2–3s 上半身近景对招 | 按 `11 §六` 补一段机枪节奏近景对招（3轻1重 / 封破杀），逐拍写招式链 |
| **参考图漂移 / 首帧变了**（img2video） | 开头加了参考图里没有的空镜或运镜 | 按 R17 重写镜头 1：从参考图当前姿态直接启动 |
| **武器回手 / 道具复活** | 生活道具退场后又出现在手里 | 按 R18 执行：退场道具不得回手，重设动作因果 |
| **定格停死 / 静止尬** | 定格帧全画面冻结 | 按 R19 分流：2.0 换白闪 + 震镜；2.5 绑流动元素 + ramp |
| **近战武器逻辑违和**（弓绞杀 / 矛当枪托用） | 跳过武器战术定位分析，媒介不同源 | 按 SKILL §二 1.5 四维分析重做；进攻性近战答案改到同源媒介上（弓箭手 → 箭匕 + 弓防御） |
| **末段死静 / 泄气** | 拿静一拍凑 beat，无威胁升级 | 按 R20②：静一拍 ≤1s，改双峰结构（威胁升级 → 二次峰值） |

```
【诊断】逐维打分（0–10）：打击感 _ / 节奏 _ / 镜头 _ / 逻辑性 _ / 丰富性 _

```

## 三、本 skill 的自我质检（每次改完 skill 后跑）

1. **默认值是否显式**：SKILL.md 必须写明"默认画风 = 写实"，不能只列选项（历史两次栽在这）
2. **红线是否可判定**：每条红线必须有客观判定方法，不能是"打斗要好看"这种主观描述
3. **证据是否可溯**：新增技法必须绑到 `14` 里的具体视频编号（或标注来源库名与入编时间）
4. **路线是否互斥**：写实禁用项与 2D 禁用项不得同时生效
5. **路由是否唯一**：一个任务只能命中一条路线，不得"既走 2D 又走写实"
