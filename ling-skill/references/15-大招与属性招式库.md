## 一、大招的默认骨架（15s 四段）

**核心认知：大招不是普通打斗的"延长"，是一次完整的"升级兑现"。**
前摇必须成立 · 聚能必须有异象 · 释放必须有明确路径 · 被击反馈必须有层次 · 结尾必须停在最有记忆点的画面。

### 1.1 四段时间分配（15s 单段大招）

```
0–2s    前摇 / 起势         （人物动作开始，气场启动）
2–5s    聚能 / 异象扩大      （云层塌缩 / 法阵亮起 / 粒子倒灌）
5–10s   技能主体释放         （攻击路径 + 清场）
10–15s  命中 / 终结 / 余波    （杀首领 + 环境遗留 + 停高峰）
```

30s 短视频里大招段照此四段等比例扩展；更短的（8–10s）按同逻辑压缩，但**四段顺序不得换**。

### 1.2 分镜时长铁律（硬性）

| 规则 | 数值 |
|---|---|
| 任意单个分镜时长 | **≤4s** —— 4s 内必须有明确分镜 |
| 15s 成品分镜数 | 建议 **4–6 个**（推荐拆法 0-2 / 2-4 / 4-6 / 6-10 / 10-15） |
| 每个分镜至少含（7 类中 ≥3 项） | 人物动作 · 技能形态 · 能量变化 · 运镜方式 · 环境反馈 · 被击反馈 · 空间变化 |
| 分镜写法顺序 | **时间 → 分镜内容总结 → 景别 → 分镜内容** |

```
分镜三：4-6秒。【聚能异象】景别：高空俯拍转中景。分镜内容：……
```

### 1.3 结尾停在高峰（与 `08 §三` 收尾规则配合）

大招段的**最后一秒**优先停在：命中瞬间 / 轰杀瞬间 / 爆炸吞没瞬间 / 巨型法相压下瞬间 / 剑阵合拢瞬间 / 冰封完成瞬间。
**禁止**把"安静收尾 / 慢慢散去 / 平静落地"作为大招段主画面——大招段不是收尾段，收尾选型仍走 `SKILL.md §四` 体裁分流。

## 二、六层设计语言（至少成立 4 层，最好 6 层）

生成大招时不能只写"某种元素很强"，要同时设计六层。**少于 4 层明确成立 = 通常不够国漫级**。

| 层 | 设计方向（可选） |
|---|---|
| **1 · 起势层** | 单手抬起周围粒子倒流 / 双手结印阵纹层层亮起 / 身体悬空衣袍被气场托起 / 武器轻震空间先裂 / 目光锁敌，四周先失真 |
| **2 · 聚能层** | 云层塌缩 / 地面亮纹扩张 / 粒子倒灌 / 法阵旋转 / 神兽法相渐成形 / 多层异象由小到大叠加 |
| **3 · 主体形态层** | 光柱·火柱·雷柱 / 巨型法相 / 神禽·凶兽·霜龙·雷兽 / 剑阵·剑河·万剑轮 / 火莲·冰镜·古印·大钟·天碑 / 扇面冲击波·环状震荡圈·漩涡吞噬核 |
| **4 · 清场层** | 扫荡型（横推一整片）/ 点杀型（高密度不规则连锁击穿）/ 压制型（先压跪再清空）/ 吞没型（火海·寒潮·雷网·剑雨持续覆盖）/ 追猎型（自动锁敌追击） |
| **5 · 首领终结层** | 必须比清场**升级至少一项**：体量 / 速度 / 材质 / 法相 / 镜头 / 结果。常见：正面贯穿 / 法相压下 / 多重封锁后中心处刑 / 塌缩瞬爆 / 抹除式湮灭 / 冻结后粉碎 |
| **6 · 余波层** | 世界要留痕：地面巨坑 / 熔浆外翻 / 雷痕烧灼 / 剑痕撕开云层 / 冰层蔓延不止 / 空间裂纹迟滞崩开 |

> **层与层的递进**：清场层与首领终结层**不能只是"威力变大"**——必须有**形态升级**
> （例：清场用雷网覆盖 → 终结收成单点雷兽光柱贯穿首领），否则判"层级不够"。

## 三、三条硬铁律

### 3.1 双成品铁律

正式成品默认输出**两条**：`标准版`（完整、稳、清晰）+ `强化版`（更狠、更炸、更有终结感）。
两条必须**同题不同拍法**——在以下维度里**至少 3 项**拉开差异，不能只换近义词：

起势方式 · 异象规模 · 技能主体形态 · 被击反馈层级 · 终结画面的凶狠度 · 镜头路径

### 3.2 参考不照抄铁律

参考模版的**结构强度 / 镜头密度 / 节奏推进 / 清怪+杀首领的层级感**——
但不复刻它的句子、路线、异象（不许"每条大招都是雷云+双龙+雷兽换个颜色"）。
给了火系 / 冰系 / 剑仙飞剑，必须长出该属性**自己的视觉语言**。

### 3.3 成品语言风格

读起来"像已经能拍出来"，不是概念大纲：
电影化 · 高密度视觉信息 · 明确的镜头运动 · 清晰的技能升级链 · 粒子/能量/空间/环境反馈丰富 ·
**分镜文字像专业镜头描述，不是抽象夸赞词堆砌**。

## 四、反同质化组合公式

同一属性要避免只剩单一路数，按公式组合：

```
主属性 + 设计母题 + 主体形态 + 清场方式 + 终结方式 + 环境遗留
```

示例（火系）：

| 组合 | 母题 | 主体形态 | 清场 | 终结 | 遗留 |
|---|---|---|---|---|---|
| A | 神话法相 | 朱雀火翼 | 俯冲扫荡 | 中心镇压 | 满地焦痕 |
| B | 爆燃毁灭 | 炎爆核心 | 正面横推 | 巨型爆燃球 | 火山裂地 |
| C | 唯美高级 | 火莲开合 | 花瓣吞没 | 中心爆燃处刑 | 飘浮火屑与红雾 |

示例（雷系）：`雷 + 天罚审判 + 雷云光环 + 不规则轰落 + 雷兽光柱处刑 + 雷痕遍地`；
`雷 + 极速贯杀 + 雷枪/雷刃 + 点杀型连锁 + 贯穿抹除 + 空间水纹震荡`。

> **硬性**：同一模板 / 同一属性 / 同一结局下，**至少改变 3 项**（起势 / 异象来源 / 能量材质 / 主体形态 / 清怪方式 / 终结方式 / 镜头母题 / 环境毁坏形式）。

## 五、三个热门国漫方向（学"设计语言"，不复刻 IP）

| 方向 | 提炼的设计语言 | 转成大招特征 |
|---|---|---|
| **凡人修仙传式** | 法宝驱动 · 阵纹符文层层展开 · 小起势带大后果 · 精密控制感 · 冷静理性但杀伤明确 | 技能不是一下炸开，而是逐层布阵→逐层锁定→逐层兑现；异象讲结构感；镜头强调"控制"与"精准命中" |
| **仙逆式** | 苍凉古意 · 天威压顶 · 极强精神压迫 · 空间/意志/规则层面的镇杀 | 前摇短但威压极强；聚能时周围**先失真、失声、失重**；本体带"天罚 / 古神 / 镇压 / 抹除"感；终结偏湮灭 |
| **完美世界式** | 太古宝术 · 神禽凶兽法相 · 巨物奇观 · 天地共鸣 · 肉身与法术同时爆发 | 主体形态更巨大更原始更兽性；不止能量柱，要"法相 / 凶兽 / 古纹 / 宝术洪流"；环境山川云层跟着共振 |

> 调用原则：**吸收特效方法，不照搬现成桥段**；不得写出具体 IP 的专有招式名。

| **首领终结** | 仰拍主技能锁定首领 / 特写终结前的极限压迫 / 命中一刻强冲击变焦或强透视 / 最后远景或环绕展示彻底湮灭 |

## 八、绝对禁止项（命中即回炉）

1. 不要所有属性都写成"**聚球 → 发射 → 爆炸**"。
2. 不要所有终结都只是"**敌人爆炸消失**"。
3. 不要**只换颜色，不换异象结构**。
4. 不要只写抽象压迫、**不写具体执行层**。
5. 不要把热门国漫的设计语言写成**具体 IP 招式复刻**。

---

## 九、生成前速查 + 反模板化自检

**生成前 5 问**：这条大招最强的视觉记忆点是什么？· 技能主体是什么形态？· 清场段和杀 boss 段是否明显升级？· 环境有没有留下真实痕迹？· **如果去掉颜色，这条大招是否仍有独特结构？**
——答不出来，说明还不够国漫级。

**写完后 5 查**（反模板化自检）：
1. 把属性颜色换掉，这条还成立吗？（成立 = 属性辨识度不够）
2. 去掉一个镜头名词，是否只剩"很炸很帅"？（是 = 执行层不够）
3. 把主角换人，是否几乎不变？（是 = 招式个性不够）
4. 清场段和杀 boss 段是否只是威力变大、没有形态升级？（是 = 层级不够）
5. 是否与参考模版过于相似？（是 = 创新度不够）
