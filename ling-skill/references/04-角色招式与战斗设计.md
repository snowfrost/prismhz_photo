# 04 · 角色招式与战斗设计

> 来源：棂原话「可以给skill加上给出场角色设计能力招式战斗偏好 就省事很多」（2026-09-12）。
> 本文件把这句话落成可执行流程。
> **2026-10-11 增补**：吸收叩叩哥参考包——§七 武学流派速查（20+ 一页纸）。

## 一、出场角色卡（每个角色必填六格）

| 格 | 内容 | 示例（红中道人一战的两位） |
|---|---|---|
| 身份一句话 | 一句话立住 | 驱祟散人 · 纸伞行者 |
| 武器/媒介 | 唯一武器，全程不变形 | 黑灰旧纸伞（24 根伞骨） |
| 招式 3–5 | 每招一句动作定义 | 闭伞反敲 / 半开弹回 / 旋伞卸力 / 伞柄勾荡 |
| 大招 1 | 定音技，需结界或范围定义 | **伞狱结界**：24 骨亮起，压缩全场力量于极小范围 |
| 战斗偏好 | 打法的价值取向 | 借力卸力、以守为攻、以环境判位 |
| 视觉签名 | 一眼认出的元素 | 湿发、耳侧铜铃、朱红眼妆 |

## 二、招式与武器必须同源

棂的实测反例：**"2抽象武器还是打不起来"**（2026-09-14）。
抽象武器（无形态、无物理逻辑）会让模型无法生成可信动作。规则：

1. 武器要有**明确形态 + 明确握法 + 明确运动类型**（刺/劈/旋/挑/勾/砸）
2. 招式命名要能翻译成动作短语（"闭伞反敲"能画，"强大的一击"不能画）
3. 同一招在不同回合要有**变体**（反敲→反挑→柄端顶偏），而不是重复同一击

## 三、对手设计（BOSS）

* 必须与主角形成**打法对照**：主角借力卸力 ↔ BOSS 高压压制
* BOSS 的存在感靠**规则与压迫**，不靠拟人化（麻将牌头不许长脸）
* BOSS 至少 2 个阶段：常态 → 满局（如"满堂赤局"：数十张牌影布满空间）
* BOSS 的崩解要写清"缩一帧再炸散"，而不是直接消失

## 四、群敌分层（丰富性来源）

| 层级 | 数量 | 作用 | 证据 |
|---|---|---|---|
| 主敌 | 1 | 决斗、承担大招 | 红中道人、兽人首领 |
| 精锐 | 2–4 | 夹击、打断节奏 | V56 兽人战士 |
| 杂兵 | 8–20 | 密度与包围感，同款不同个体 | V11 骷髅水手、V43 白狐群、V3 黑甲兵 |

杂兵尽量写"同款不同个体"（同装备、不同姿态/体型/损毁度），避免生成重复粘贴感。

## 五、召唤物与道具

棂原话：「还可以文生召唤物战斗 2.5是有点离谱」（2026-10-01）。
可用：召唤兽（白狐/白虎/龙）、道具阵（符纸/红线/牌阵）、地形机关。
写清三件事：**出现方式 / 行动规则 / 被清除方式**。

## 六、战斗偏好 → 提示词落地模板

```
【角色】<身份>，武器<唯一武器>，招式<招1/招2/招3>，大招<大招名+效果>，
战斗偏好：<借力卸力/以快制慢/……>，视觉签名：<白发+铜铃+朱红眼妆>。
【对手】<身份>，武器<…>，阶段一<…>，阶段二<…>，崩解方式<缩一帧再炸散>。
【本段回合安排】R1：<攻防因果> → R2：<升级> → R3：<大招定音>。
```

## 七、武学流派速查（20+ 一页纸 · 吸收自叩叩哥参考包）

> **用途**：给角色设计"战斗偏好"时先选**武学底子**——流派决定招式命名、节奏性格
> （顿挫型 vs 圆活型）、特效质感与适配镜头。**选 1 主战 + 1–2 辅修即可**，不必堆流派。

| 空手道 | 一击必杀 · 直线 | 正拳 / 手刀 / 跳踢 | 顿挫 |

| 螳螂拳 | 快刁缠 · 连续转 | 翻跌出腿 / 连环转 / 勾搂采挂 | 快频 |

> **顿挫 vs 圆活 = 视觉性格**：顿挫型（八极/咏春/泰拳）"砰。砰。砰砰。"炸点式；
> 圆活型（太极/八卦/合气）"～～～～"流水式。"刚 vs 柔"要让观众感到**整套节奏体系在打架**，不只是招式不同。

### 7.2 兵器与身法体系（素材专项库速查）

| 体系 | 内容 | 定位一句话 |
|---|---|---|
| 9 套剑法 | 武当太乙玄门剑 / 武当六路 132 式 / 杨式 55 式太极剑 / 独孤九剑 / 华山基础剑法 / 玉女十九剑 / 峨眉白猿二十四剑 / 青龙剑 32 式 / 峨眉子午剑 | 从道家圆转到破绽猎手，九种剑格 |
| 长柄镰刀 | 正统死神长柄镰刀（写实、**无锁链无幻术**） | 中远距斩劈清场 + 镰钩卸械 |
| 太刀 | 梦想一心太刀术（胸口拔刀 / 无想一刀）；绯雪樱灼流单太刀（常世身+预求身双形态） | 居合快斩与霜樱双形态 |
| 轻功 | 高级轻功体系（25 核心式：借力 / 换气 / 折身 / 换向 / 回落 / 再起） | 非魔法化位移，**禁无理由飞行** |
| 修仙 | 修仙高级剑招体系（25 核心式：御剑 / 剑阵 / 剑墙 / 飞剑远杀 / 虚空裂斩） | 仙侠尺度 + 清晰剑招结构 |

### 7.3 选型公式

```
主战流派（性格匹配角色）+ 辅修（补短板）+ 身法/轻功（位移）+ 兵器（如有）→ 招式卡六格（§一）
```

示例（源自参考包）：冷酷破绽猎手 = 独孤九剑 + 截拳道/咏春 + 武侠身法；
轻功宗师 = 高级轻功体系 + 剑法或截拳道（落点杀伤）+ 武侠身法（基础走位）。
**注意**：辅修是"补短板"，不是把两个流派硬拼——招式命名统一到一个语汇体系里。
