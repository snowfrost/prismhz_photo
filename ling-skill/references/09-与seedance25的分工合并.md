# 09 · 与 seedance25-prompt 的分工与合并（角色/武器/三视图问题）

> 本文档回答一个反复出现的疑问：**ling-skill 只要角色，seedance25-prompt 要角色+武器+三视图，到底该听谁的？**
> 结论：**不是二选一，是分层。** 打斗提示词 =资产层（seedance25-prompt）+ 导演层（ling-skill）。

---

## 一、疑问的根源：两个 skill 管的是不同层

| | seedance25-prompt | ling-skill |
|---|---|---|
| 管什么 | **资产层**——角色长什么样、武器长什么样、多镜头怎么锁一致 | **导演层**——这场戏怎么打、五维怎么落地、收尾怎么收 |
| 关键产出 | 人物四视图、道具图、参考图编号绑定、跨镜一致性 | 招式卡、节拍表、风格锁、特效语汇、收尾三型 |
| 解决的问题 | 「同一个人别换脸」「同一把刀别变形」 | 「别站桩」「别只放特效」「结尾别尬」 |

**两者不冲突，是同一部片子的上下游。**

```
[资产层 seedance25-prompt]  人物三视图 + 武器三视图 + 场景图 → 参考图①②③④
                                    ↓ 喂给
[导演层ling-skill]  五维打击模型 + 招式卡 + 节拍表 + 风格锁 → 完整视频提示词
```

---

## 二、直接回答你的三个疑问

### Q1：现在只控角色，不需要武器吗？
**需要。** 但不需要单独写「武器三视图」，而是要把武器**锁进角色的资产里**。

昨天那份稿子之所以能跑出满意的效果，是因为猫耳女用了「右前臂三圈红绸皮鞭」
这种**可穿戴于角色身上的媒介**——它本身就是角色外观的一部分，跟着人走就不会错。
但如果换成「她手里有一把长剑」而没有锁武器图，跨镜头时刀型必变。

**判据**：
|武器类型 | 需要单独出三视图吗 | 原因 |
|---|---|---|
| 贴身媒介（鞭、锁链、绷带、戒指、伞） | **不需要**，写进角色资产 | 不会脱离角色 |
| 独立武器（刀、枪、棍、斧） | **需要** | 会脱离角色被换形 |
| 一次性道具（酒瓶、椅子、石头） | 不需要，但要在节拍里写明何时碎/何时丢 | 状态变化即可控 |

### Q2：角色要出三视图吗？
**要，但只在「多镜头 / 系列 / 要跨段复用角色」时出。**

单条30 秒且角色只有一个连续镜头的段落，**不必出三视图**——
昨天那份猫耳女vs 裸上身男之所以满意，是因为它就是**单条、单场景、两个角色全程在场**，
没有跨镜换场的需求。

seedance25-prompt 的 `references/03-真人人物.md` §6.5 也明确写了边界：
> 「适合真人角色定妆/多镜头一致性项目（对话戏、系列片）；纯风格化/卡通风角色不需要真实感四步法」

**出三视图的触发条件**（任一命中就要出）：
1. 同一条视频里有**任何切镜换角度**（人物转到侧面/背面）
2. 同一条视频超过30 秒且要分段生成再拼接
3. 同一角色要出现在多条不同视频里（系列片）
4. 有换装需求（多套造型各出一张）

### Q3：不三视图会怎样？
**实测：不三视图 + 单镜头连续在场 = 没问题。** 你昨天实测「整体挺满意」就是这个组合。

风险点在于：
* 切镜到**背面/侧面**时，脸和发型会漂
* 分段生成时，每段的人物细节可能不一致
* 武器是独立道具时，形态会变

## 三、合并后的标准工作流

### 场景 A · 单条 30 秒、连续在场（昨天的用法，最省事）
```
1. 用ling-skill 出角色六格卡（身份/武器/招式/大招/偏好/视觉签名）
2. 用 seedance25-prompt 的 §6.5 版式 + §6.6 四步法，生成角色立绘（9:16）
3. 武器写进角色提示词里（贴身媒介）或单独出一张武器图（独立武器）
4. 用 ling-skill 的五维 + 节拍表 + 收尾三型，写视频提示词
5. 参考图只绑1-2 张（角色 + 场景），图少反而更稳
```
**不��三视图。** 这是性价比最高的组合。

### 场景 B · 多镜头 / 系列片 / 有换装
```
1. 出角色四视图（三视图+ 表情图）→ 锁跨镜一致性
2. 独立武器出一张三视图（正面/侧面/握持态）
3. 每套换装各出一张四视图（seedance25-prompt §6.5 要求）
4. 用 ling-skill 出节拍表，五维自检
5. 视频提示词里按 seedance25-prompt 的 C1/C2 索引标签绑定参考图
```

### 场景 C · 群战 / 召唤物（10-07 新增路线）
```
1. 主角出立绘（不必四视图，主角通常全程在场）
2. 召唤物出**一张群像图**即可（同款不同个体，见 references/08）
3. 环境级实体（伞/法阵/陨石）单独出一张，因为要反复出现
4. 参考图绑 3 张：主角 / 群像 / 环境实体
```

## 四、两类技能怎么协作（防重复劳动）

| 任务 | 单独找谁 | 理由 |
|---|---|---|
| 只写打斗提示词 | **ling-skill** | 五维 + 收尾三型 + 风格锁都在这|
| 只写文戏/情绪/台词 | seedance25-prompt | 表演体系在这 |
| 角色定妆 + 四视图 | seedance25-prompt | §6.5/6.6/6.8 在这 |
| 打斗 + 角色一致性都管 | **两个都加载** | 资产层+导演层都要 |
| 30 秒长视频的段落划分 | seedance25-prompt（§7/§8/§9） | 超长视频与延长在这 |
| 打斗的 15s/30s 节拍表 | ling-skill |references/03 模板在这 |

**红线纪律**：打斗任务里，seedance25-prompt 的 `references/00-审核把关.md` **红线检查照跑不误**
（格式/结构/参数硬错误），只是技法深度以 ling-skill 的五维为准。
两者冲突时，**硬参数听 seedance25-prompt，审美与节奏听 ling-skill**。

## 五、昨天那份稿子暴露的一个真问题

用户反馈「结尾处有点尬」。复盘后确认是**收尾层的问题，不是资产层的问题**——
所以**加三视图也解决不了**。

根因（详见 `references/08` §三）：我写的是
> 「骨钉化作白灰 + 符纸烧尽」+「背对镜头立于阶上」+「白闪收黑」

三重问题：
1. 0.5 秒内演两件事必然降级
2. 主体静止，**没有新信息进入画面**
3. 收在黑屏上，观众记住的是黑屏不是角色

**修正方案已写入 `references/08` §七**：
改用「余韵型 + 拔高型」收尾，最后 1 秒要有新东西进入画面（灯重新亮起 / 群狐围过来）。

> **教训**：资产层（三视图/武器/一致性）解决的是「不穿帮」；
> 导演层（节奏/收尾/特效语汇）解决的是「好不好看」。
> 「尬」属于后者，加三视图是南辕北辙。

## 六、给王老师的直接建议（按你的实际出片经验调）

你说实测「整体挺满意，除了结尾有点尬」——这恰好印证了分工判断：

| 现状 | 判断 |
|---|---|
| 角色没出三视图，效果满意 | ✅ 印证「单条连续在场不必三视图」，Q2 有答案了 |
| 武器只写在角色提示词里（红绸皮鞭/麻绷带） | ✅ 印证「贴身媒介不必单独锁」，Q1 有答案了 |
| 结尾尬 | ⚠️ 属导演层，不是资产层→ 用收尾三型修，加三视图无用 |

**所以你目前的工作流是对的**，只需把结尾换成余韵型/拔高型即可。
