## 二、默认画风锁（写实影视质感 · 直接抄进提示词）

### 1. 画面基底
* **实拍或引擎级渲染的真实摄影感**，不是插画感、不是手绘线稿
* 真实景深：85mm / 50mm 浅景深，背景做真实虚化
* 真实肤质：**保留自然血色与细微纹理**，有毛孔、有汗、有被风吹过的红
* 画面有**胶片颗粒 + 轻微色差 + 暗部噪点**，不要干净的数字感

### 2. 光与色（这是棂画风的灵魂）
* **强光比**：主体亮、背景压暗，明暗交界线硬
* **冷暖对撞**：冷青月光 / 冷蓝环境 × 暖灯 / 朱红 / 砂金的点缀
* **边缘光切轮廓**：发梢、刀锋、肩线、伞沿必须有细亮边
* **体积光 / 丁达尔光束**：废墟柱间、窗棂、弹幕缝隙里的光柱
* **局部光源引导视线**：gobo 光带、灯影反射、水面反光
* 空气里永远有介质：**雨雾 / 烟尘 / 水汽 / 雪烟 / 火星飞灰**

### 3. 场景与地面（地面必须参与动作）
* 开阔废墟、竹林、雪原、沙漠、神殿、庭院、赛博都市、工业厂区、马戏团
* **地面材质必参与**：积水（起涟漪、劈出放射状沟壑）、湿石（反光）、沙尘（扬起成幕）、雪（压出深痕）、棋盘格
* **前景遮挡**：断柱、幡旗、垂帘、栏杆、芦苇从镜头前掠过

### 4. 特效语汇（非人特效）
* 特效是**后期的、附加的、可辨识为特效的**，不与实拍质感混为一体
* 形态：能量护盾（半透明+ 屏幕反射）、刀剑拖尾光带、粒子爆散、火花四溅、冲击环扩散、符文阵、符纸燃烧
* **颜色单一**：一个特效只用一个主色（他惯用青蓝、朱红、金）
* 出现时机：只在**接触帧、冲击帧、大招帧**出现，不铺满全片
* 棂原话：「非真人特效 文字描述就好了」「特效参考感觉容易变成 ppt」

### 5. 人物
* 苍白/冷艳面孔，情绪外冷内静（湿发半遮眼、神情极冷极静）
* 白发 / 黑长直 / 银发，**湿发贴颊**是高频元素
* 兽耳（狐耳、狼耳、虎耳）是他极强的辨识度符号
* 朱红眼妆 / 额面红纹
* 服饰高材质密度：蕾丝、流苏、锁链、金属机械、旧织物混搭，材质必须可读

## 三、写实路线的禁用清单（与 02 文档合并使用）

| 禁止 | 原因 |
|---|---|
| 3D CGI 感 / 游戏引擎感 / 2.5D 木偶感 | 棂的默认路线**就是**引擎级渲染，但**不是廉价游戏 CG**；要电影级渲染，不要游戏过场 |
| 塑料皮肤 / 磨皮脸 / 人物脸崩 | 实拍感崩坏即出废片 |
| 手绘感 / 插画感 / 赛璐璐分色 | **这是 2D 路线的特征，写实路线禁止** |
| 低成本国漫 CG | 廉价感 |
| 3D 软体式变形（面条感） | 机械/结构类必须刚性咬合 |
| 武器变形 | 伞类尤其容易变形，被他点名禁止 |
| BOSS 拟人化 | 破坏设定 |
| 普通站桩对砍 | 节奏维度直接崩坏 |
| 血腥 / 断肢 / 处决技 | 写实路线他的实测结论："真人是真给处决" |
| 只写一个动词（如"喷火"） | 他原话："写个喷火是真只会喷火"→ 必须写形态变化与轨迹 |
| 不描述动作指望模型自己编 | 他原话："哪怕能理解 也可能偷懒给你变站桩" |

## 四、什么时候才用 2D 赛璐璐

**仅当用户明确说"要 2D / 动漫 / 番剧风"时**，才切到：
> 纯平面 2D 剧场版赛璐璐、细密手绘线稿、硬边分层阴影、局部水墨烟尘、胶片颗粒

并需配套切换禁用清单（禁 3D CGI / 塑料皮肤 / 低成本国漫 CG）。

**两套不得混写**——这是 02 文档自检第一条，也是最常被违反的一条。

## 五、模型代际差异（他反复提的坑）

| 版本 | 特性 | 对写法的约束 |
|---|---|---|
| **2.0** | 喜欢玩高动态，动态能快但会全糊 | 2D/高动态那套提示词只有 2.0 玩得动 |
| **2.5** | 自动往写实去；高动态会变噪点 | 高动态提示词给 2.5 会全是噪点 → 写实路线更适合 2.5 |

他原话：「2.5看了圈好像也只是分镜衔接好了些 画面质感没啥变化」。
