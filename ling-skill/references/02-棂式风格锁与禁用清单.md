# 02 · 棂式风格锁与禁用清单

> 全部来自 93 条视频的画面证据 + 棂在群内的原话。**风格锁是默认值，用户指定其他风格时以用户为准，但禁用清单照用**（它是踩坑总结）。

## 一、风格锁（正向）

### 1. 人物
* 苍白/冷艳面孔，情绪外冷内静（"湿发半遮眼，神情极冷极静"）
* 发型：白发、黑长直、银发，湿发贴颊是高频元素
* 兽耳/兽人化（狐耳、狼、白虎）——他作品里极强的辨识度
* 妆面：朱红眼妆/额面红纹（红中剧本"朱红眼妆"）

### 2. 服饰与材质
* **高材质密度**：蕾丝、流苏、锁链、金属机械混搭、旧纸伞、符纸
* 材质必须可读：金属倒角反光、织物纤维、皮革磨损
* 配色：米白 / 银白 / 灰白为主调，配单点高饱和强调色（朱红、青蓝、紫电）

### 3. 光与影
* 强光比 + 边缘光切轮廓（"侧后方暖灯切出面部与剑锋边缘高光"）
* 冷环境光 + 暖色对撞（冷青月光 × 暗红朱砂 / 深夜冷蓝 × 暖灯）
* 空气透视：雨雾、烟尘、水汽始终在场
* 局部光源做视线引导：gobo 光带、月光斜照、灯影反射

### 4. 场景
* 开阔 + 前景遮挡：废墟、竹林、雪原、沙漠、神殿、马戏团、棋局、图书馆、冰洞
* 地面材质必参与动作：积水、湿石、沙尘、雪、棋盘格

### 5. 画面质地
* 2D 路线：纯平面 2D 剧场版赛璐璐、细密手绘线稿、硬边分层阴影、局部水墨烟尘、胶片颗粒
* 写实路线：极致超清（雨滴/纤维/钢铁细纹可读）、浅景深、真实肤质保留血色与纹理

### 6. 收尾
* 大招 → 余波回落 → 白闪一瞬 → 收黑
* 最后一帧常留一个"信物"（破碎麻将角、飞落的牌、落下的伞）

## 二、禁用清单（反向，必写进提示词）

| 禁止 | 棂的实测原因 |
|---|---|
| 3D CGI 感 / 游戏引擎感 / 2.5D 木偶感 | 会背叛 2D 作画路线（红中剧本明写禁止） |
| 塑料皮肤 / 人物脸崩 | 真人感崩坏，出片即废 |
| 低成本国漫 CG | 廉价感 |
| 武器变形 | "伞武器变形"被点名禁止 |
| BOSS 拟人化（如麻将牌头长出人脸） | 破坏设定 |
| **普通站桩对砍** | 节奏维度直接崩坏，见 `01` 2.2 |
| 3D 软体式变形（面条感） | 机甲/结构类必须刚性咬合（飞书案例同结论） |
| 真人 + 高武打斗 | 原话"真人画风做这种高武打斗还是有点出戏" |
| 真人 + 处决技 / 血腥收尾 | 原话"现在真人打斗都有点血腥""结尾处决技 真人是真给处决" |
| 用特效参考图喂真人特效 | 原话"特效参考感觉容易变成ppt"→ 非真人特效**只用文字描述** |
| 只写一个动词（如"喷火"） | 原话"写个喷火是真只会喷火"→ 必须写形态变化与轨迹 |
| 不描述动作、指望模型自己编 | 原话"描述下吧 哪怕能理解 也可能偷懒给你变站桩" |

## 三、写提示词时的自检

1. 风格锁是否只用了**一套**（2D 或写实，不混）？
2. 禁用清单是否整段附上（尤其"禁止站桩对砍""禁止武器变形"）？
3. 真人路线是否已删掉处决/血腥？
4. 特效是否全部文字描述（不用参考图）？
5. 每个动词是否写了形态、方向、结果？
