# 11 · 真人实拍打斗语法（群友作品蒸馏）

> **来源**：微信群「邪恶红猴子的罪恶大本营」25 条真人打斗（2026-09-18 ~ 10-06）。
> 其中棂本人 9 条（#19/#44/#56/#65/#69/#74/#85/#93/#97），其他作者 16 条
> （雷二白 4 / 颜磊吖 2 / 耳东 2 / 反面教材 1 / 马跃 1 / Voxcat 1 / 邦BANG 1 / jiifll 1 / 曼波 1 / 黄大发 1）。
> **定位**：这是**真人实拍/写实渲染**的武打路线，与 `07` 的棂式写实影视质感同源，但更偏"真人格斗"而非"高武"。
> **与棂原话的关系**：棂说「真人画风做这种高武打斗还是有点出戏」——
> 但群友证明了：**真人路线不是不能打，是不能"高武"**。把招式收在人类物理极限内，真人打斗反而最耐看。

## 一、棂的真人打斗与群友的差异

| 维度 | 棂的真人 9 条 | 群友真人 16 条 |
|---|---|---|
| 主题 | 古装/和室/日式楼阁群战、持械（刀/弓） | 现代都市街斗、赤膊搏击、走廊/楼梯近身 |
| 场地 | 楼阁、竹林、办公室 | 街道、楼梯间、水泥空地、道场 |
| 打点 | 招式 + 环境（灯笼、木桌、竹） | 拳拳到肉的近身缠斗 |
| 收尾 | 遮挡留白、不处决 | 撂倒/制服，不致命 |

**共同点（真人路线的硬约束）**：动作幅度收在人体极限内、无超自然特效、不处决不血腥。

| # | 技法 | 怎么做 | 证据 |
|---|---|---|---|

## 三、真人打斗提示词模板（30s · 近身格斗）

```
【画风锁】真实摄影机成像，实拍质感（真人实拍或用写实渲染模拟实拍）；
真实肤质保留毛孔与血色，衣料真实褶皱与汗渍；自然光或单一实用光源；
轻微手持晃动与呼吸感；胶片颗粒与暗部噪点；浅景深但保持对手在同焦点。
禁止：超自然特效、塑料皮肤、磨皮脸、廉价CG、武器变形、血腥断肢、处决技。

【角色锁】@图片1 主角脸型/发型/服饰全程稳定；群敌用同款制服批量（黑衣/深色）。

[0–1s]  低机位：只拍靴子与地面，主角踏入画面前景
[1–3s]  拉到中景，主角与对手对峙，走位交换位置（OTS 保持两人同框）
[3–6s]  回合一：出拳→格挡→反制，每次接触有身体位移与一声闷响
[6–9s]  对手反击，主角被逼退撞上[环境道具：桌/栏杆]，道具翻倒
[9–12s] 主角借环境反打，近身缠斗，镜头跟随不切，地面积水/尘土被带起
[12–18s] 群敌围上（同款黑衣 3–5 人分层站位），主角走位打散
[18–24s] 回合密度提升，切点变密，主角跃起或拉倒对手
[24–30s] 收尾：主角踉跄站定喘息，对手倒地不起；不定格情绪，定格在具体姿态（扶墙/垂手/回头）
```

## 四、真人路线禁用清单

| 禁止 | 为什么 |
|---|---|
| 超自然特效（能量波/光刃/粒子爆发） | 棂原话"真人画风做这种高武打斗还是有点出戏" |
| 血腥 / 断肢 / 处决技 | 棂原话"现在真人打斗都有点血腥""真人是真给处决" |
| 塑料皮肤 / 磨皮脸 | 真人路线最忌讳的崩坏点 |
| 动作超出人体极限（飞檐走壁/无重力滞空） | 一旦脱离物理，真人感立刻崩 |
| 打空气（无接触反馈、无位移） | 真人打斗的"假"主要来自这里 |
| BOSS 拟人化 / 武器变形 | 同 `02` 通用禁用 |

## 五、收尾规则（真人专属，与体裁分流叠加）

* 真人短视频收尾 **一律不用处决**：
  * **制服型**：对手被撂倒/按在地上/投降 → 主角站起来喘息（本批最常用，`LV-6`）
  * **留白型**：遮挡（衣摆/雨幕/门框）切走，不交代结果（棂的 `#56` 竹林路线）
* 与 `08 §三` 收尾三型叠加使用时，**优先选 C 定型式**（定格在具体动作），
  比 A/B 更贴真人质感。
