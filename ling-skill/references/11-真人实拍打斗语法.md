# 11 · 真人实拍打斗语法（群友作品蒸馏）

> **来源**：微信群「邪恶红猴子的罪恶大本营」25 条真人打斗（2026-09-18 ~ 10-06）。
> 其中棂本人 9 条（#19/#44/#56/#65/#69/#74/#85/#93/#97），其他作者 16 条
> （雷二白 4 / 颜磊吖 2 / 耳东 2 / 反面教材 1 / 马跃 1 / Voxcat 1 / 邦BANG 1 / jiifll 1 / 曼波 1 / 黄大发 1）。
> **定位**：这是**真人实拍/写实渲染**的武打路线，与 `07` 的棂式写实影视质感同源，但更偏"真人格斗"而非"高武"。
> **与棂原话的关系**：棂说「真人画风做这种高武打斗还是有点出戏」——
> 但群友证明了：**真人路线不是不能打，是不能"高武"**。把招式收在人类物理极限内，真人打斗反而最耐看。
> **2026-10-11 增补**：吸收叩叩哥参考包——§六 近景对招体系（机枪节奏三模式 / 微表情微反馈）。

## 一、棂的真人打斗与群友的差异

| 维度 | 棂的真人 9 条 | 群友真人 16 条 |
|---|---|---|
| 主题 | 古装/和室/日式楼阁群战、持械（刀/弓） | 现代都市街斗、赤膊搏击、走廊/楼梯近身 |
| 场地 | 楼阁、竹林、办公室 | 街道、楼梯间、水泥空地、道场 |
| 打点 | 招式 + 环境（灯笼、木桌、竹） | 拳拳到肉的近身缠斗 |
| 收尾 | 遮挡留白、不处决 | 撂倒/制服，不致命 |

**共同点（真人路线的硬约束）**：动作幅度收在人体极限内、无超自然特效、不处决不血腥。

## 三、真人打斗提示词模板（30s · 近身格斗）

```
【画风锁】真实摄影机成像，实拍质感（真人实拍或用写实渲染模拟实拍）；
真实肤质保留毛孔与血色，衣料真实褶皱与汗渍；自然光或单一实用光源；
轻微手持晃动与呼吸感；胶片颗粒与暗部噪点；浅景深但保持对手在同焦点。
禁止：超自然特效、塑料皮肤、磨皮脸、廉价CG、武器变形、血腥断肢、处决技。

【角色锁】@图片1 主角脸型/发型/服饰全程稳定；群敌用同款制服批量（黑衣/深色）。

[0–1s]  低机位：只拍靴子与地面，主角踏入画面前景
[1–3s]  拉到中景，主角与对手对峙，走位交换位置（OTS 保持两人同框）
[3–6s]  回合一：出拳→格挡→反制，每次接触有身体位移与一声闷响
[6–9s]  对手反击，主角被逼退撞上[环境道具：桌/栏杆]，道具翻倒
[9–12s] 主角借环境反打，近身缠斗，镜头跟随不切，地面积水/尘土被带起
[12–18s] 群敌围上（同款黑衣 3–5 人分层站位），主角走位打散
[18–24s] 回合密度提升，切点变密，主角跃起或拉倒对手
[24–30s] 收尾：主角踉跄站定喘息，对手倒地不起；不定格情绪，定格在具体姿态（扶墙/垂手/回头）
```

## 四、真人路线禁用清单

| 禁止 | 为什么 |
|---|---|
| 超自然特效（能量波/光刃/粒子爆发） | 棂原话"真人画风做这种高武打斗还是有点出戏" |
| 血腥 / 断肢 / 处决技 | 棂原话"现在真人打斗都有点血腥""真人是真给处决" |
| 塑料皮肤 / 磨皮脸 | 真人路线最忌讳的崩坏点 |
| 动作超出人体极限（飞檐走壁/无重力滞空） | 一旦脱离物理，真人感立刻崩 |
| 打空气（无接触反馈、无位移） | 真人打斗的"假"主要来自这里 |
| BOSS 拟人化 / 武器变形 | 同 `02` 通用禁用 |

## 五、收尾规则（真人专属，与体裁分流叠加）

* 真人短视频收尾 **一律不用处决**：
  * **制服型**：对手被撂倒/按在地上/投降 → 主角站起来喘息（本批最常用，`LV-6`）
  * **留白型**：遮挡（衣摆/雨幕/门框）切走，不交代结果（棂的 `#56` 竹林路线）
* 与 `08 §三` 收尾三型叠加使用时，**优先选 C 定型式**（收在具体可读的动作），
  比 A/B 更贴真人质感。
* **但若这条视频只是「打斗片段」**（不讲情节与胜负）→ **一律在打斗中结束、不定格**
  （王老师 2026-10-11 裁定）：最后一个动作做到一半、镜头随动作快速拉开放走即止。

## 六、近景对招体系（吸收自叩叩哥参考包 · 真人路线最吃这套）

### 6.1 核心认知：打戏有两套观赏性

```
远景/全景 → 看"大动作"（腾空/旋转/下劈/撑地）→ 视觉奇观型观赏性
近景/中近景 → 看"杀意"（拳脚交错/格挡弹开/寸拳贴脸）→ 密度压迫型观赏性
```

**没有近景对招的打戏 = 只有爆炸没有枪战。** 真人路线尤其吃这一套——脸和手是真人素材最强的资产。

### 6.2 位置与配额

* 15s 里**必须至少 1 段（2–3s）上半身近景对招**，纯远景大动作 ≠ 完整打戏；
* **位置 A（1.5–5s）**：开局突进后，用近景拳脚对轰建立"打起来了"的密度感（先近身对招再拉开打大动作，节奏有起有伏）；
* **位置 B（8–9s）**：情绪拐点前，用近景对招把密度推到极致，给拐点蓄势（密度拉满→突然翻转 = 情绪被弹射出去）。

### 6.3 景别与机位

| 景别 | 画面内容 | 用途 |
|---|---|---|
| 中近景 | 胸部以上 + 双臂 | 对招主体：看清拳肘攻防 + 面部表情 |
| 近景 | 肩部以上 | 冲刺密度：连拳贴脸，汗水血雾飞溅 |
| 特写 | 面部 / 单手 / 接触点 | 微慢镜插入：格挡瞬间拳头停在眼前一寸 |

| 对招类型 | 机位 | 运镜 |
|---|---|---|
| 面对面连拳对轰 | 侧面平视 | 快速平摇跟拍 |
| 一攻一守（攻方压制） | 攻方斜后方过肩 | 手持微晃跟推 |
| 贴脸寸劲 / 短打 | 正面平视（被击者视角） | 极微前推 + 手持晃动 |
| 格挡弹开 → 反击 | 45° 侧面 | 先定后摇（格挡稳 → 弹开晃） |
| 肘法近身绞杀 | 低角度仰拍 | 微仰跟拍 |
| 攻防同框（化劲 / 借力） | 侧面平视 / 略俯 | 环绕微移 |

### 6.4 机枪节奏三模式（近景对招的节奏）

```
【炮弹节奏】远景大动作：砰————砰————砰！（一招一停有蓄力间隙）
【机枪节奏】近景对招：砰砰砰砰——砰！砰砰砰——砰！！（高密度连击穿插重击）
```

| 模式 | 节奏 | 适用角色 |
|---|---|---|
| **3 轻 1 重** | 3 次快速轻击 + 1 次重击慢放——"刷刷刷——砰！" | 咏春 / 空手道 / 散打 |
| **左右交替加速** | 左-右-左-右，间隔越来越短，像打鼓加速 | 泰拳 / 八极 / 拳击 |
| **封-破-杀** | 2 次格挡弹开 + 1 次破防 + 1 次致命击——"挡住了→挡住了→没挡住→完了" | 太极 / 擒拿 / 柔术 |

### 6.5 手部攻击（近景主场）

近景天然是手部攻击的主场——远景看不清的拳 / 掌 / 肘 / 指切换，近景全部放大。

* **观赏性排序**：砸肘 > 横肘 > 寸拳 > 上勾拳 > 标指/插指 > 推掌 > 冲拳 > 拍掌；
* **招式链配额**：短近景段 ≥3 段（招式 + 落点 + 防守反馈）；长近景段 4–6 段，必须含**肘击**或指 / 腕变化；
* **禁抽象频率**："每秒攻击 ≥N 次"一律不可用（`13 R16`）；
* **写法对比**：
  * ✅ "太极寸拳贴着红茶护臂滑入，拳头碾过前臂肌肉直抵肋骨缝隙，红茶咬牙格挡的手臂因冲击震颤，拳面擦过肋骨发出骨骼摩擦的闷响"
  * ❌ "太极出拳击中红茶"

### 6.6 微表情与微反馈体系

**微表情（攻方）**

| 状态 | 描写 | 适配 |
|---|---|---|
| 冷静压制 | 眼神如刀、面无表情、嘴角微抿 | 技术碾压型 |
| 暴怒狂攻 | 咬牙切齿、瞳孔收缩、额头青筋暴起 | 力量碾压型 |
| 从容拆招 | 眼皮微抬、嘴角微扬、呼吸平稳 | 化劲 / 借力型 |
| 绝境反击 | 眼底寒光一闪、表情从痛苦→坚定 | 逆转型拐点 |

**微表情（守方）**：被重击命中 → 瞳孔骤缩、嘴角血线、眼球震颤 ｜ 被连击压制 → 冷汗滚落、呼吸急促、眉头紧锁 ｜ 被化劲 → 错愕一闪 → 瞬间理解。

**微反馈（身体层面）**

| 类型 | 描写 | 效果 |
|---|---|---|
| 格挡震颤 | 格挡手臂微颤 / 拳头停在眼前一寸 | 力量的"可见" |
| 拳面擦血 | 血珠沿弧线甩出 | 近景独有暴力美学 |
| 汗珠飞溅 | 连击中汗珠从发梢甩出 | 速度感可见 |
| 护臂崩开 | 格挡被弹开，手臂甩向两侧 | "挡不住了"的信号 |
| 吐血 / 血雾 | 重击命中，血雾喷出 | 终结感 |

> **近景 → 远景的转换**禁止跳切，按 `12 §6.5` 三步过渡法执行。
