## 〇、两条交付形态（与 SKILL.md §第 0 步 的判定表配套）

| | **A · 单条直出（默认）** | **B · 多镜剪辑（本文件）** |
|---|---|---|

## 一、Shot 规格（每镜独立可生成）

### 1.1 时长（硬性）

| 规则 | 数值 |
|---|---|
| 任意单个 Shot | **≤4s**（与 `15 §1.2` 同源：4s 内必须有明确镜头） |
| 快节奏打斗 | 单 Shot 可压到 1.5–2.5s，密度 > 时长 |
| 一个攻防回合 | 拆 3–5 拍：攻 → 挡/格 → 反制 → 瞬移/闪避 → 再攻；每拍 0.2–0.5s |
| 密度底线 | **每 2s 内至少一个完整攻防回合 + 一次位移** |

### 1.2 独立性（跨镜规则）

* 每个 Shot **完全独立**：主体 → 动作 → 场景 → 镜头 → 风格/约束，五维顺序写全；
* **起始状态必须在动作字段独立描述**，严禁"接上一镜"式跨镜引用；
* 上一镜的末状态 = 下一镜的起始状态，衔接靠**剪辑规则**（§三）而不是靠语句引用。

### 1.3 镜头写法（每次必含五要素）

每一次镜头描述必须写全：**[景别] + [拍摄视角] + [角度] + [运镜方式] + [跟随目标]**。

```
✅ 中景 · 45° 斜拍平视 · 跟拍跟镜 · 跟随芭乐腰部横向平移
❌ 镜头拉远 / 镜头靠近 / 跟随拍摄（模糊描述 = 红线）
```

* 景别四选一：全景 / 中景 / 近景 / 特写；
* 视角五选一：正 / 侧 / 斜 / 俯 / 仰；
* 角度要具体（"30°仰""90°侧""45°斜俯"）；
* 跟随必须写明目标（跟谁 / 跟哪个部位）。
* 镜头要有目的性：正常对招→中近景侧面带移动感｜蓄力前摇→仰视慢推｜快速攻防→斜角+方向移动｜特写→只做破绽/转折点的过渡标点。

> 镜头五要素、景别匹配、空间感铁律、近远景过渡的完整细则见 `12 §七`（三条路线通用）。

## 二、切点规则（治"疯切 → 疯乱 / 发飘 / 接不上"）

### 2.1 三条基础法则

| # | 法则 | 说明 |
|---|---|---|
| 1 | **运动方向衔接** | 上一镜角色向右运动 → 下一镜也从左侧入画继续向右；方向不可无故反转 |
| 2 | **动势延续（match-cut）** | 切前切后同向：顺同一弧线续挥、残影链指向落点、速度线顺移动方向铺满、自上一击落点直接续出 |
| 3 | **切在运动中段** | 切点落在**挥砍/突进/撞击的中途**，不切在静止帧、不切在姿势停顿处 |

### 2.2 动势衔接词库（缝合相邻招式/切点）

* **接力连词**：顺势、借力、劲道不断、收招不停、一气呵成、衔尾续挥、承着上一击、势头未歇、余力顺转
* **方向延续**：顺同一弧线续挥、残影链指向落点、速度线顺移动方向铺满、自上一击落点直接续出、动势不折
* **弧线跟随**：完整挥出带 follow-through、收势自然坠落、惯性带动身形续转、末端拖尾顺势甩出
* **反面禁写**：相邻两镜方向/姿态互不相干地硬拼 ｜ 在静止帧切 ｜ 只写发力帧不写承接

### 2.3 命中拍的四段写法（每个关键碰撞点，`弹药库五节` 原义）

```
⓪ 命中前·装弹   ：半拍蓄力慢拍（攻击者"自己慢一下"，独立成拍）
① 接触·砸入     ：镜头猛震 + 命中点径向速度模糊 + 白闪一两帧（画面继续走）
② 顿·微升格     ：ramp 进 0.3–0.5s 微升格，被击者沿受力方向压缩/形变，
                  碎屑/火花仍缓慢流动外扩（非冻结）——可多次
③ 击飞·回速     ：snap back 全速，间距骤然拉大，被击者被打飞出画/撞结构
④ 目标反馈      ：受击反馈（斩断/击飞/洞穿/崩塌）+ 单色闪光/线条/碎屑——反馈必带回馈特效
```

> 名场面级大升格全片 **1 次**，留给大招；微升格另计。

## 三、一镜到底形态（对照面，按需选用）

当用户明确要求"**一镜到底 / 长镜头 / 不切镜 / 连贯流畅**"时，切回单镜内小节式写法：

* 每个 15s 拆 **3–5 个小节（打斗可到 6–8 节）**，每节 3–8s；
* 小节之间由**机位移动或人物动作**驱动自然过渡，**不写"切至"**；
* 每节标注画面内人数（"严格 X 人，无第 X+1 人"）；
* 特写配额：每 15s 至少 1–2 个特写节（占比 20–30%）；
* 空间连续性：站位/道具/光照/天气逐节一致；人物未离场默认始终在场；
* 台词 ≤30 字/节（5–6 字≈1 秒）；音效每节必写，禁"无"。

> **一镜到底 ≠ 全局默认**：它只是用户明确要求时的形态；默认仍走单条直出（时间轴式）或多镜剪辑。
> 写多镜时**禁止**在 Shot 表里混入"一镜到底"式的小节描述——两套格式不得混用。

## 四、多镜剪辑的 Shot 表模板

```
【交付形态】多镜剪辑（Shot 序列）
【全局约束】角色锁 + 风格锁 + 禁用清单（只写一次，各 Shot 不重复）

Shot 1｜0–2.5s
  景别/视角/角度/运镜/跟随：中景 · 30°斜拍 · 快速横移 · 跟随主角突进方向
  内容：主角低姿突进，敌方从光柱后接战；接触帧震镜 + 单色火花
Shot 2｜2.5–5s
  景别/视角/角度/运镜/跟随：近景 · 侧面平视 · 快速平摇 · 跟随双方拳肘
  内容：3 轻 1 重机枪节奏——右直拳打鼻梁→左摆拳打太阳穴→右顶肘撞胸口→左勾拳重击
        对手依次后仰、格挡、格挡震颤、被击后仰；汗珠甩出
Shot 3｜……
  （每镜独立、可单独生成；镜与镜之间按 §二 切点规则衔接）
```

**交付前自查**：每镜 ≤4s？五要素齐？切点都在运动中段？动势词衔接了？起始状态独立？——
再过一遍 `13` 全部红线。
