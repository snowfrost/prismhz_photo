## 〇、两条交付形态（与 SKILL.md §第 0 步 的判定表配套）

| | **A · 单条直出（默认）** | **B · 多镜剪辑（本文件）** |
|---|---|---|
| 产物 | 一条提示词（时间戳分镜式）→ 一条连续视频 | **Shot 序列表** → 逐镜出片 → 剪辑拼合 |
| 适用 | 15–30s 单条、单一空间、以动作为主 | 换景/换装/多时间点、群战多视角、>30s 长片、要求"电影感剪辑" |
| 写法 | `03` 时间轴骨架 + 路线语法（`10/11/12`） | 本文件：Shot 规格 + 切点规则 |
| 判据 | 用户没提"分镜表/剪辑/多机位/多条生成" | 用户提了其中任一，或内容长度/空间跨度超单条承载 |

> ⚠️ **历史教训**：参考包里"一镜到底 vs 多镜快切"曾被视为矛盾——实际是**交付形态差异**，
> 不是语法冲突。判定形态后，五维判据与质检红线**照常全部适用**。

## 一、Shot 规格（每镜独立可生成）

### 1.1 时长（硬性）

| 规则 | 数值 |
|---|---|
| 任意单个 Shot | **≤4s**（与 `15 §1.2` 同源：4s 内必须有明确镜头） |
| 快节奏打斗 | 单 Shot 可压到 1.5–2.5s，密度 > 时长 |
| 一个攻防回合 | 拆 3–5 拍：攻 → 挡/格 → 反制 → 瞬移/闪避 → 再攻；每拍 0.2–0.5s |
| 密度底线 | **每 2s 内至少一个完整攻防回合 + 一次位移** |

### 1.2 独立性（跨镜规则）

* 每个 Shot **完全独立**：主体 → 动作 → 场景 → 镜头 → 风格/约束，五维顺序写全；
* **起始状态必须在动作字段独立描述**，严禁"接上一镜"式跨镜引用；
* 上一镜的末状态 = 下一镜的起始状态，衔接靠**剪辑规则**（§二）而不是靠语句引用。

### 1.3 镜头写法（每次必含五要素）

每一次镜头描述必须写全：**[景别] + [拍摄视角] + [角度] + [运镜方式] + [跟随目标]**。

```
✅ 中景 · 45° 斜拍平视 · 跟拍跟镜 · 跟随芭乐腰部横向平移
❌ 镜头拉远 / 镜头靠近 / 跟随拍摄（模糊描述 = 红线）
```

* 景别四选一：全景 / 中景 / 近景 / 特写；
* 视角五选一：正 / 侧 / 斜 / 俯 / 仰；
* 角度要具体（"30°仰""90°侧""45°斜俯"）；
* 跟随必须写明目标（跟谁 / 跟哪个部位）。
* 镜头要有目的性：正常对招→中近景侧面带移动感｜蓄力前摇→仰视慢推｜快速攻防→斜角+方向移动｜特写→只做破绽/转折点的过渡标点。

> 镜头五要素、景别匹配、空间感铁律、近远景过渡的完整细则见 `12 §六`（三条路线通用）。

## 二、切点规则（治"疯切 → 疯乱 / 发飘 / 接不上"）

### 2.1 三条基础法则

| # | 法则 | 说明 |
|---|---|---|
| 1 | **运动方向衔接** | 上一镜角色向右运动 → 下一镜也从左侧入画继续向右；方向不可无故反转 |
| 2 | **动势延续（match-cut）** | 切前切后同向：顺同一弧线续挥、残影链指向落点、速度线顺移动方向铺满、自上一击落点直接续出 |
| 3 | **切在运动中段** | 切点落在**挥砍/突进/撞击的中途**，不切在静止帧、不切在姿势停顿处 |

### 2.2 动势衔接词库（缝合相邻招式/切点）

* **接力连词**：顺势、借力、劲道不断、收招不停、一气呵成、衔尾续挥、承着上一击、势头未歇、余力顺转
* **方向延续**：顺同一弧线续挥、残影链指向落点、速度线顺移动方向铺满、自上一击落点直接续出、动势不折
* **弧线跟随**：完整挥出带 follow-through、收势自然坠落、惯性带动身形续转、末端拖尾顺势甩出
* **反面禁写**：相邻两镜方向/姿态互不相干地硬拼 ｜ 在静止帧切 ｜ 只写发力帧不写承接

### 2.3 命中拍的四段写法（每个关键碰撞点，`弹药库五节` 原义）

```
⓪ 命中前·装弹   ：半拍蓄力慢拍（攻击者"自己慢一下"，独立成拍）
① 接触·砸入     ：镜头猛震 + 命中点径向速度模糊 + 白闪一两帧（画面继续走）
② 顿·微升格     ：ramp 进 0.3–0.5s 微升格，被击者沿受力方向压缩/形变，
                  碎屑/火花仍缓慢流动外扩（非冻结）——可多次
③ 击飞·回速     ：snap back 全速，间距骤然拉大，被击者被打飞出画/撞结构
④ 目标反馈      ：受击反馈（斩断/击飞/洞穿/崩塌）+ 单色闪光/线条/碎屑——反馈必带回馈特效
```

> 名场面级大升格全片 **1 次**，留给大招；微升格另计。

## 三、运镜速查与组合公式（15 种 · 吸收自叩叩哥参考包）

> 写每个 Shot 的运镜时从这里选；与 `12 §6.6` 旋转禁令配合使用。

| # | 运镜 | 操作 | 最佳场景 | 景别 |
|---|---|---|---|---|
| 1 | 跟拍跟镜 | 镜头贴身跟随，滑步进退缠斗 | 近身拳脚/连续连招 | 中近景 |
| 2 | 环绕运镜 | 以两人为圆心 ≤180° 半环绕（禁满圈） | 对峙/蓄势/大招前 | 中景→全景 |
| 3 | 急速推镜 | 命中瞬间镜头猛然前冲 | 攻击命中瞬间 | 中景→特写 |
| 4 | 急速拉镜 | 大动作后快速后拉 | 腾空落地/展示站位 | 中景→全景 |
| 5 | 低角度仰拍 | 贴地低机位仰拍（30°–60°） | 起手蓄势/起跳出腿 | 近景→中景 |
| 6 | 高空俯拍 | 高空垂直/斜俯视 | 走位/双人格斗 | 全景 |
| 7 | 慢动作跟镜 | 高难动作慢拍跟拍 | 旋踢/飞膝/大招 | 中近景→特写 |
| 8 | 摇镜横移 | 水平平稳横摇 | 横向游走试探/拆招 | 中景 |
| 9 | 甩镜闪切 | 碰撞时镜头急速甩动 | 重拳/肘击碰撞瞬间 | 近景 |
| 10 | 特写切镜 | 拳→腿→眼三段快切 | 蓄力/情绪渲染 | 特写 |
| 11 | 升降运镜 | 随腾空升起、落地时下沉 | 腾空动作/跳跃 | 中景→全景 |
| 12 | 穿物穿梭 | 穿过门框/柱间间隙追随 | 楼道街巷/障碍场景 | 中景 |
| 13 | 对打正反打 | 甲乙双方视角交替 | 连续攻防 | 近景 |
| 14 | 旋转摇镜 | 旋身动作时镜头小幅自旋 | 旋转类动作 | 中景 |
| 15 | 定格定镜 | 命中瞬间画面骤停 | 重击命中/情绪高潮 | 特写→近景 |

**运镜组合公式**（实战极少单用一种）：

| 组合 | 运镜链 | 适用 | 情绪曲线 |
|---|---|---|---|
| 突进组合 | 急速推镜 → 跟拍跟镜 → 甩镜闪切 | 开局突进/贴身对轰 | 压迫→密集→爆发 |
| 大招组合 | 急速后拉跟镜 → 慢动作跟镜 → 定格定镜 | 终结技/大招释放 | 张力→细节→高潮 |
| 逆转组合 | 对打正反打 → 急速推镜 → 定格定镜 | 情绪拐点/绝地反击 | 对等→突变→定格 |
| 腾空组合 | 升降运镜 → 高空俯拍 → 急速拉镜 | 腾空连招/落地重击 | 升起→俯瞰→拉开 |
| 环境互动组合 | 穿物穿梭 → 跟拍跟镜 → 甩镜闪切 | 街巷追逐/障碍场景 | 临场→贴身→碰撞 |

**AI 生成执行注意**（实测）：

* 急速推镜：写"推进至落点前 0.5 米处骤停"（防推过头糊）；
* 甩镜：写"急速甩动约 15°、轻微模糊拖影"（防撕裂）；
* 穿物：写"穿过门框间隙"，不写"穿墙"（防穿模）；
* 特写切镜：写明"①②③三段快速切换，每段 0.3 秒"（防跳切感）；
* 旋转摇镜：写"随角色转身方向同向小幅自旋"（防不同步）。

## 四、连续性控制三件套（多镜必写 · 吸收自叩叩哥参考包）

> **根因**：AI 视频模型没有跨镜头记忆，每镜独立生成。空间/状态/道具信息只写一次，模型会随机重建——
> 人物从床右跳到床左、背景角色忽坐忽躺、道具换手或凭空消失。
> **多镜交付时，每个 Shot 提示词开头强制复写三件套**（单条直出模式则在全局前缀写一次）。

### 4.1 空间锚（锁物理布局）

```
[空间锚]场景名，核心家具位置，门窗方位，关键角色固定位置
```

* 只写空间关系，不写动作、情绪；方位用绝对词（左/右/中央/前景/后景），**不用"旁边""附近"**；
* 进阶（可选）：数值坐标叠加——X 横向占比 % / Y 纵向占比 % / 朝向 XX°（0°=正对镜头，90°=右侧身，180°=背对，270°=左侧身）；
* 角色移动后更新锚中位置；换场景重写新锚；
* ❌ "翠花在床上"（太模糊）→ ✅ "刘翠花半卧于病床左侧位（X30%/Y55%/朝向90°）"。

### 4.2 状态锁（锁人物姿态）

```
[状态锁]角色A=姿态/位置，角色B=姿态/位置，角色C=画外（位置不变）
```

* 场景中**每个角色**都要列出，不管是否在焦点中；不在画面写"画外（位置不变）"；
* 与上一镜相同**照抄，不要省略**——背景人物"忽坐忽躺"的唯一原因就是省略；
* 姿态词库（只用标准词）：站立/行走/坐下/半卧/平躺/侧卧/蹲下/弯腰/前倾 + 不动/微动/缓步/快步/僵住/定格。

### 4.3 道具锁（锁着装与手持）

```
[道具锁]角色A=道具/着装状态，角色B=道具/着装状态
```

* 列出每个可见角色的手持（左手持 X/右手持 X/空手/放下 X）、着装（敞开/扣合/歪斜）、佩戴、状态（完好/污渍/撕裂/湿痕/褶皱/脱落）；
* **受伤、被泼液体、衣服撕裂是持久状态**——后续所有镜头必须保持，直到换装；
* 道具消失必须写明去向（放下/丢失/被夺）→ 与 `13 R18` 武器三级判定配合。

> **打斗适配**：打斗里的"武器在手/脱手/掉落""衣甲破损/护具崩开/披风撕裂"全部进道具锁逐镜保持；
> 与 `13 R4`（空间不重置）、`R15`（逻辑锁）配套使用。

## 五、一镜到底形态（对照面，按需选用）

当用户明确要求"**一镜到底 / 长镜头 / 不切镜 / 连贯流畅**"时，切回单镜内小节式写法：

* 每个 15s 拆 **3–5 个小节（打斗可到 6–8 节）**，每节 3–8s；
* 小节之间由**机位移动或人物动作**驱动自然过渡，**不写"切至"**；
* 每节标注画面内人数（"严格 X 人，无第 X+1 人"）；
* 特写配额：每 15s 至少 1–2 个特写节（占比 20–30%）；
* 空间连续性：站位/道具/光照/天气逐节一致；人物未离场默认始终在场；
* 台词 ≤30 字/节（5–6 字≈1 秒）；音效每节必写，禁"无"。

> **一镜到底 ≠ 全局默认**：它只是用户明确要求时的形态；默认仍走单条直出（时间轴式）或多镜剪辑。
> 写多镜时**禁止**在 Shot 表里混入"一镜到底"式的小节描述——两套格式不得混用。

## 六、多镜剪辑的 Shot 表模板

```
【交付形态】多镜剪辑（Shot 序列）
【全局约束】角色锁 + 风格锁 + 禁用清单（只写一次，各 Shot 不重复）

Shot 1｜0–2.5s
  景别/视角/角度/运镜/跟随：中景 · 30°斜拍 · 快速横移 · 跟随主角突进方向
  内容：主角低姿突进，敌方从光柱后接战；接触帧震镜 + 单色火花
Shot 2｜2.5–5s
  景别/视角/角度/运镜/跟随：近景 · 侧面平视 · 快速平摇 · 跟随双方拳肘
  内容：3 轻 1 重机枪节奏——右直拳打鼻梁→左摆拳打太阳穴→右顶肘撞胸口→左勾拳重击
        对手依次后仰、格挡、格挡震颤、被击后仰；汗珠甩出
Shot 3｜……
  （每镜独立、可单独生成；镜与镜之间按 §二 切点规则衔接）
```

**交付前自查**：每镜 ≤4s？五要素齐？切点都在运动中段？动势词衔接了？起始状态独立？——
再过一遍 `13` 全部红线。
