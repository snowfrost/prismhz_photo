## 一、什么时候用这条路线

| 用 | 不用 |
|---|---|
| 高武夸张招式、对波、召唤物、必杀技 | 需要真实感/纪实感/品牌调性的片子 |
| 黑白极简或水墨等高风格化视觉 | 用户明确要"真人/写实/实拍" |
| 15s 以内的高密度对打（本批 2D 样本中位 15s） | 30s 以上要完整叙事的打斗 |

> 本批 16 条 2D 里，**15s 及以下占 11 条** —— 2D 路线的天然时长是 15s 上下，密度优先。

## 二、十条专属语法（带证据编号）

| # | 技法 | 怎么做 | 证据 |
|---|---|---|---|
| 2D-1 | **单/双色刃光做主视觉** | 画面压在黑白灰高对比底上，**只让刃光是高饱和色**（红/蓝/紫/青任选一到两种）。全场唯一彩色元素 = 唯一视觉焦点 | #200 红刃、#199 红蓝双刃、#225 紫刃、#194 光刃 |
| 2D-2 | **旋转主观镜头** | 镜头绕刀光做 roll/旋转，刀光被拖成环形轨迹；大招时旋转加速收成**同心圆/放射圆盘** | #199/#200/#225 末段均为同心圆旋转收束 |
| 2D-3 | **残影链 + 多位置同帧** | 同一帧内角色出现在 2–3 个位置，暗示超高速位移；不做真实运动模糊，要做**清晰分层的残影** | #200 顶部帧、#202 雪地屋顶 |
| 2D-4 | **水墨抽象化轨迹** | 动作痕迹不用物理实体，用**墨迹/泼墨/飞白**表达；墨迹可成龙卷、旋涡、拉丝 | #119 墨迹成龙卷旋涡、#110 水墨风红衣女 |
| 2D-5 | **全屏白 + 集中线炸开** | 大招命中瞬间**全屏纯白**（1–2 帧），随后放射状集中线炸开；这是 2D 独有的节奏标点 | #225/#200 末行、#105 金法阵爆发 |
| 2D-6 | **剪影化与低细节面部** | 高速段人物压成剪影或极简色块，**只保留轮廓可信**；面部细节只在静止帧给 | #119 全程剪影、#199 远景小人 |
| 2D-7 | **眼部超近景作情绪锚点** | 高速动作中插入**一只眼睛的超近景**（红瞳/异色瞳），一帧即过 | #200 红眼特写、#225 红瞳特写 |
| 2D-8 | **场景几何化** | 废墟/建筑/栏杆用**大色块 + 硬边**，不做材质细节；空间读起来像舞台布景 | #199/#200 废墟走廊、#204 雪地 |
| 2D-9 | **静—爆相位** | 连续几帧近乎静止（姿势定格），然后猛切到爆发动作；**静是为了让爆更爆** | #200 第 2 行静止帧 → 第 3 行爆发 |
| 2D-10 | **留白负形** | 用大片白/灰负形包裹动作，人物在留白里"浮"着打；负形也是构图主体 | #119 水墨留白、#161 竹林雾白 |

## 三、2D 专属提示词模板（15s）

```
【画风锁】纯平面2D剧场版赛璐璐，细密手绘线稿，硬边分层阴影，[水墨/黑白高对比]质感，
胶片颗粒，极强作画张力；画面压在[黑白灰]底上，全片只保留[刃光色]一种高饱和色。
禁止：3D CGI、游戏引擎感、2.5D木偶感、塑料皮肤、手绘细节过载、人物脸崩、武器变形。

【角色锁】@图片1 主角脸型/发型/服饰/武器全程稳定；高速段人物可剪影化，静止帧恢复细节。

【节奏】首帧即战 → 三轮高速交锋（残影链）→ 静一拍 → 唯一一次全屏白+集中线大招 → 收在日常动作上。

[0–1s]  极低机位贴地仰拍，主角从画面外冲入，[武器]拖出[色]光弧
[1–3s]  旋转主观镜头，刀光被拖成环形，画面压成剪影，残影链三层
[3–4s]  静一拍：主角定格，只留眼睛超近景（异色瞳）一帧
[4–6s]  爆发：多位置同帧，敌人被击退撞墙，大色块硬边碎裂
[6–8s]  环境介入：[水墨/负形]沿地面漫开，动作痕迹抽象成笔触
[8–10s] 敌方反击，主角被压制，镜头压低贴脸
[10–13s] 唯一一次全屏纯白（2帧）→ 放射状集中线炸开 → 同心圆收束
[13–15s] 收尾：不定格在情绪，定格在一个具体动作（收刀/回头/刃尖滴水）
```

## 四、2D 路线专属禁用清单

| 禁止 | 为什么 |
|---|---|
| 3D CGI 感 / 游戏引擎感 / 2.5D 木偶感 | 直接毁掉 2D 作画属性 |
| 塑料皮肤 / 磨皮脸 | 2D 要的是线稿与色块，不是光滑表皮 |
| 写实摄影机成像 / 浅景深虚化 / 真实肤质毛孔 | 这是写实路线的锁，混进来即风格打架 |
| 动作痕迹用实体粒子/真实火花 | 该走墨迹/笔触/集中线 |
| 多色高饱和同时出现 | 破坏"单色刃光=唯一焦点"的核心 |
| 均匀高速、全程一个速度 | 没有静，爆就不成立 |

## 五、与写实路线的切换铁律

**两套风格锁不得混写。** 判断方法只有一条：
用户说"动漫/番剧/2D/赛璐璐/水墨" → 走本条；
否则一律走 `07` 的**写实影视质感**（默认）。

> 本批 16 条 2D 中，**没有一条**同时具备写实肤质与摄影机浅景深 —— 群友自己也在严格分流。
