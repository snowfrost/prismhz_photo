## 一、什么时候用这条路线

| 用 | 不用 |
|---|---|
| 高武夸张招式、对波、召唤物、必杀技 | 需要真实感/纪实感/品牌调性的片子 |
| 黑白极简或水墨等高风格化视觉 | 用户明确要"真人/写实/实拍" |
| 15s 以内的高密度对打（本批 2D 样本中位 15s） | 30s 以上要完整叙事的打斗 |

> 本批 16 条 2D 里，**15s 及以下占 11 条** —— 2D 路线的天然时长是 15s 上下，密度优先。

## 二、十条专属语法（带证据编号）

| # | 技法 | 怎么做 | 证据 |
|---|---|---|---|
| 2D-1 | **单/双色刃光做主视觉** | 画面压在黑白灰高对比底上，**只让刃光是高饱和色**（红/蓝/紫/青任选一到两种）。全场唯一彩色元素 = 唯一视觉焦点 | #200 红刃、#199 红蓝双刃、#225 紫刃、#194 光刃 |
| 2D-2 | **旋转主观镜头** | 镜头绕刀光做 roll/旋转，刀光被拖成环形轨迹；大招时旋转加速收成**同心圆/放射圆盘** | #199/#200/#225 末段均为同心圆旋转收束 |
| 2D-3 | **残影链 + 多位置同帧** | 同一帧内角色出现在 2–3 个位置，暗示超高速位移；不做真实运动模糊，要做**清晰分层的残影** | #200 顶部帧、#202 雪地屋顶 |
| 2D-4 | **水墨抽象化轨迹** | 动作痕迹不用物理实体，用**墨迹/泼墨/飞白**表达；墨迹可成龙卷、旋涡、拉丝 | #119 墨迹成龙卷旋涡、#110 水墨风红衣女 |
| 2D-5 | **全屏白 + 集中线炸开** | 大招命中瞬间**全屏纯白**（1–2 帧），随后放射状集中线炸开；这是 2D 独有的节奏标点 | #225/#200 末行、#105 金法阵爆发 |
| 2D-6 | **剪影化与低细节面部** | 高速段人物压成剪影或极简色块，**只保留轮廓可信**；面部细节只在静止帧给 | #119 全程剪影、#199 远景小人 |
| 2D-7 | **眼部超近景作情绪锚点** | 高速动作中插入**一只眼睛的超近景**（红瞳/异色瞳），一帧即过 | #200 红眼特写、#225 红瞳特写 |
| 2D-8 | **场景几何化** | 废墟/建筑/栏杆用**大色块 + 硬边**，不做材质细节；空间读起来像舞台布景 | #199/#200 废墟走廊、#204 雪地 |
| 2D-9 | **静—爆相位** | 连续几帧近乎静止（姿势定格），然后猛切到爆发动作；**静是为了让爆更爆** | #200 第 2 行静止帧 → 第 3 行爆发 |
| 2D-10 | **留白负形** | 用大片白/灰负形包裹动作，人物在留白里"浮"着打；负形也是构图主体 | #119 水墨留白、#161 竹林雾白 |

## 三、2D 专属提示词模板（15s）

```
【画风锁】纯平面2D剧场版赛璐璐，细密手绘线稿，硬边分层阴影，[水墨/黑白高对比]质感，
胶片颗粒，极强作画张力；画面压在[黑白灰]底上，全片只保留[刃光色]一种高饱和色。
禁止：3D CGI、游戏引擎感、2.5D木偶感、塑料皮肤、手绘细节过载、人物脸崩、武器变形。

【角色锁】@图片1 主角脸型/发型/服饰/武器全程稳定；高速段人物可剪影化，静止帧恢复细节。

【节奏】首帧即战 → 三轮高速交锋（残影链）→ 静一拍 → 唯一一次全屏白+集中线大招 → 收在日常动作上。

[0–1s]  极低机位贴地仰拍，主角从画面外冲入，[武器]拖出[色]光弧
[1–3s]  旋转主观镜头，刀光被拖成环形，画面压成剪影，残影链三层
[3–4s]  静一拍：主角定格，只留眼睛超近景（异色瞳）一帧
[4–6s]  爆发：多位置同帧，敌人被击退撞墙，大色块硬边碎裂
[6–8s]  环境介入：[水墨/负形]沿地面漫开，动作痕迹抽象成笔触
[8–10s] 敌方反击，主角被压制，镜头压低贴脸
[10–13s] 唯一一次全屏纯白（2帧）→ 放射状集中线炸开 → 同心圆收束
[13–15s] 收尾：不定格在情绪，定格在一个具体动作（收刀/回头/刃尖滴水）
```

## 四、2D 路线专属禁用清单

| 禁止 | 为什么 |
|---|---|
| 3D CGI 感 / 游戏引擎感 / 2.5D 木偶感 | 直接毁掉 2D 作画属性 |
| 塑料皮肤 / 磨皮脸 | 2D 要的是线稿与色块，不是光滑表皮 |
| 写实摄影机成像 / 浅景深虚化 / 真实肤质毛孔 | 这是写实路线的锁，混进来即风格打架 |
| 动作痕迹用实体粒子/真实火花 | 该走墨迹/笔触/集中线 |
| 多色高饱和同时出现 | 破坏"单色刃光=唯一焦点"的核心 |
| 均匀高速、全程一个速度 | 没有静，爆就不成立 |

## 五、与写实路线的切换铁律

## 六、番剧作画体系（6 件套 · 吸收自叩叩哥参考包）

> 来源：番剧作画打斗弹药库（飞驰影漫社）。走路线 ③ 时按需追加；弹药动词库另见素材原文。

### 6.1 画风基准（画风锁定四要素：色调 + 光质 + 作画质感 + 镜头特征）

| 基准 | 特征 |
|---|---|
| **现代作画流（ufotable / MAPPA）← 默认** | 高饱和能量撞色、流体般粒子海量浮游、电影级构图与体积光、丝滑 sakuga 作画、命中重震镜白闪、青白/品红能量辉光 |
| 少年热血（龙珠 / 火影） | 高对比爆气色调、集中线满屏、斗气环绕、光束对轰、瞬身残影频闪、粗线条硬阴影 |
| 剑戟作画（Fate 味） | 冷冽金属光质、刃光青白残轨、暗调场景点缀火星、居合名场面（全片唯一升格处）、优雅弧线运镜 |
| 复古赛璐璐（90 年代） | 平涂色块、颗粒胶片质感、手绘速度线、暖黄打光、夸张透视广角 |

用户给参考图时：照四要素格式反推图片画风并锁定，**全程复用同一句，不换措辞**；无参考图默认锁现代作画流。

### 6.2 作画特效层（每个动作节点必挂 ≥1 层，五类混用）

* **线条特效**：放射状集中线内收 / 横向速度线扫过 / 动作拖影线 / 爆闪冲击线 / 蓄力集中线暴涨；
* **冲击强调**（画面不停）：命中白闪 1–2 帧 / 色彩瞬间提亮 / 命中点径向速度模糊 / 镜头猛震 / 单色放射背景瞬闪；
* **气场斗气**：能量气焰缠身 / 斗气暴涨掀飞碎石 / 地面被气压压出环形气浪 / 发丝布料被气场推起 / 爆气柱冲天；
* **残影分身**：多重残像拖尾 / 瞬移残影链 / smear 抹除帧夸张形变 / 残影追上本体消散；
* **能量与粒子**：液态流动能量 / 光尘逆光浮游 / 能量碎屑如萤火坠落 / 刃光青白残轨 / 雨滴在能量场中被点亮。

**挂载口诀**：动作动词 → 紧跟 [作画反馈]（受体如何崩裂/被击飞）→ 再叠一层作画特效（速度线/白闪震镜/气场/残影）。三段式让每个节点"有肉有光有线"。

### 6.3 单色调冲击 + 线条爆发（画面继续动，只瞬间套一层滤镜）

| 手法 | 做法 |
|---|---|
| **黑白闪** | 重击/决胜瞬间整屏 0.1–0.2s 去色成高对比黑白，立刻切回彩色（动作不停）——只留给全片最重那几击 |
| **单色染屏** | 整屏被单色瞬间笼罩再褪去：红=杀气/暴怒 ｜ 蓝青=冷冽杀招 ｜ 金橙=大招充能 ｜ 紫品红=能量过载/觉醒 |
| **集中线** | 蓄力时四周向内收束、爆发时从中心炸开，把视线钉在主体或命中点 |
| **速度线** | 横向/斜向流动线随动作方向铺满，表现高速疾掠、瞬移、连斩 |
| **漫画线条背景** | 爆发/大招瞬间背景抽象化成手绘线条/网点/单色放射，剥离写实环境只留张力 |
| **描边剪影** | 逆光/爆发瞬间粗黑轮廓描边，高对比剪影一闪 |

★ 频率：黑白闪 + 单色染屏每个回合碰撞/技能发动都可来，**全片十几次不嫌多**；每次 ≤0.15s、闪完即回、融在运动里。

### 6.4 作画反馈库（按材质取用，比写实版更夸张）

* 混凝土/石材：蛛网状崩裂整块炸飞，碎块如陨石拖尾，扬起灰白尘爆；
* 金属：表面深陷形变，迸出一串橙红火花，金属哀鸣中被击穿；
* 玻璃：放射状炸裂，碎片如雨拖速度残影，每片映出打斗残影；
* 地面：冲击波犁开放射状巨沟，环形气浪掀翻一圈地砖；
* 高速位移：脚下炸开一圈扬尘/水花，身后拖速度线残影，掠过处草木碎石被气流卷起；
* 落地/踏地：双足砸地压出放射状裂纹与尘环，积水四溅拉出水丝，气浪把发丝布料整体掀起；
* 空气/能量：音爆环扩散，气浪扭曲背景，白闪盖满全屏后迅速褪去。

### 6.5 疯切运镜库（番剧核心：每条至少用到 6 种不同运镜）

* **爆发段**：荷兰角疾切 / 贴脸特写硬切全景 / 甩镜入战糊成流光 / 微观特写骤然拉远；
* **博弈段**：荷兰角攻防急切 / 甩镜衔接每一招 / 贴脸↔远景暴力反差跳切 / 残影拖尾横移 / 交错擦身冲出；
* **对垒段**：高速环绕旋转 / 碎屑径向飞散拖尾 / 名场面大升格特写（≤0.4s、碎屑仍流动）/ 推轨逼近面部再急速拉远 / 蓄力集中线内收；
* **余波段**：气场收敛中缓慢拉远 / 低角度仰拍英雄 pose 剪影 / 残影消散中落定。

> ⚠️ **冲突裁决（与 `12 §6.6` 旋转禁令）**：番剧惯例的"360° 高速环绕"是人工作画产物；
> **AI 生成时降级为 ≤180° 半环绕 + 高速 roll 自旋**，禁满圈 360° 与螺旋上升（防眩晕/失向）。

### 6.6 特写标点库（每个特写 = 一个新镜头，对 AI 安全）

| 特写 | 职责 | 位置 |
|---|---|---|
| 握拳/攥刀 | 预告发力（"上膛信号"） | 出招前 |
| 脚掌蹬地/碾地 | 交代"力从哪来"+ 重量 | 突进/踹击前（配尘土/地裂） |
| 移动速度特写 | 卖"快"：局部 + 满屏速度线 + 地面回馈 | 位移过程中 |
| 刀出鞘/举械/寒光 | 制造期待 | 交锋前 |
| 眼神/瞳孔锁定 | 延迟满足（"下一帧要出大事"） | 命中前一瞬 |
| 命中局部特写（拳砸/刃入） | 节奏重音·落点 | 命中瞬间切对侧角度 |
| 被击者反应/踉跄 | 因果闭环之"果"，用反应确认这一击的分量 | 命中后一拍，稍长 |

★ **一个完整重音单元 = 蓄力特写（因）→ 命中（连接）→ 反应特写（果）**。
