# 12 · 写实渲染 / 3D CG 打斗语法（最大一类）

> **来源**：全量 174 条打斗中 **133 条属此类**（棂 90 + 群友 43）。
> 这是**本群最主流的打斗形态**，也是棂 2026-09~10 的主力路线（与 `07` 的"写实影视质感"同源，
> 但 `07` 只讲画风，本文件讲**打斗层面的语法**）。
> 界定：真实摄影机成像质感或引擎级三维渲染（非手绘、非真人实拍），
> 含奇幻高武、机甲、巨型生物、召唤物等题材。
> **2026-10-11 增补**：吸收叩叩哥参考包——§六 镜头与切镜通用铁律（三条路线通用）+ §七 特效系统
> （轨迹四要素 / 生长三段论 / 三段使命）。

## 二、十二条 CG 打斗语法（带证据编号）

### A 组 · 视觉基底

| # | 技法 | 怎么做 | 证据 |
|---|---|---|---|
| CG-1 | **镜面/几何光纹地面** | 场地地面做**镜面反射**或**金色几何光纹**，角色的动作在地面留下倒影或光路；场地本身是"舞台" | #245/#215 竞技场镜面地、#246 水面反射、#243 金色光阵 |
| CG-2 | **单一主色能量几何** | 全片能量特效只用**一个色系**，且形态规整（法阵/光柱/放射线/环），不做杂色烟雾 | #245 金白光阵、#207 红光蛛网、#230 紫光柱 |
| CG-3 | **光柱阵列做空间框** | 用一排**垂直光柱**（或立柱）把战场框成走廊/竞技场，光柱同时是照明与边界 | #245 金色光柱列、#206 红色光柱、#222 巨型圆环 |
| CG-4 | **雪/尘/水汽恒在场** | 空气介质永远有雪烟/扬尘/水汽，让光线可见（丁达尔），也让动作有"拖尾" | #246 冰雪、#243 蓝色雾气、#215 地面雾 |

### B 组 · 角色与招式

| # | 技法 | 怎么做 | 证据 |
|---|---|---|---|
| CG-5 | **兽耳女 + 伴生兽群** | 主角为兽耳/狐面，配**白狐群等伴生兽**分层站位（围环/扇面/伏地），兽群即"活体特效" | #215/#234/#245 白狐群围半环、#173 红线牵狐 |
| CG-6 | **光刃/长兵器的拖影** | 兵器运动时留**清晰色光拖影**（不是模糊），长度=力度；收招时拖影回收 | #246 剑光拖影、#245 金色交叉光轨 |
| CG-7 | **甲片与布料的物理反馈** | 击打带起甲片震动、披风/飘带/毛发的**惯性延迟**，方向与力一致 | #245 飘带、#219 长兵器红缨、#240 长发 |
| CG-8 | **招式带"起手光效"** | 大招前有明确的**蓄力视觉信号**（手掌发光/法阵亮起/光环聚拢），给观众预告 | #243 手中金色光球、#229 金光轮、#245 蓄力 |

| # | 技法 | 怎么做 | 证据 |
|---|---|---|---|

## 三、CG 打斗提示词模板（30s · 奇幻高武）

```
【画风锁】引擎级三维渲染的写实影视质感：真实摄影机成像、85mm浅景深、
真实材质（金属倒角反光/织物纤维/皮革磨损）、胶片颗粒与轻微色差、
强光比硬交界、体积光丁达尔光束；环境常有雪烟/扬尘/水汽。
全片能量特效只用[单一主色]一种，形态规整（法阵/光柱/放射线），只在冲击帧与大招帧出现。
禁止：手绘插画感与二维赛璐璐分色、廉价游戏CG、塑料皮肤/磨皮脸、
3D软体面条感、武器变形、BOSS拟人化、血腥断肢处决。

【角色锁】@图片1 主角脸型/发型/服饰/武器全程稳定；伴生兽用同款不同个体批量。

[0–2s]  全景建立：镜面/光纹地面 + 垂直光柱阵列框出竞技场，主角立于中央
[2–5s]  敌方（黑甲/巨怪/机械）从光柱后进入，回合 1：攻→挡→退，光刃拖影留色光轨迹
[5–9s]  回合 2：主角跃起或借兽群掩护，甲片/飘带惯性延迟，地面起尘
[9–13s] 中段转折：主角被压制 → 唯一一次升格（大招/附魔/惊险躲过三选一）
[13–20s] 蓄力：手掌/手中武器亮起[主色]光球或法阵，光环聚拢预告大招
[20–26s] 大招命中：接触帧爆发能量几何（放射线/法阵），短促震镜 + 尘屑粒子
[26–30s] 收尾：地面向天射出[主色]光柱（拔高型）→ 拉远景几乎静止 → 定格在徽记
```

## 四、CG 路线禁用清单

| 禁止 | 为什么 |
|---|---|
| 手绘插画感 / 二维赛璐璐分色平涂 | 这是 2D 特征，写实渲染路线专禁 |
| 廉价游戏 CG / 2.5D 木偶感 | 直接掉档 |
| 塑料皮肤 / 磨皮脸 | 真实质感崩坏 |
| 3D 软体面条感（结构变形） | 机甲/结构类必须刚性咬合 |
| 多色高饱和特效同时出现 | 破坏"单色能量语汇" |
| 武器变形 / BOSS 拟人化 | 同 `02` 通用禁用 |
| 血腥断肢 / 处决特写 | 平台与观感双因（见 `02`） |

## 五、与 07（画风）的分工

* `07` 定**画风是什么**（写实影视质感 vs 2D）→ 决定用哪套风格锁；
* 本文件定**打斗怎么写**（场地/能量/招式/尺度/收尾）→ 在写实渲染路线内部使用；
* 两者是**串联**关系：先按 `07` 确认走写实 → 再按本文件写打斗语法。

## 六、镜头与切镜通用铁律（三条路线通用 · 吸收自叩叩哥参考包）

> 本章三条路线（写实 / 真人 / 2D）都适用，`10`/`11`/`16` 共享。

### 6.1 镜头规格五要素（每次镜头描述必含）

```
[景别] + [拍摄视角] + [角度] + [运镜方式] + [跟随目标]
```

* 景别四选一：全景 / 中景 / 近景 / 特写；
* 视角五选一：正 / 侧 / 斜 / 俯 / 仰；
* 角度具体化："30°仰""90°侧""45°斜俯"；
* 跟随目标写死：跟哪个角色 / 哪个部位；
* ❌ 禁"镜头拉远 / 镜头靠近 / 跟随拍摄"这类模糊描述（命中 `13 R3`）。

### 6.2 镜头目的性四原则

| 场景 | 镜头配方 |
|---|---|
| 正常速度对招 | 中近景 · 侧面 · 带移动感（聚焦手法变化） |
| 蓄力大前摇 | 仰视慢推（突出威力） |
| 快速攻防 | 斜角 + 方向移动（镜头配合显速度） |
| 特写 | 只做破绽 / 转折点的过渡标点 |

### 6.3 景别匹配法则

* 大幅动作（腾空 / 旋转 / 下劈 / 扫腿 / 飞踢）→ 配**全景 / 中景**（展示全貌 + 空间感）；
* 小幅动作（拳掌肘对攻 / 寸拳 / 格挡）→ 配**近景 / 中近景**（放大密度）；
* 小动作禁用全景（信息稀释看不清）；大动作禁止只用近景（张力不足）。

### 6.4 空间感铁律（30–60° 斜角）

中景及以上（能看到两人完整身子）**禁止 90° 侧面正拍**——那是横版格斗游戏感，纵深和兵器厚度全部消失；
必须用 **30–60° 斜角**制造纵深。高速兵器攻防同理（`16` 多镜路线同样适用）。

### 6.5 近景 ↔ 远景过渡

* **【近 → 远】三步过渡法**：① 近景：重击命中（看清打击点）→ ② 中景：被击者后退 / 被推飞（镜头跟拉）→ ③ 全景：撞墙 / 滑行 / 腾空（看大动作全貌）。**禁止跳切**。
* **【远 → 近】两步压缩法**：① 全景→中景：突进贴脸（镜头急推）；② 中景→近景：拳已到眼前（镜头微推锁脸）。允许——突进自带速度感。

### 6.6 旋转运镜禁令

成品提示词**禁止 360° 环绕与螺旋上升运镜**（眩晕、失向，三人同场更严重）：

* 近景对招段：用小幅**线性**运镜（急速横移跟拍 / 急速推镜 / 跟拍跟镜 / 震镜 / 快切 / 慢镜随动）；
* 终结爆发段：急速后拉跟镜 → 定格，或低仰推镜 → 定格；
* 环绕运镜仅在对峙蓄力段（无攻防接触时）**≤180°** 半圈，禁满圈。

## 七、特效系统（起源 → 流动 → 爆散 → 余韵；只生长，不开关）

### 7.1 特效轨迹四要素（缺一不可）

| 要素 | 定义 | 写法示例 |
|---|---|---|
| ① 起源点 | 特效从哪里生成 | "拳面凝聚""脚尖浮现""肘尖炸开" |
| ② 流动形态 | 沿什么路径流动 | 直线穿刺 / 弧线切割 / 螺旋扩散 / 垂直坠落 / 涟漪扩散 |
| ③ 终点爆散 | 在落点怎么炸开 | 冲击波 / 碎裂 / 扩散 / 湮灭 |
| ④ 余韵残留 | 攻击后是否留痕 | 地面焦痕 / 空气波纹 / 冰晶碎屑 / 火焰余烬 / 光痕缓缓熄灭 |

### 7.2 流动形态 × 动作类型匹配

| 动作 | 轨迹形态 | 写法示例 |
|---|---|---|
| 直拳 / 寸拳 / 标指 / 正蹬 / 脚尖刺 | 直线穿刺型 | "劲气沿前臂→拳面→指尖凝聚成锥，直线刺出留下空气被击穿的细长气孔" |
| 弧线踢 / 回旋踢 / 摆拳 / 横肘 / 鞭拳 | 弧线切割型 | "气焰沿小腿弧线从脚跟燃至脚尖，扫过处空气被切割出新月弧刃" |
| 旋转类 / 旋风踢 / 反背肘 | 螺旋扩散型 | "气焰沿身体旋转轴心螺旋上升，踢出时螺旋扩散炸开" |
| 下劈 / 砸肘 / 千斤坠 | 垂直坠落型 | "沿下劈腿拖出垂直火痕，触地瞬间环形冲击波炸裂" |
| 化劲 / 格挡 | 涟漪扩散型 | "接触点涟漪层层扩散，对方拳劲被逐层荡开消解" |
| 终结技 | 四合一型 | 起源→流动→爆散→余韵全部到位，终极视觉 |

### 7.3 特效生长三段论（时间维度）

特效不是"开关"（啪地出现），是"生长"（从萌芽到绽放）：

| 阶段 | 节点 | 表现 | 写法关键词 |
|---|---|---|---|
| **萌芽期** | 攻击起点 | 微弱但可辨识（颜色对 + 形态对 + 密度极低），预告"大招来了" | 凝聚 / 浮现 / 若隐若现 |
| **生长期** | 攻击推进 | 沿轨迹不断壮大，密度 / 范围 / 亮度递增 | 蔓延 / 增强 / 拖出 / 越来越浓 |
| **绽放期** | 命中瞬间 | 巅峰全力输出，冲击波 / 爆散 / 环形扩散 | 巅峰绽放 / 环形冲击波 / 气浪轰然扩散 |

### 7.4 特效三段使命（15s 的"炸"怎么分）

| 段 | 时间 | 强度 | 形态 |
|---|---|---|---|
| 前段 | 0–3s | 强（但非全力，留后手） | **一招一炸**：单招带完整特效弧线，一击即收（烟花弹：砰！亮了！灭了！） |
| 中段 | 3–12s | 弱 → 中 | **收尾炸**：连打过程**零特效**保持干净，收尾重击突然炸开（鼓点：咚咚咚——砰！） |
| 后段 | 12–15s | 巅峰（无保留） | **全程铺满炸**：三段论全开（烟花秀：点燃→升空→炸开→余烬飘落） |

> **铁律**：连打中零特效（否则画面糊 + 注意力被拉走，削弱机枪节奏的压迫感）；但**收尾重击必须有特效**——那是连打的"句号"。

### 7.5 特效动态描写 5 条

① 必须有**运动方式**（不是"紫黑气焰"，而是"紫黑烈焰缠绕小腿跳动炸裂"）；
② 必须有**质感词**；③ 必须有**层次**（焰流本体 + 纹理细节 + 外围光晕，≥3 层）；
④ 必须有**听觉层**；⑤ 必须**绑定身体部位**（"缠在 XX 部位上"，不是笼统"在角色身上"）。
