## 用法（三步）

1. **角色创建时选体系**：按 `04 §七` 流派选型定下兵器/身法方向，到对应卷读「技法总览表」。
2. **取招**：从该体系 12 招（或 25 招式）中取 **3–5 招 + 1 个杀招**，抄「详细技法表」里的执行级描述
   （招式名 + 动作 + 攻击轨迹 + 适用场景 + 视觉价值），**不要自己另编招式名**。
3. **挂特效与镜头**：每卷末尾的「镜头铁律 + 特效绑定建议 + 禁忌」直接并入角色卡与分镜约束。

> 多人武器对打时：双方各选一套体系，招式对位按 `01 §4.1`（攻防回合制）组织；打斗近景段照常过 `13 R16` 招式序列化。

## 红线适配（用本目录时必挂）

| 红线 | 要求 |
|---|---|
| R18 武器三级判定 | 明确武器 = 全片核心武器：招式、握法、刃口方向全程一致，禁中途变形 |
| R7 动词三要素 | 每招都写形态 / 方向 / 结果（词库已按此格式给出，抄全不要截断） |
| 真人路线 `11 §四` | 兵器招式不得超出人体极限；镰刀 / 太刀的奇幻轨迹只给路线 ① ③ |
| `12 §6.5` | 景别切换按三步过渡法，不跳切 |
| 特效单色系 R14 | 每卷「特效绑定建议」取用时按路线折成单色系（2D 路线再折成手绘笔触） |
