# 宋韵 · 创作提示词引擎

> 把一句诗、一段思路或一个生活片段，变成可直接使用的宋韵美学提示词。
> 不讲美学理论，直接给画面。

## 这是什么

「宋韵」是一个面向 AI 绘画与视频生成的提示词工程 Skill，专为**宋代美学**（宋画、宋词、宋制汉服、文人生活）打造。它把诗词意象自动拆解为画面要素分配，产出三套可直接投喂的提示词：

- **图片提示词**：image-gpt-2 长自然语言写法（13 段结构）+ Midjourney 写法（参数四件套收尾）
- **视频提示词**：Seedance 2.5 六层公式 + 秒级时间戳分镜（诗词逐句拆画，画面节奏跟随词的情绪曲线）
- **画意反推**：给一张参考图，反推成宋韵提示词

## 三条质感路线（严禁混写）

| 路线 | 定位 | 词汇特征 |
|------|------|----------|
| **A · 写实电影感**（默认） | 真人实拍质感 | 85mm、film grain、natural skin tone；松弛生活感时切「生活纪录片档」 |
| **B · 画意古画感** | 宋画绢本质感 | 绢本设色、工笔皴法（必带笔触描述）、大面积留白、散点透视 |
| **C · 图志海报** | 平面商业插画 | 瑞兽图志七段结构，适合节气海报、IP 物料、卡片封面 |

## 风格内核一句话

**淡到极致才是宋韵——克制、清雅、松弛、有生活气。**

- 低饱和传统色具名（月白、天水碧、不肯红……HEX 三联写法）
- 留白 + 前景遮挡，人物只占画面一半，「小人物大风景」
- 侧逆光柔雾、冷漫射光，弱化生硬阴影
- 妆造素雅（对襟褙子、素色低盘发），服装写「形制三件套」防影楼装
- 微事件叙事：一个极小的生活事故 + 人物克制的反应，比摆拍出情绪

## 使用方式（WorkBuddy 会话内）

直接说触发词即可，例如：

```
拆这首《行香子》，出宋韵视频
把这句诗变成画面：小舟从此逝，江海寄余生
来一组宋韵荷塘美人组图（横屏）
给这张图反推成宋韵提示词
```

**响应规则**：

| 你给什么 | 得到什么 |
|----------|----------|
| 单句诗 / 一个画面思路 | 直接 1-3 幅完整提示词（近景｜远景｜特写多景别组） |
| 整首词 / 诗（做视频） | 先给「画面拆解方案表」逐句确认，再逐句展开时间戳分镜 |
| 模糊需求 | 先反问：图还是视频？人物还是山水？横屏还是竖屏？ |

## 快速速查（开写前 5 秒）

1. **选路线**：写实电影感 or 画意古画感 → 词汇不混写
2. **定密度**：MJ 每幅 ≥90 词，五件套（分层服装/动作微细节/光影逻辑/皮肤材质/色板支撑）不缺
3. **定人物**：锚定句逐字一致，跨幅复用防漂移
4. **定数量**：单句 1-3 幅，整首先方案再展开
5. **定输出**：图片 MJ 四件套参数收尾，视频 30s 8 拍时间戳收尾

## 持续进化

本 Skill 内置**每日学习机制**（工作日自动执行）：按周主题轮换（服饰形制 → 纹样面料 → 色彩 → 宋画反推 → 整合）检索新素材，新词条以「中英对照提示词写法」形式追加进词库，每周归档推送至本仓库。
