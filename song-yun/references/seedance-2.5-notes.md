# Seedance 2.5 语法备忘（2026-08-31 官方手册 + 社区实测）

## 能力清单（官方手册）
- 单镜头原生 30s 直出；延长模式可续至 60s（多次套娃）；超长视频模式最长 180s
- 时间戳文本控制：秒级精度（误差±1s），控制动作演变与场景转场
- 多模态参考：至多 50 个素材（图片/视频/白模/绿幕），@语法分工
- 多宫格分镜图输入：推荐简约线稿/火柴人分镜，Prompt 控制构图、景别、运镜与动作
- 编辑能力：局部消除/替换、空间视角修改、BGM 分离移除、音色参考、多人参考（防双胞胎脸）、无缝转场、白模控制、绿幕编辑
- 小语种支持：中文理解重点优化，中文提示词直接写
- 去字幕/BGM 稳定性大幅优化

## 时间戳写法规则（社区实测）
- 基础格式：`0-3秒：动作描述；3-6秒：动作描述`；标记格式：`[0s] [2s] [4s]`
- 铁律：时间范围连续、不重叠、不跳跃、从 0 开始
- 每段一个核心动作；用"起始态→过程→结束态"描述（"从站立缓缓过渡到转身完成"）
- 段长 3-5 秒最佳；<2s 太碎，>8s 失去分段意义
- 30s 视频节点 ≤8 个，5-6 个为最佳密度
- 场景切换写 0.5-1s 过渡节点，避免生硬跳切
- 运镜/景别也可绑定时间（"第5秒开始镜头从左向右横移，第8秒停止改为上摇"）
- 全局约束（一致性、排除项）放时间戳之外
- 先粗后细：先 0-5/5-10 粗粒度，稳定后再细拆
- 时间戳不是帧级精确，是"节奏清晰的导演意图"

## 六层提示词公式
`[主体与身份] + [场景与时间] + [连续动作] + [镜头与景别] + [光影和声音] + [一致性与排除项]`
真人视频加四条：身份锚点（年龄/发型/服装/特征）、表演动机（为什么看/停/转身）、微动作（呼吸/视线/手指）、一致性约束。

## 30 秒通用结构
0-5s 建立场景 → 5-10s 触发事件 → 10-18s 核心展示 → 18-25s 情绪/视角升级 → 25-30s 结果落点+稳定尾帧（最后 1 秒画面稳定，方便延长或接字幕）

## 180 秒写法
总纲（人物/目标/视听风格）+ 分场（0-30 建立 / 30-70 发展 / 70-120 核心 / 120-160 转折 / 160-180 收束）+ 连续性约束。不是 30s 提示词的六倍。

## @ 参考素材语法
```
@图片1：只参考人物身份、脸型和发型；
@图片2：只参考服装版型与材质；
@视频1：只参考运镜节奏，不继承人物、车辆和环境；
@音频1：只参考音色与节奏。
```
参考素材锁定"长什么样"，提示词说明"接下来发生什么"。

## 视频延长写法
回答四问：从哪一帧接续？已有运动按什么速度继续？下一件新事件？哪些必须不变？
禁忌：只说"继续十秒"。

## 编辑指令公式
`编辑对象 + 时间范围 + 修改动作 + 目标结果 + 保留项`——最重要的词是"保留"。

## SHOT 表分镜写法（2026-09-11 补，来源：PicX Studio"古风美人多镜头"模板 / YouMind Seedance 2.0 多镜头提示词）

复杂表演类（多镜头、微表情、有台词）在时间戳剧本之外多一种骨架，五个部件：

1. **首帧 FIRST FRAME**：声明"=上传参考图，100%锁定"，逐项写死五官、妆容、发饰、服饰、姿态，
   再补一句铁律：`人物五官妆容服饰与首帧一致，全程肢体灵活流动，不得僵直定住`。
2. **分镜脚本**：`SHOT n｜起止秒｜景别` 三联表头，每镜只写：机位/景别 + 动作链（连贯有呼吸感）+ 微表情
   （睫毛一颤、胸口呼吸起伏、唇角几不可察上扬）+ 台词或"无台词，仅环境声"。
3. **镜头总述 CAMERA**：多机位分镜罗列（中近景/眼部 macro/侧脸特写/手部特写/回中近景），
   切换方式（硬切或极短叠化）、浅景深、背景虚化处理。
4. **氛围光线**：光向 + 色调 + 环境动效（花瓣飘落、流苏轻晃、金尘浮动）+ 基调词。
5. **声音设定**：音色/语速/气声程度，台词处严格贴合口型；台词量克制（全程 1-3 句短气语，
   其余用呼吸、叹息、眼神表演——"少台词重微表情"是古风美人档的关键）。

**节奏要点**：末镜"动中带静"收束（起身动作余韵中回眸/定格），比直接静止收尾自然；
表演优先级 = 眼神 > 手部细节 > 肢体大动作，镜头景别跟着优先级走（眼部可推 macro）。
